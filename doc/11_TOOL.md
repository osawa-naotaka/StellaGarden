# 施設・装置のクラフト設計 - Stella Garden

## 1. 設計方針

### 1.1 基本原則

- **序盤は金属なしで農業を開始できる**: 丸太と石だけでフェーズ1の全施設を構築可能
- **金属加工は中盤の自然な進行**: 隕鉄を見つけて炉＋金床で鍛造を開始する
- **割り刀（フロー）が板を解禁する鍵**: 隕鉄1個で作れる小さな刃物が、後半の全施設を解禁する
- **金属はリサイクル可能**: 持続可能な生活という世界観と一致
- **施設のアップグレードは導入しない**（フィージビリティスタディの範囲では簡潔さを優先）

### 1.2 素材の入手方法

| 素材 | 入手方法 | 再生成 | 備考 |
|------|---------|--------|------|
| 木材 | 斧で樹木を伐採 | あり（植林で再生） | 最も基本的な素材 |
| 石 | フィールド中の石をピッケルで砕く | あり（時間経過後にランダム再生成） | 序盤から入手可能 |
| 土 | シャベルでどこからでも採取 | あり（無尽蔵） | 炭焼き窯の材料 |
| 粘土 | シャベルで川辺から採取 | あり（時間経過後にランダム再生成） | 川の堆積作用で再供給される設定 |
| 隕鉄 | ピッケルでフィールド上の隕鉄を採取 | **なし（有限資源）** | 未開拓惑星の地表に散在 |

### 1.3 中間素材

| 中間素材 | レシピ | 解禁フェーズ | 用途 |
|---------|--------|------------|------|
| 硬木の歯 | 丸太 ×1 → 【作業台】 → 硬木の歯 | フェーズ1 | 脱穀機の歯 |
| 木炭 | 木材 → 【炭焼き窯】 → 木炭 | フェーズ2 | 炉の燃料（高温用） |
| 刃 | 隕鉄 or 鉄塊 → 【炉+木炭で加熱】→【金床で打つ】 → 刃 | フェーズ2 | 鉄の道具の刃部分 |
| 板 | 丸太 → 【作業台+割り刀】 → 板 | フェーズ3 | 搾油機・浸漬槽・紡ぎ車・織機 |
| 木ネジ棒 | 木材 → 【作業台+ノミ】 → 木ネジ棒 | フェーズ3 | 搾油機のスクリュー |
| 車軸 | 木材 → 【作業台+ノミ】 → 車軸 | フェーズ3 | 紡ぎ車の回転軸 |
| 木枠 | 板 → 【作業台+ノミ】 → 木枠 | フェーズ3 | 織機のフレーム |

## 2. フェーズ1 — 金属なし（序盤：食糧確保）

### 2.1 概要

序盤は丸太と石のみで農業基盤を構築する。ジャガイモ栽培と大豆の脱穀まで可能。**板も金属も不要*。

### 2.2 施設クラフトレシピ

#### 作業台（素手で作成 — 最初のクラフト）

```
丸太 ×4 → 【素手】 → 作業台
```

斧で木を倒し、丸太を組み合わせて作る。全てのクラフトの起点となる最重要施設。

#### 焚き火（素手で作成）

```
石 ×4 → 【素手】 → 焚き火
```

石を円形に並べた焚き火台。木材を投入して燃やすことで草木灰を生産する。草木灰はジャガイモの肥料（カリウム源）として序盤の農業に不可欠。

**用途:**
- 木材 → 草木灰（肥料）

#### 堆肥場（作業台で作成）

```
丸太 ×4 → 【作業台】 → 堆肥場
```

丸太を井桁に組んだ囲い。有機物を投入して発酵させ、堆肥を生産する。

#### 硬木の歯（作業台で作成 — 中間素材）

```
丸太 ×1 → 【作業台】 → 硬木の歯
```

硬い木材（樫や楢など）の丸太を作業台で石を使って削り出し、くし状の歯を成形する。脱穀機の部品として使用。金属の刃は不要 — 大豆の莢を外す程度の強度は硬木で十分。

#### 脱穀機（作業台で作成）

```
丸太 ×2 + 硬木の歯 ×1 → 【作業台】 → 脱穀機
```

千歯扱き（せんばこき）をモデルにした手動式。丸太の台座に硬木の歯（くし状）を横一列に並べ、大豆の茎を歯にあてがって引き抜くことで莢を外す。歴史的にも初期の千歯扱きは竹歯であり、硬木の歯で十分に機能する。

### 2.3 フェーズ1の素材フロー

```
伐採(斧) → 木材(丸太) ─→【素手】→ 作業台
                        ├→【作業台】→ 堆肥場
                        ├→【作業台】→ 脱穀機
                        └→【焚き火に投入】→ 草木灰

石(ピッケル) → 石 →【素手】→ 焚き火
```

## 3. フェーズ2 — 金属加工の開始（中盤への準備）

### 3.1 概要

隕鉄を見つけたら金属加工を開始する。炭焼き窯で木炭を作り、炉で隕鉄を加熱し、金床の上でハンマーで叩いて刃を鍛造する。刃に木の柄をつけて各種鉄の道具を作る。**最初に作る鉄器は割り刀（フロー）** — これにより丸太から板が作れるようになり、フェーズ3の全施設が解禁される。

金属加工を始めるために金属は不要。炭焼き窯は茎と土、炉は粘土と石、金床は石、ハンマーは石と木で全て作れる。

### 3.2 施設クラフトレシピ

#### 炭焼き窯（素手で構築 — 使い捨て）

```
案A (3:1): 丸太 ×12 + 茎 ×2 + 土 ×2 → 【素手】 → 炭焼き窯 → 木炭 ×4 + 土 ×2（窯は消滅）
案B (1:1): 丸太 ×12 + 茎 ×2 + 土 ×2 → 【素手】 → 炭焼き窯 → 木炭 ×12 + 土 ×2（窯は消滅）
```

丸太を積み上げ、藁や茎で覆い、その上から土で密閉して空気穴だけ残す。着火後、数日かけて蒸し焼きにし、完了後に土の覆いを崩して木炭を取り出す。**窯は使い捨て** — 覆いの藁は炭化するため再利用できず、毎回作り直す。土は窯を崩した際に回収可能。歴史的にも伏焼き法（charcoal clamp）はこの方式。

変換比率は案A（3:1、現実寄り）と案B（1:1、手間寄り）の2案を検討中（詳細は doc/18_FUEL.md 参照）。木材は窯の「中身」そのものであり、空の窯を作って後から投入するのではない。大豆の脱穀で出る茎と、どこでも取れる土が材料なので、使い捨てでも資源的な負担はほぼゼロ。

※数値は仮。他の施設レシピと合わせて調整予定。

#### 炉（素手で作成）

```
粘土 ×8 + 石 ×4 → 【素手】 → 炉
```

粘土を成形して石で土台を組み、天日で数日乾燥させた後、内部で最初の火を焚いて炉自身の壁を焼き固める（自己焼成）。別の炉は不要 — 世界中の伝統的な粘土炉と同じ方法。木炭を燃料にして送風管（粘土管で口吹き）で空気を送り込むことで、鍛造に必要な800〜1000℃に達する。中央アジアの伝統的な鍛冶炉をイメージした素朴な壺型〜ドーム型。

**用途:**
- 隕鉄 or 鉄塊を木炭で加熱 → 赤熱状態にして金床で刃を鍛造

#### 石の金床（素手で作成）

```
石 ×4 → 【作業台】 → 石の金床
```

大きく平らな石を据え付けた台。加熱した隕鉄や鉄塊をこの上に載せてハンマーで叩き、刃を成形する。歴史的にも最初期の鍛冶は大きな平石を金床として使用していた。

### 3.3 道具クラフトレシピ

#### 石のハンマー（作業台で作成）

```
石 ×1 + 木材 ×1 → 【作業台】 → 石のハンマー
```

石を木の柄に括り付けた原始的なハンマー。金床の上で加熱した金属を叩いて成形するのに使う。

#### 木のトング（作業台で作成）

```
木材 ×1 → 【作業台】 → 木のトング
```

生木を曲げた簡易火ばさみ。炉から熱い金属を掴んで金床に移すのに使う。

#### 刃（鍛造で作成 — 全ての鉄器の基礎）

```
隕鉄 ×1 or 鉄塊 ×1 → 【炉+木炭で加熱】→【トングで加熱した鉄を金床に移動】→【金床+ハンマーで鍛造】 → 刃
```

金床の上で赤熱した金属を叩いて薄く延ばし、刃の形に成形する。全ての鉄の道具はこの刃に木の柄をつけて作る。将来、刃以外の鍛造品（釘、蝶番等）が必要になった場合は、金床のレシピ選択肢として追加する。

#### 割り刀 / フロー（作業台で作成 — フェーズ3への鍵）

```
刃 ×1 + 木材 ×1 → 【作業台】 → 割り刀
```

L字型の刃物。丸太に刃を当て、木槌で叩いて木目に沿って割り、板を作る。鋸が普及する以前から使われていた歴史的な板作りの道具（riving）。割った板は木目を切断しないため、鋸で挽いた板より強度が高い。

**隕鉄1個 → 刃1個 → 割り刀1本。この割り刀がフェーズ3の全施設を解禁する。**

### 3.4 鍛造の手順

```
1. 炭焼き窯で木材から木炭を作る
2. 隕鉄をピッケルで採取する
3. 炉に木炭を入れて着火する
4. 隕鉄（or 鉄塊）を炉に入れて赤熱状態まで加熱する
5. 木のトングで赤熱した金属を掴み、石の金床に移す
6. 石のハンマーで叩いて刃の形に成形する
7. 刃 + 木材を作業台で組み合わせ → 鉄の道具
```

※ゲーム上は簡略化し、「炉に隕鉄/鉄塊と木炭を投入 → 刃を作成 → 作業台で道具を選択して作成」のような操作になる想定。

### 3.5 フェーズ2の素材フロー

```
丸太 ×8 + 茎 ×2 + 土 ×2 →【素手で構築・着火】→ 木炭 ×4（窯は消滅）

シャベル → 川辺 → 粘土 →【素手】→ 炉（+ 石×4）
石(ピッケル) → 石 →【作業台】→ 石の金床

隕鉄(ピッケル) + 木炭 →【炉で加熱】→【金床+ハンマー】→ 刃
  └→ 刃 + 木材 →【作業台】→ 割り刀（最優先）← フェーズ3を解禁
```

## 4. フェーズ3 — 板を使った高度な施設（中盤：サプライチェーン）

### 4.1 概要

割り刀で丸太から板を作れるようになり、精度や水密性が求められる高度な施設を構築できるようになる。亜麻の加工ラインと大豆の搾油ラインがここで完成する。

### 4.2 板の作り方

```
丸太 → 【作業台+割り刀】 → 板
```

割り刀を丸太に当て、木槌で叩いて木目に沿って割る。割った板は鋸で挽いた板より木目を切断しないため強度が高い。

### 4.3 施設クラフトレシピ

#### 叩き台（作業台で作成）

```
丸太 ×1 → 【作業台+割り刀】 → 叩き台
```

丸太を作業台で加工した台と、スカッチングナイフ（木製の刃）の2パーツで構成。浸漬済みの亜麻を台に押し当てて叩き、繊維と木質部を分離する。最もシンプルな施設。

#### 搾油機（作業台で作成）

```
板 ×4 + 木ネジ棒 ×1 → 【作業台】 → 搾油機
```

木製の縦型スクリュープレス機。太い木材から削り出した螺旋状の木ネジ棒で上から圧力をかけ、素材から油を搾り出す。歴史的にも中世ヨーロッパのオリーブ油・亜麻仁油搾油機は全木製のスクリュープレスだった。板による平面の受け皿が油漏れを防ぐため、丸太では代用できない。木ネジ棒の螺旋溝はノミで刻む必要がある。

#### 浸漬槽（作業台で作成）

```
板 ×8 + 粘土 ×2 → 【作業台】 → 浸漬槽
```

長方形の木製水槽。板を組んで槽を作り、接合部を粘土で目止め（コーキング）して水漏れを防ぐ。水を張って亜麻を漬けるため、隙間のない板張りが必須。48x16（3タイル横長）の大型施設のため板が多めに必要。水場（川・池）の近くに設置する。

#### 紡ぎ車（作業台で作成）

```
板 ×2 + 車軸 ×1 → 【作業台】 → 紡ぎ車
```

大きな木製フライホイール（車輪）と、車軸で連結されたスピンドルで構成。車輪を回すと糸が撚られる仕組み。スピンドルの先端は硬木を尖らせて代用し、金属不要。歴史的にもチャルカ（インドの手紡ぎ車）など全木製の紡ぎ車は多数存在する。フレームには薄い板が必要。車軸はノミで丸棒に削り出す。

#### 織機（作業台で作成 — 最も大型）

```
板 ×4 + 木枠 ×2 → 【作業台】 → 織機
```

木製のフレームに綜絖（そうこう）を組み込んだ手織り機。縦糸を張り、梭（シャトル）で横糸を通して布を織る。32x32（2x2タイル）の大型施設で素材が多く必要。板から木枠を作る二段階の加工が必要な唯一の施設。木枠のほぞ穴はノミで開けて接合する。

## 5. 金属のライフサイクル（リサイクル）

### 5.1 鍛造・劣化・再鍛造の循環

```
隕鉄 →【炉+木炭で加熱】→【金床+ハンマー】→ 刃 →【作業台+木材】→ 鉄の道具
                                                                      ↓ 使用による劣化
                                                                    耐久度0
                                                                      ↓
                                                                    鉄塊（残骸）
                                                                      ↓
                                               【炉+木炭で再加熱】→【金床+ハンマー】→ 刃
                                               （少量の追加隕鉄が必要な場合あり — 鍛造時のロス分）
                                                                      ↓
                                                              【作業台+木材】→ 鉄の道具（復活）
```

鉄塊は「中間素材」ではなく「劣化産物」としてのみ出現する。壊れた道具の金属部分（刃が欠け、使い物にならなくなった残骸）が鉄塊であり、炉で再加熱して金床で打ち直すことで再び刃にできる。

### 5.2 設計意図

- **持続可能性**: 壊れた鉄の道具から鉄塊を回収し、再び刃に打ち直して再利用できるため、有限資源である隕鉄を最大限活用できる
- **資源管理のジレンマ**: 鍛造のたびに少量のロスが生じるため、いずれ追加の隕鉄が必要になる。フィールド探索の動機付け
- **会社への依存脱却**: 初期装備の道具が壊れても、鉄塊を回収して自力で刃を鍛造し、新しい道具を作れる。道具の再申請（評価低下）を避けられる

### 5.3 隕鉄による鉄の歴史的背景

人類が最初に利用した鉄は隕鉄であり、鉄鉱石の製錬（紀元前1500年頃）より数千年早い。

- **エジプト（紀元前3200年）**: ツタンカーメンの短剣が隕鉄製（ニッケル含有で確認）
- **イヌイット**: 19世紀まで、グリーンランドの巨大隕石（Cape York隕石）から石で欠片を叩き割り、刃物にしていた
- **加工方法**: 隕鉄は完全に溶かす必要がない。加熱して赤熱状態（800〜1000℃）にし、ハンマーで叩いて成形する（鍛造）
- **耐久性**: ニッケルを含むため地上の鉄より錆びにくい

惑星開拓という設定では、隕石が風化せず地表に残っている説得力があり、世界観と非常に相性が良い。

## 6. 道具のクラフトレシピ

### 6.1 初期装備と自作道具の関係

プレイヤーは会社からの持ち込み品として鉄製の道具一式（くわ、じょうろ、鎌、ピッケル、斧、シャベル、ノミ）を所持してゲームを開始する。これらは使用により劣化し、いずれ壊れる。

壊れた道具の補充方法は3つ：
1. **会社に再申請**: 鉄製品が届くが、評価が下がる
2. **木/石版を自作**: 性能は劣るが、素材はどこでも手に入る（フェーズ1から可能）
3. **隕鉄で鉄版を自作**: 性能は持ち込み品と同等（フェーズ2から可能）

### 6.2 木/石版の道具（フェーズ1から作成可能）

| 道具 | レシピ | 作成場所 | 歴史的根拠 |
|------|--------|---------|-----------|
| 木のくわ | 木材 ×2 | 作業台+石 | 木の棒の先端を平たく削った掘り棒。最古の農具の一つ |
| 木のシャベル | 木材 ×2 | 作業台+石 | 硬木をくさびで割り、石で擦って板状に整えた木製スペード。中世ヨーロッパでも広く使用 |
| 石の斧 | 石 ×1 + 木材 ×1 | 作業台+石 | 磨製石斧。新石器時代の基本道具 |
| 石のピッケル | 石 ×1 + 木材 ×1 | 作業台+石 | 石の先端を尖らせて柄に固定 |
| 石の鎌 | 石 ×1 + 木材 ×1 | 作業台 | 燧石の薄片を木の柄に埋め込んだ鎌。ナトゥーフ文化（紀元前12000年）から存在 |
| じょうろ | 粘土 ×2 | 炉で焼成 | 素焼きの壺に注ぎ口をつけたもの。水を保持するため焼成が必須 |

**注意**:
- じょうろのみ炉（フェーズ2）が必要。素焼きしないと粘土が水でふやけるため。初期装備のじょうろは壊れにくい設定とし、じょうろが壊れるまでにフェーズ2に到達できる想定。
- ノミは木/石版が存在しない。精密な溝彫り・穴開けには鋭い金属刃が必須であり、石では代用できない。ノミはフェーズ3の中間素材（木ネジ棒・車軸・木枠）の加工に必要だが、フェーズ3の時点で鉄の鍛造が可能なため、持ち込みノミが壊れても鉄のノミを自作できる。

### 6.3 鉄版へのアップグレード（フェーズ2から作成可能）

鉄が使えるようになったら、鍛造した刃に木の柄をつけて鉄の道具を作る。

| 道具 | レシピ | 作成場所 | 効果 |
|------|--------|---------|------|
| 鉄のくわ | 刃 ×1 + 木材 ×1 | 作業台 | 耕作速度UP / 耐久度UP |
| 鉄のシャベル | 刃 ×1 + 木材 ×1 | 作業台 | 採掘速度UP / 耐久度UP |
| 鉄の斧 | 刃 ×1 + 木材 ×1 | 作業台 | 伐採速度UP / 耐久度UP |
| 鉄のピッケル | 刃 ×1 + 木材 ×1 | 作業台 | 採掘速度UP / 耐久度UP |
| 鉄の鎌 | 刃 ×1 + 木材 ×1 | 作業台 | 収穫速度UP / 耐久度UP |
| 鉄のノミ | 刃 ×1 + 木材 ×1 | 作業台 | 精密加工の精度UP / 耐久度UP |

鍛造は「隕鉄 or 鉄塊 →【炉+金床】→ 刃」の1工程。刃から道具への組み立ては作業台で行う。じょうろは粘土製で十分に機能するため、鉄版アップグレードの対象外。ノミは木/石版が存在しないため、アップグレードではなく新規作成となる（持ち込み品の代替）。

## 7. 全体構造

### 7.1 素材フロー全体図

```
【フェーズ1: 金属なし】
伐採(斧) → 丸太 ─→【素手】→ 作業台
                   ├→【作業台】→ 堆肥場
                   ├→【作業台】→ 脱穀機（+ 硬木の歯）
                   └→【焚き火に投入】→ 草木灰
石(ピッケル) → 石 →【素手】→ 焚き火

【フェーズ2: 金属加工】
丸太 + 茎 + 土(シャベル) →【素手で構築・着火】→ 木炭（窯は消滅）
川辺(シャベル) → 粘土 →【素手】→ 炉（+ 石×4）
地面(素手) → 石 →【素手】→ 石の金床
隕鉄(ピッケル) + 木炭 →【炉+金床+ハンマー】→ 刃 →【作業台+木材】→ 割り刀 ← フェーズ3を解禁
                                                    └→【作業台+木材】→ 鉄の道具各種

【フェーズ3: 板で高度な施設】
丸太 →【割り刀】→ 板
丸太 →【作業台】→ 叩き台
木材 →【作業台+ノミ】→ 木ネジ棒 / 車軸
板  →【作業台+ノミ】→ 木枠
板 →【作業台】─→ 搾油機（+ 木ネジ棒）
               ├→ 浸漬槽（+ 粘土）
               ├→ 紡ぎ車（+ 車軸）
               └→ 織機（+ 木枠）
```

### 7.2 推奨建設順序

ゲーム進行に合わせた施設の建設順序。05_CULTIVATION.md のゲーム進行フロー（6.2節）と対応する。

|------|----------|---------|------|
| ① | 作業台 | 丸太 ×4 | 全クラフトの起点 |
| ② | 焚き火 | 石 ×4 | 草木灰の生産（ジャガイモの肥料） |

| ④ | 脱穀機 | 丸太 ×2、硬木の歯 ×1 | 大豆の脱穀 |

**フェーズ2 — 金属加工:**

| 順序 | 施設/道具 | 必要素材 | 理由 |
|------|----------|---------|------|
| ⑤ | 炭焼き窯 | 丸太 ×8、茎 ×2、土 ×2 | 木炭 ×4 を生産（使い捨て） |
| ⑥ | 炉 | 粘土 ×8、石 ×4 | 隕鉄の加熱 |

| ⑩ | 刃（鍛造） | 隕鉄 ×1 | 鉄の道具の基礎パーツ |
| ⑪ | 割り刀 | 刃 ×1、木材 ×1 | 丸太→板の加工を解禁 |

**フェーズ3 — サプライチェーン構築:**

| 順序 | 施設 | 必要素材 | 理由 |
|------|------|---------|------|
| ⑫ | 搾油機 | 板 ×4、木ネジ棒 ×1 | 大豆/亜麻の搾油 |
| ⑬ | 浸漬槽 | 板 ×8、粘土 ×2 | 亜麻のレッティング |

| ⑮ | 紡ぎ車 | 板 ×2、車軸 ×1 | 亜麻繊維 → 糸 |

### 7.3 素材消費量の目安

**フェーズ1:**
- 丸太: 10本（作業台4 + 堆肥場4 + 脱穀機2）+ 硬木の歯用1 = 11本
- 石: 4個（焚き火）

**フェーズ2:**
- 茎: 2個（炭焼き窯）
- 土: 2個（炭焼き窯）
- 粘土: 8個（炉）
- 石: 9個（炉4 + 石の金床4 + 石のハンマー1）
- 隕鉄: 1個（刃 → 割り刀）
- 木材: 3本（石のハンマー1 + 木のトング1 + 割り刀の柄1）+ 木炭用の木材

**フェーズ3:**
- 板: 合計20枚（搾油機4 + 浸漬槽8 + 紡ぎ車2 + 織機4 + 木枠用2）
- 丸太: 叩き台1本
- 粘土: 2個（浸漬槽の目止め）
- 木材: 木ネジ棒用1 + 車軸用1 = 2本

板1枚あたり丸太1本とすると、フェーズ3で丸太約23本程度。全フェーズ合計で丸太約37本、粘土10個、石13個、茎2個、土2個、隕鉄1個。

## 8. 新規素材

### 8.1 粘土

#### 概要
川辺に自然に存在する堆積物。炉や浸漬槽など、耐水性・耐熱性が求められる施設の材料として使用する。

#### 入手方法
- **場所**: 川辺・湖岸のタイルに粘土パッチとして存在
- **道具**: シャベルで採取
- **採取後**: その場の粘土は消滅する
- **再生成**: 一定時間経過後、川辺タイルにランダムで再生成される（川の堆積作用による再供給）

#### 用途

| 用途 | 必要数 | 施設 |
|------|--------|------|
| 炉の建材 | 8 | 炉 |
| 浸漬槽の目止め | 2 | 浸漬槽 |

#### 設計意図
- 川辺に行く理由を作り、マップ探索を促す
- 再生成ありだが大量には必要ないため、資源管理のストレスは低い
- 10_RIVER.md の川システムとの自然な連携

### 8.2 隕鉄

#### 概要
未開拓惑星の地表に散在する隕石由来の鉄。人類が最初に利用した鉄は隕鉄であり（鉄器時代以前のエジプト・ヒッタイト等）、惑星開拓という設定と非常に相性が良い。

#### 入手方法
- **場所**: フィールド上にデフォルトで存在（ランダム配置）
- **道具**: ピッケルで採取
- **再生成**: **なし（有限資源）**。惑星に降り注いだ隕石は増えないため

#### 用途

| 用途 | 必要数 | 備考 |
|------|--------|------|
| 刃の鍛造（→割り刀） | 1 | フェーズ3を解禁する最重要用途 |
| 刃の鍛造（→鉄の道具各種） | 1個/刃 | 鉄塊からのリサイクルでも可 |
| 鍛造時のロス補充 | 少量 | リサイクル時に必要な場合あり |
| 将来の金属部品 | 未定 | 自動化機械、高度な道具、建築資材等 |

#### 設計意図
- **探索の報酬**: フィールド探索中に光る石を見つける楽しさ
- **有限であることの価値**: 再ポップしないため、見つけたら慎重に使う動機が生まれる
- **将来への布石**: 鉱山システムを導入しなくても、少量の金属加工が可能
- **世界観との一致**: 未開拓惑星なら隕石が風化せず地表に残っている説得力がある

### 8.3 石

#### 概要
フィールドの地面に散在する小石。焚き火、炉、金床など、石組みの施設の材料として使用する。

#### 入手方法
- **場所**: フィールドの地面に散在
- **道具**: 素手で拾う
- **再生成**: あり（時間経過後にランダム再生成）

### 8.4 木炭

#### 概要
炭焼き窯で木材を蒸し焼きにして作る燃料。通常の木材では到達できない高温（1000℃以上）を実現し、金属の鍛造を可能にする。

#### 入手方法
- **生産**: 木材 → 【炭焼き窯】 → 木炭
