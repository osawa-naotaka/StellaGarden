# 施設・装置のクラフト設計 - Stella Garden

> 本ドキュメントは、旧クラフト・鍛造仕様を最新設計に合わせて整理した版である。  
> 特に `15_RE_SYNOPSIS.md`、`18_FUEL.md`、`19_CRAY.md`、`20_FORGE.md` の内容を優先し、旧仕様との矛盾を解消している。  
> 旧来の「炉で加熱 → トングで運ぶ → 金床でハンマーで叩く」を必須とする鍛造フローは廃止し、**炉UIで加熱して `hot_meteoric_iron` を作り、金床で `blade` に変換する簡略フロー**を正式仕様とする。

---

## 1. 設計方針

### 1.1 基本原則

- **序盤は金属なしで農業を開始できる**
  - 木材・石・土・粘土だけで、食糧確保と基礎加工が成立する
- **クラフトはオープンクラフト方式**
  - スキルツリーは採用しない
  - プレイヤーは最初から作り方を知っており、制約は資源と設備のみ
- **金属加工は中盤の自然な進行**
  - 隕鉄を見つけ、木炭を作り、炉と金床で刃を得る
- **割り刀（フロー）が板加工の解禁キー**
  - 板を作れるようになることで、中盤以降の施設群が一気に広がる
- **金属は有限資源だが、将来的な再利用余地を残す**
  - ただし、現時点の正式仕様では鉄塊リサイクル経路は未対応
- **施設アップグレード制は導入しない**
  - フィージビリティスタディ段階では、段階的な施設追加で進行感を作る

### 1.2 クラフト進行の全体像

| フェーズ | 主題 | 主な解禁内容 |
|---|---|---|
| フェーズ1 | 金属なしの生活基盤 | 作業台、焚き火、堆肥場、脱穀機 |
| フェーズ2 | 金属加工の開始 | 炭焼き窯、炉、石の金床、刃、割り刀 |
| フェーズ3 | 板加工と高度施設 | 搾油機、浸漬槽、紡ぎ車、織機 |
| 将来 | 自動化・灌漑・物流 | 水車、シャフト、台車、各種アタッチメント等 |

### 1.3 最新鍛造フロー

旧仕様では、鍛造は以下のような多段階工程だった。

- 炉で加熱
- トングで取り出す
- 金床に移す
- ハンマーで叩く

しかし最新仕様では、これを以下に簡略化する。

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-8
隕鉄 ×1
  → 【炉 + 木炭で加熱】
  → 赤熱した隕鉄（hot_meteoric_iron） ×1
  → 【金床にインタラクト】
  → 刃（blade） ×1
```

この変更により、

- UI/UX が簡潔になる
- チルなゲーム性と整合する
- 炉UI・金床操作・燃料管理に役割が分かれる
- 旧来のトング・ハンマー必須仕様との矛盾が解消される

### 1.4 旧仕様からの整理ポイント

- **トング・ハンマーは鍛造の必須工程ではない**
  - レシピ定義が残る可能性はあるが、正式フローからは外れる
- **鉄塊（`iron_ingot`）の再鍛造は将来対応**
  - 本ドキュメントでは扱わない
- **炉は専用UIを持つ施設**
  - 原材料・燃料・結果の3スロットで処理する
- **燃料は木材と木炭の2系統**
  - ただし鍛造では木炭を使用する

## 2. 素材の入手方法

| 素材 | 入手方法 | 再生成 | 備考 |
|---|---|---|---|
| 木材 | 樹木を伐採 | あり | 最も基本的な素材 |
| 石 | フィールド上の石を採取 | あり | 序盤から使う |
| 土 | シャベルで採取 | 実質無尽蔵 | 炭焼き窯などに使用 |
| 粘土 | 川辺で採取 | あり | 炉・浸漬槽・焼きレンガ系に使用 |
| 隕鉄 | フィールド上の隕鉄を採取 | なし | 有限資源。鍛造の起点 |
| 茎・枝葉・残渣 | 農作業や伐採の副産物 | あり | 堆肥・炭焼き窯材料などに使用 |
| 木炭 | 炭焼き窯で生産 | 生産物 | 高温燃料 |

## 4. フェーズ1 — 金属なし（序盤：食糧確保）

### 4.1 概要

この段階では、農業の立ち上げと最低限の加工を行う。  
ジャガイモの食糧確保、大豆の脱穀、堆肥づくりまでが主な目標。

### 4.2 施設クラフトレシピ

#### 作業台（最初のクラフト）

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
木材 ×4 → 【素手】 → 作業台
```

- 全クラフトの起点
- 最優先で作る施設

#### 焚き火

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
石 ×4 → 【素手】 → 焚き火
```

- 木材を燃やして草木灰を得る
- 序盤の肥料供給源

**用途**
- 木材 → 草木灰

#### 堆肥場

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
木材 ×4 → 【作業台】 → 堆肥場
```

- 有機物を投入して堆肥を作る
- ひまわり、茎、枝葉、残渣などを処理する

#### 硬木の歯

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
木材 ×1 → 【作業台】 → 硬木の歯
```

- 脱穀機の部品
- 金属なしで作れる

#### 脱穀機

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
木材 ×2 + 硬木の歯 ×1 → 【作業台】 → 脱穀機
```

- 茎付き大豆を脱穀する
- 大豆加工ラインの入口

### 4.3 フェーズ1の素材フロー

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-10
木材
 ├→ 作業台
 ├→ 堆肥場
 ├→ 硬木の歯 → 脱穀機
 └→ 焚き火に投入 → 草木灰

石
 └→ 焚き火
```

## 5. フェーズ2 — 金属加工の開始（中盤への準備）

### 5.1 概要

隕鉄を見つけたら、木炭を作り、炉と金床で刃を得る。  
この段階の最重要目標は **割り刀の作成** である。  
割り刀ができると板加工が解禁され、フェーズ3へ進める。

### 5.2 施設クラフトレシピ

#### 炭焼き窯

木炭の変換比率は `18_FUEL.md` で最終決定待ちだが、現時点では2案併記とする。

**案A（3:1）**
```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
木材 ×12 + 茎 ×2 + 土 ×2 → 【素手】 → 炭焼き窯 → 木炭 ×4 + 土 ×2
```

**案B（1:1）**
```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
木材 ×12 + 茎 ×2 + 土 ×2 → 【素手】 → 炭焼き窯 → 木炭 ×12 + 土 ×2
```

- 使い捨て施設
- 茎は消費される
- 土は回収される
- 木炭生産専用

#### 炉

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
粘土 ×8 + 石 ×4 → 【素手】 → 炉
```

- 鍛造用の加熱施設
- 専用UIを持つ
- 原材料スロット、燃料スロット、結果スロットを持つ

**用途**
- 隕鉄 + 木炭 → 赤熱した隕鉄

#### 石の金床

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
石 ×4 → 【作業台】 → 石の金床
```

- 赤熱した隕鉄を刃に変換する
- フィールド上で直接インタラクトする施設

### 5.3 鍛造関連アイテム

#### 赤熱した隕鉄

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
隕鉄 ×1 + 木炭 ×1 → 【炉】 → 赤熱した隕鉄 ×1
```

- `itemId`: `hot_meteoric_iron`
- 炉の結果スロットに生成される
- 冷却しない
- 金床で刃に変換するための中間素材

#### 刃

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
赤熱した隕鉄 ×1 → 【金床】 → 刃 ×1
```

- 鉄製道具の基礎パーツ
- 割り刀の材料
- 各種鉄道具の材料

#### 割り刀 / フロー

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
刃 ×1 + 木材 ×1 → 【作業台】 → 割り刀
```

- 板加工の解禁キー
- フェーズ3への入口

### 5.4 正式な鍛造手順

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-10
1. 炭焼き窯で木炭を作る
2. 隕鉄を採取する
3. 炉UIを開く
4. 原材料スロットに隕鉄を入れる
5. 燃料スロットに木炭を入れる
6. 日経過で赤熱した隕鉄が生成される
7. 結果スロットから回収する
8. 金床にインタラクトして刃にする
9. 刃 + 木材で割り刀や鉄道具を作る
```

### 5.5 旧仕様の扱い

以下は旧仕様として扱い、正式フローから外す。

- 木のトングで炉から金属を運ぶ工程
- 石のハンマーで金床上の金属を叩く工程
- 鉄塊からの再鍛造を現時点で必須とする記述

**補足**
- トング・ハンマー自体を完全削除するとは限らない
- ただし、少なくとも現在の鍛造の正規ルートではない

### 5.6 フェーズ2の素材フロー

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-12
木材 + 茎 + 土
  → 炭焼き窯
  → 木炭

粘土 + 石
  → 炉

石
  → 石の金床

隕鉄 + 木炭
  → 炉
  → 赤熱した隕鉄
  → 金床
  → 刃
  → 割り刀
```

## 6. フェーズ3 — 板を使った高度な施設（中盤：サプライチェーン）

### 6.1 概要

割り刀で板を作れるようになると、加工施設の幅が大きく広がる。  
ここで大豆・亜麻の本格的な加工ラインが成立する。

### 6.2 板の作り方

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
木材 → 【作業台 + 割り刀】 → 板
```

- 丸太を木目に沿って割る
- 高度施設の基本建材

### 6.3 施設クラフトレシピ

#### 叩き台

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
木材 ×1 → 【作業台 + 割り刀】 → 叩き台
```

- 浸漬済み亜麻から繊維を分離する

#### 搾油機

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
板 ×4 + 木ネジ棒 ×1 → 【作業台】 → 搾油機
```

- 大豆や亜麻の種から油を搾る
- 油粕も副産物として得る

#### 浸漬槽

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
板 ×8 + 粘土 ×2 → 【作業台】 → 浸漬槽
```

- 亜麻のレッティングに使う
- 水場近くに置く想定

#### 紡ぎ車

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
板 ×2 + 車軸 ×1 → 【作業台】 → 紡ぎ車
```

- 亜麻繊維を糸にする

#### 織機

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-3
板 ×4 + 木枠 ×2 → 【作業台】 → 織機
```

- 糸から布や袋を作る
- 大豆出荷にも関わる重要施設

### 6.4 フェーズ3の素材フロー

```/dev/null/StellaGarden/doc/11_TOOL.md#L1-14

 └→ 板
     ├→ 搾油機
     ├→ 浸漬槽
     ├→ 紡ぎ車
     └→ 織機

木材
 ├→ 木ネジ棒 → 搾油機
 ├→ 車軸 → 紡ぎ車
 └→ 木枠 → 織機
```

## 9. 燃料との関係

### 9.1 基本方針

燃料は以下の2種類。

- 木材
- 木炭

### 9.2 本ドキュメントとの関係

- **炭焼き窯** は木材を木炭に変換する施設
- **炉** は木炭を燃料として使う
- 焼きレンガなど将来の中温加工では木材も候補になりうる
- 高温加工は木炭前提

### 9.3 木炭変換比率

木炭の変換比率はまだ最終決定していない。

- 案A: 3:1
- 案B: 1:1

したがって、本ドキュメントでは炭焼き窯レシピを2案併記とする。

## 10. 粘土との関係

### 10.1 粘土の役割

粘土は以下に使う。

- 炉
- 浸漬槽
- 将来的な焼きレンガ・導水路系

### 10.2 設計上の意味

- 川辺に行く理由になる
- 水システムとクラフト進行がつながる
- 金属加工と灌漑の両方に関わる重要資源

## 11. 現時点での正式な整理

### 正式仕様として採用するもの

- オープンクラフト方式
- 炭焼き窯による木炭生産
- 炉UIによる加熱処理
- `hot_meteoric_iron` の導入
- 金床で `blade` を得る簡略鍛造
- 割り刀による板加工解禁
- フェーズ1 → フェーズ2 → フェーズ3 の段階構成

### 旧仕様として扱うもの

- トング必須
- ハンマー必須
- 炉から金床への手運搬を正式工程とする記述
- 鉄塊リサイクルを現時点で正式フローに含める記述

## 13. まとめ

Stella Garden のクラフト進行は、

- 木と石で生活基盤を作り
- 木炭と隕鉄で金属加工を始め
- 割り刀で板を作り
- 板から高度な加工施設へ進む

という流れで構成される。

そして鍛造は、旧来の複雑な手順ではなく、

**炉で加熱して赤熱した隕鉄を作り、金床で刃にする**

というシンプルな流れに整理された。

これにより、クラフト進行はより明快になり、  
農業・加工・灌漑・自動化へ自然につながる構造になっている。
