# 施設・装置のクラフト設計 - Stella Garden

## 1. 設計方針

### 1.1 基本原則

- **鉄なしで全施設を作れる**: 木材と粘土を中心に、全ての加工施設を金属なしでクラフト可能とする
- **中間素材は最小限**: 板（木材から加工）が主要な中間素材。過度な複雑さを避ける
- **素手→作業台の2段階**: 作業台と炉のみ素手で作成可能。他の全施設は作業台で作成する
- **施設のアップグレードは導入しない**（フィージビリティスタディの範囲では簡潔さを優先）

### 1.2 素材の入手方法

| 素材 | 入手方法 | 再生成 | 備考 |
|------|---------|--------|------|
| 木材 | 斧で樹木を伐採 | あり（植林で再生） | 最も基本的な素材 |
| 粘土 | シャベルで川辺から採取 | あり（時間経過後にランダム再生成） | 川の堆積作用で再供給される設定 |
| 石 | 地面から拾う / 川辺で採取 | あり（時間経過後にランダム再生成） | 粘土と同様 |
| 隕鉄 | ピッケルでフィールド上の隕鉄を採取 | **なし（有限資源）** | 未開拓惑星の地表に散在 |

### 1.3 中間素材（作業台で加工）

| 中間素材 | レシピ | 用途 |
|---------|--------|------|
| 板 | 木材 → 【作業台】 → 板 | ほぼ全施設の基本材料 |
| 硬木の歯 | 木材 → 【作業台】 → 硬木の歯 | 脱穀機の歯 |
| 木ネジ棒 | 木材 → 【作業台】 → 木ネジ棒 | 搾油機のスクリュー |
| 車軸 | 木材 → 【作業台】 → 車軸 | 紡ぎ車の回転軸 |
| 木枠 | 板 → 【作業台】 → 木枠 | 織機のフレーム |

## 2. 施設クラフトレシピ

### 2.1 作業台（素手で作成 — 最初のクラフト）

```
木材 ×4 → 【素手】 → 作業台
```

斧で木を倒し、丸太を組み合わせて作る。全てのクラフトの起点となる最重要施設。

---

### 2.2 炉（素手で作成）

```
粘土 ×8 + 石 ×4 → 【素手】 → 炉
```

粘土を成形して石で土台を組み、天日干し後に内部で火を焚いて焼き固める。歴史的にも粘土製の素焼き炉は金属なしで作れる。中央アジアの伝統的な鍛冶炉をイメージした素朴な壺型〜ドーム型。

**用途:**
- 木材 → 草木灰（肥料）
- 将来: 隕鉄 → 鉄塊（金属加工）

---

### 2.3 堆肥場（作業台で作成）

```
板 ×6 → 【作業台】 → 堆肥場
```

板を箱型に組んだシンプルな構造。切り欠きや木ダボで接合する。

---

### 2.4 脱穀機（作業台で作成）

```
板 ×2 + 硬木の歯 ×1 → 【作業台】 → 脱穀機
```

千歯扱き（せんばこき）をモデルにした手動式。歴史的にも初期の千歯扱きは竹歯であり、硬木の歯で十分に機能する。木の台座に硬木の歯（くし状）を横一列に並べ、大豆の茎を歯にあてがって引き抜くことで莢を外す。

---

### 2.5 搾油機（作業台で作成）

```
板 ×4 + 木ネジ棒 ×1 → 【作業台】 → 搾油機
```

木製の縦型スクリュープレス機。太い木材から削り出した螺旋状の木ネジ棒で上から圧力をかけ、素材から油を搾り出す。歴史的にも中世ヨーロッパのオリーブ油・亜麻仁油搾油機は全木製のスクリュープレスだった。作業台での加工の中では、木ネジ棒の削り出しが最も手間のかかる工程。

---

### 2.6 浸漬槽（作業台で作成）

```
板 ×8 + 粘土 ×2 → 【作業台】 → 浸漬槽
```

長方形の木製水槽。板を組んで槽を作り、接合部を粘土で目止め（コーキング）して水漏れを防ぐ。48x16（3タイル横長）の大型施設のため板が多めに必要。水場（川・池）の近くに設置する。

---

### 2.7 叩き台（作業台で作成）

```
板 ×2 → 【作業台】 → 叩き台
```

一枚板の台と、スカッチングナイフ（木製の刃）の2パーツで構成。浸漬済みの亜麻を台に押し当てて叩き、繊維と木質部を分離する。最もシンプルな施設。

---

### 2.8 紡ぎ車（作業台で作成）

```
板 ×2 + 車軸 ×1 → 【作業台】 → 紡ぎ車
```

大きな木製フライホイール（車輪）と、車軸で連結されたスピンドルで構成。車輪を回すと糸が撚られる仕組み。スピンドルの先端は硬木を尖らせて代用し、金属不要。歴史的にもチャルカ（インドの手紡ぎ車）など全木製の紡ぎ車は多数存在する。

---

### 2.9 織機（作業台で作成 — 最も大型）

```
板 ×4 + 木枠 ×2 → 【作業台】 → 織機
```

木製のフレームに綜絖（そうこう）を組み込んだ手織り機。縦糸を張り、梭（シャトル）で横糸を通して布を織る。32x32（2x2タイル）の大型施設で素材が多く必要。板から木枠を作る二段階の加工が必要な唯一の施設。

---

## 3. 施設クラフトの全体図

### 3.1 素材フロー

```
伐採(斧) → 木材 →【素手】→ 作業台
川辺(シャベル) → 粘土 ─┐
地面(素手) → 石 ────┘→【素手】→ 炉

                ┌→ 板 ×6 ──────────────────→ 堆肥場
                ├→ 板 ×2 + 硬木の歯 ──────────→ 脱穀機
木材 →【作業台】─┼→ 板 ×4 + 木ネジ棒 ──────────→ 搾油機
                ├→ 板 ×8 + 粘土 ×2 ──────────→ 浸漬槽
                ├→ 板 ×2 ──────────────────→ 叩き台
                ├→ 板 ×2 + 車軸 ────────────→ 紡ぎ車
                └→ 板 ×4 + 木枠 ×2（板から加工）→ 織機
```

### 3.2 推奨建設順序

ゲーム進行に合わせた施設の建設順序。05_CULTIVATION.md のゲーム進行フロー（6.2節）と対応する。

**序盤（食糧確保フェーズ）:**

| 順序 | 施設 | 必要素材 | 理由 |
|------|------|---------|------|
| ① | 作業台 | 木材 ×4 | 全クラフトの起点 |
| ② | 炉 | 粘土 ×8、石 ×4 | 草木灰の生産（ジャガイモの肥料） |
| ③ | 堆肥場 | 板 ×6 | 堆肥の生産（万能肥料） |

**中盤（サプライチェーン構築フェーズ — 大豆ライン）:**

| 順序 | 施設 | 必要素材 | 理由 |
|------|------|---------|------|
| ④ | 脱穀機 | 板 ×2、硬木の歯 ×1 | 大豆の脱穀 |
| ⑤ | 搾油機 | 板 ×4、木ネジ棒 ×1 | 大豆/亜麻の搾油 → 油＋油粕 |

**中盤（サプライチェーン構築フェーズ — 亜麻ライン）:**

| 順序 | 施設 | 必要素材 | 理由 |
|------|------|---------|------|
| ⑥ | 浸漬槽 | 板 ×8、粘土 ×2 | 亜麻のレッティング |
| ⑦ | 叩き台 | 板 ×2 | 亜麻の繊維分離 |
| ⑧ | 紡ぎ車 | 板 ×2、車軸 ×1 | 亜麻繊維 → 糸 |
| ⑨ | 織機 | 板 ×4、木枠 ×2 | 糸 → 布/袋（大豆出荷に必要） |

### 3.3 木材消費量の目安

全施設を建設するために必要な木材の総量（概算）:

| 中間素材 | 必要板数 | 備考 |
|---------|---------|------|
| 板 | 合計 30枚 | 全施設分 |
| 硬木の歯 | 1 | 脱穀機用 |
| 木ネジ棒 | 1 | 搾油機用 |
| 車軸 | 1 | 紡ぎ車用 |
| 木枠 | 2 | 織機用（板から加工） |

板1枚あたり木材1本とすると、木枠用を含めて木材約35本程度。粘土は合計10個（炉8 + 浸漬槽2）。

## 4. 新規素材: 粘土

### 4.1 概要

川辺に自然に存在する堆積物。炉や浸漬槽など、耐水性・耐熱性が求められる施設の材料として使用する。

### 4.2 入手方法

- **場所**: 川辺・湖岸のタイルに粘土パッチとして存在
- **道具**: シャベルで採取
- **採取後**: その場の粘土は消滅する
- **再生成**: 一定時間経過後、川辺タイルにランダムで再生成される（川の堆積作用による再供給）

### 4.3 用途

| 用途 | 必要数 | 施設 |
|------|--------|------|
| 炉の建材 | 8 | 炉 |
| 浸漬槽の目止め | 2 | 浸漬槽 |

### 4.4 設計意図

- 川辺に行く理由を作り、マップ探索を促す
- 再生成ありだが大量には必要ないため、資源管理のストレスは低い
- 10_RIVER.md の川システムとの自然な連携

---

## 5. 新規素材: 隕鉄

### 5.1 概要

未開拓惑星の地表に散在する隕石由来の鉄。地球では人類が最初に利用した鉄は隕鉄であり（鉄器時代以前のエジプト・ヒッタイト等）、惑星開拓という設定と非常に相性が良い。

### 5.2 入手方法

- **場所**: フィールド上にデフォルトで存在（ランダム配置）
- **道具**: ピッケルで採取
- **再生成**: **なし（有限資源）**。惑星に降り注いだ隕石は増えないため

### 5.3 加工

```
隕鉄 → 【炉】 → 鉄塊（少量）
```

### 5.4 用途（現時点の想定）

現在のフィージビリティスタディの範囲では、全施設が木材と粘土のみでクラフト可能なため、隕鉄の具体的な用途は将来フェーズに委ねる。想定される用途:

- 自動化機械の金属部品
- 高度な道具の作成
- ロボットの修理・製造
- 建築資材（釘、金具など）

### 5.5 設計意図

- **探索の報酬**: フィールド探索中に光る石を見つける楽しさ
- **有限であることの価値**: 再ポップしないため、見つけたら慎重に使う動機が生まれる
- **将来への布石**: 鉱山システムを導入しなくても、少量の金属加工が可能
- **世界観との一致**: 未開拓惑星なら隕石が風化せず地表に残っている説得力がある
