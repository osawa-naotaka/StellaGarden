## アイコンと地図上のエンティティスプライト

基本は16px x 16pxのトップビューで作る。
pngフォーマットで、RGBA8888。
背景透過。サイズ記載のないものは 16x16。
各ファイルにはid番号を振ってある。そのidを使ってss_sprite_xxx.pngという形式のファイル名で作成。

## 土地

地図上のエンティティスプライトは並べて使った時に違和感がないように、連続した絵になるように上下左右端を作成する。

- インベントリのアイコン
  - [x] 046 土の塊
    - 不規則な形の土の塊。中程度の茶色。
- 地図上のエンティティスプライト
  - 雑草地（ありものを使うので新たには作らない）
  - [x] 047 荒地（収穫直後など）
    - 草も作物もない剥き出しの土。中程度の茶色で均一な面。
  - [x] 048 耕作地（耕され、畝立てされている土地）
    - 畝の畝（うね）と畝間（うねま）が交互に並ぶ横縞模様。明るい茶色〜赤茶色。中央に畝が横1列、その上下に畝間の半分が横一列ずつ。
  - [x] 049 水やりされた耕作地
    - 耕作地ベースに、畝間（溝部分）に水が少し溜まっているイメージ。土全体がやや濃い色になり湿っぽい質感。
  - [x] 050 肥料を撒いた土（緑肥漉き込み後の土も同スプライト）
    - 耕作地のスプライトの上に乗せて使う。白い斑点が散っている耕作地。白い斑点のみを描き、その他は背景として透過にする。
  - [x] 051 連作障害が発生した土地
    - くすんだ黄土色〜灰茶色のベース。病斑を示す濃い茶色や黒の斑点模様が全体に広がっている。健全な土地より暗く不健康な印象。

## 施設（地図上エンティティスプライトとアイコン）

施設はすべてフィールドに配置するオブジェクト。ざる / 選別台はFS対象外のため省略。
アイコンは全て16px x 16pxにする。フィールドに置いた時の施設の大きさが下記に示されたものになる。

| 施設 | サイズ（px） | タイル数 | 段階数 | 用途 |
|------|------------|---------|--------|------|
| 焚き火 | 16x16 | 1x1 | 1 | 木材 → 草木灰 |
| 炉 | 16x16 | 1x1 | 1 | 隕鉄を木炭で加熱し、赤熱した隕鉄を作る |
| 炭焼き窯 | 16x16 | 1x1 | 1 | 使い捨て。丸太×12+茎×2+土×2 → 木炭（変換量は仕様検討中、窯は消滅） |
| 石の金床 | 16x16 | 1x1 | 1 | 赤熱した隕鉄を刃に成形する台 |
| 堆肥場 | 32x32 | 2x2 | 3（熟成段階） | 有機物 → 堆肥 |
| 千歯扱き | 32x16 | 2x1（横長） | 1 | 茎付き大豆 → 大豆 + 茎 |
| 搾油機 | 32x32 | 2x2 | 1 | 大豆 / 亜麻の種 → 油 + 油粕 |
| 浸漬槽 | 48x16 | 3x1（横長） | 1 | 亜麻のレッティング。水場付近に設置 |
| 叩き台 | 16x16 | 1x1 | 1 | 浸漬済み亜麻 → 亜麻の繊維 + 作物残渣 |
| 紡ぎ車 | 32x16 | 2x1 | 1 | 亜麻の繊維 → 糸 |
| 織機 | 32x32 | 2x2 | 1 | 亜麻糸 → リネン布（袋は手動クラフト） |

### 各施設の描画メモ

- [x] 052 **炉**（16x16）
  - 粘土製の壺型〜ドーム型の小型炉。中央上部に開口部（火口）があり、炎が見えている。粘土の送風管（吹子）で空気を送り込む構造。中央アジアの伝統的な鍛冶炉に近いイメージ。木炭を燃料にして隕鉄を加熱し、赤熱した隕鉄を作る。
  - 参考: [File:Bukhara,_forge.jpg (Wikimedia Commons)](https://commons.wikimedia.org/wiki/File:Bukhara,_forge.jpg)
  - 炉は32x32にしたくなったため、052はアイコンとして使う

- [x] 053 **堆肥場**（32x32、3段階スプライト）
  - 木製の四角い枠（コンポストボックス）。段階に応じて内容物が変化:
    - 段階1（投入直後）: 緑〜黄緑色の有機物（草や葉）が積まれている
    - 段階2（発酵中）: 茶色に変色し、少し湯気が出ているイメージ
    - 段階3（熟成完了）: 黒〜濃い茶色の均一な堆肥が詰まっている
  - 参考: [Category:Compost bins (Wikimedia Commons)](https://commons.wikimedia.org/wiki/Category:Compost_bins)

- [x] 054 **千歯扱き**（32x16・横長）
  - 千歯扱き（せんばこき）をモデルにした手動式。丸太の台座に硬木の歯（くし状）が横一列に並んでいる。大豆の茎を歯にあてがって引き抜くことで莢が外れる仕組み。歴史的にも初期の千歯扱きは竹歯であり、金属不要。
  - 参考: [千歯扱き (Wikipedia)](https://ja.wikipedia.org/wiki/%E5%8D%83%E6%AD%AF%E6%89%B1%E3%81%8D)

    - 一応、類似資料です。

- [x] 055 **搾油機**（32x32）
  - 木製の縦型スクリュープレス機。太い木の柱に螺旋状のネジが通っており、上から押し付けて素材から油を搾り出す。中世ヨーロッパの亜麻仁油・オリーブ油搾油機のイメージ。
  - 参考: [Category:Oil presses (Wikimedia Commons)](https://commons.wikimedia.org/wiki/Category:Oil_presses)

- [x] 056 **浸漬槽**（48x16・横長）

- [x] 057 **叩き台**（16x16）

## 灌漑システム（16_IRRIGATION.md で追加されたもの）

### 共通方針

- 畝間水路・石組み導水路は接続状態に応じてスプライトを切り替える
- 接続パターンは **端末4方向 + 直線2方向 + 90度×4 + T字×4 + 十字×1 = 15種類** で全ての分岐を網羅
- 水あり/水なしの2状態（水門は開/閉）を別スプライトとして用意
- スプライトは回転ではなく、全パターンを個別画像として描き出す（ゲーム内で回転処理をしない方針）
- 最新仕様では、水は「水面＝海面方式」を前提とし、畑への散水は**水タイルから直接ではなく、畝間水路またはじょうろを経由して行う**
- 旧来の `waterSource` / `flowedWater` 前提の説明は採用しない

### ID番号とサブ番号の規則

同一カテゴリ内で向き・縦横のバリエーションがあるものは、親ID + サブ番号で表現する。

- ファイル名: サブ番号ありは `ss_sprite_107_1.png` のように `_サブ番号` を付加、サブなしは `ss_sprite_106.png`
- 親IDはカテゴリ（形状 × 状態）を示す
- サブ番号は向き/縦横のバリエーションを示す

### 接続パターン一覧（参考）

畝間水路・石組み導水路で共通:

| 形状 | サブ番号の割り当て | バリエーション数 |
|---|---|---|
| 端末 | _end_u=上向き / _end_d=下向き / _end_l=左向き / _end_r=右向き | 4 |
| 直線 | _v=縦 / _h=横 | 2 |
| 90度曲がり | _corner_ru=右上 / _corner_rd=右下 / _corner_lu=左上 / _corner_ld=左下 | 4 |
| T字 | _t_u=上向き枝 / _t_d=下向き枝 / _t_l=左向き枝 / _t_r=右向き枝 | 4 |
| 十字 | なし | 1 |

水門:

| 状態 | サブ番号の割り当て |
|---|---|
| 閉・開 | _h=横向き / _v=縦向き |

## 動力・加工機械（17_AUTOMATION.md で追加されるもの）

### 共通方針

- シャフトは 16x16 の地形オーバーレイとして機能する（畝間水路と同様のネットワーク層）
- シャフトの接続パターンは 直線2 + L字4 + T字4 + 十字1 = **11種**（端末スプライトは機械スプライト側でカバーするため省略）
- 水車は2方向（縦/横）× 3フレームアニメーション = **6スプライト**（向きは voxel の variant ビットで保持、サブ番号がフレーム番号）。スプライトは縦方向を上下対称、横方向を左右対称に描き、両端どちらが水でも違和感が出ないようにする
- 加工機械は3フレームアニメーション = 各 **3スプライト**、全て 48x48（3x3タイル）

### 水車（動力源）

## 機械中間素材（11_TOOL.md のクラフト整理で追加されたもの）

水動力施設・台車・ウインチ等のクラフトレシピを「現実の機械工学に沿った階層」にまとめ直した結果、共通部品として中間素材を導入した。すべて板（085）や軸（既存 `shaft`、131）を加工して作る木工部品で、複数の施設レシピで共有される。

16x16スプライトが計6個。すべてインベントリアイコン（地図上には直接配置しない素材）。

- インベントリアイコン
  - [ ] 157 **木製歯車（wooden_gear）** 16x16
    - 板から削り出した小さな木製の歯車。円盤の外周に台形の歯が等間隔に並ぶ。明るい茶色の木材で、中央に軸穴がある。真上から見た形（円盤）。歯数は8〜12枚程度の素朴な作り。
      - 平歯車（spur gear）の素朴な形を想定。歯はノミで彫り出した感じ。
  - [ ] 158 **ベベルギア（bevel_gear）** 16x16
    - 円錐台状の傘歯車。シャフトの直角方向への動力伝達に使う。明るい茶色の木材。真上から見たときは円盤に見えるが、外周の歯が斜め（円錐側面に沿う向き）に走っているのが特徴。157の平歯車と区別がつくよう、外周の歯を斜線パターンで表現する。
    - 参考動画: https://www.youtube.com/watch?v=oNuhr3htNWs - 木製ベベルギアの動作
    - 参考: [Bevel gear (Wikipedia)](https://en.wikipedia.org/wiki/Bevel_gear)

    - 板を組み合わせて作った大型の木製車輪（リム + スポーク + ハブ）。明るい茶色〜赤茶色の木材。スポークは4〜6本程度。中央のハブに軸穴がある。真上から見た形（円盤）だが、157の歯車と区別するためスポーク構造を強調する。

  - [ ] 162 **鉄の歯（iron_teeth）** 16x16

    - 用途: ドラム（160）の外周に植え込まれる脱穀用の歯。doc/09 の脱穀機（154）の説明にある「回転するドラムに金属の歯のようなものが多数ついている」の歯部分。
