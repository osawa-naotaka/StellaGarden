## アイコンと地図上のエンティティスプライト

基本は16px x 16pxのトップビューで作る。
pngフォーマットで、RGBA8888。
背景透過。サイズ記載のないものは 16x16。
各ファイルにはid番号を振ってある。そのidを使ってss_sprite_xxx.pngという形式のファイル名で作成。

## 土地

地図上のエンティティスプライトは並べて使った時に違和感がないように、連続した絵になるように上下左右端を作成する。

- インベントリのアイコン
  - [x] 046 土の塊
    - 不規則な形の土の塊。中程度の茶色。
- 地図上のエンティティスプライト
  - 雑草地（ありものを使うので新たには作らない）
  - [x] 047 荒地（収穫直後など）
    - 草も作物もない剥き出しの土。中程度の茶色で均一な面。
  - [x] 048 耕作地（耕され、畝立てされている土地）
    - 畝の畝（うね）と畝間（うねま）が交互に並ぶ横縞模様。明るい茶色〜赤茶色。中央に畝が横1列、その上下に畝間の半分が横一列ずつ。
  - [x] 049 水やりされた耕作地
    - 耕作地ベースに、畝間（溝部分）に水が少し溜まっているイメージ。土全体がやや濃い色になり湿っぽい質感。
  - [x] 050 肥料を撒いた土（緑肥漉き込み後の土も同スプライト）
    - 耕作地のスプライトの上に乗せて使う。白い斑点が散っている耕作地。白い斑点のみを描き、その他は背景として透過にする。
  - [x] 051 連作障害が発生した土地
    - くすんだ黄土色〜灰茶色のベース。病斑を示す濃い茶色や黒の斑点模様が全体に広がっている。健全な土地より暗く不健康な印象。

## 施設（地図上エンティティスプライトとアイコン）

施設はすべてフィールドに配置するオブジェクト。ざる / 選別台はFS対象外のため省略。
アイコンは全て16px x 16pxにする。フィールドに置いた時の施設の大きさが下記に示されたものになる。

| 施設 | サイズ（px） | タイル数 | 段階数 | 用途 |
|------|------------|---------|--------|------|
| 焚き火 | 16x16 | 1x1 | 1 | 木材 → 草木灰 |
| 炉 | 16x16 | 1x1 | 1 | 隕鉄を木炭で加熱し鍛造する |
| 炭焼き窯 | 16x16 | 1x1 | 1 | 使い捨て。丸太×8+茎×2+土×2 → 木炭×4（窯は消滅） |
| 石の金床 | 16x16 | 1x1 | 1 | 加熱した金属を叩いて成形する台 |
| 堆肥場 | 32x32 | 2x2 | 3（熟成段階） | 有機物 → 堆肥 |
| 脱穀機 | 32x16 | 2x1（横長） | 1 | 茎付き大豆 → 大豆 + 茎 |
| 搾油機 | 32x32 | 2x2 | 1 | 大豆 / 亜麻の種 → 油 + 油粕 |
| 浸漬槽 | 48x16 | 3x1（横長） | 1 | 亜麻のレッティング。水場付近に設置 |
| 叩き台 | 16x16 | 1x1 | 1 | 浸漬済み亜麻 → 亜麻の繊維 + 作物残渣 |
| 紡ぎ車 | 32x16 | 2x1 | 1 | 亜麻の繊維 → 糸 |
| 織機 | 32x32 | 2x2 | 1 | 亜麻糸 → リネン布 / 亜麻の袋 |

### 各施設の描画メモ

- [x] 052 **炉**（16x16）
  - 粘土製の壺型〜ドーム型の小型炉。中央上部に開口部（火口）があり、炎が見えている。粘土の送風管（吹子）で空気を送り込む構造。中央アジアの伝統的な鍛冶炉に近いイメージ。木炭を燃料にして隕鉄を加熱・鍛造する。
  - 参考: [File:Bukhara,_forge.jpg (Wikimedia Commons)](https://commons.wikimedia.org/wiki/File:Bukhara,_forge.jpg)
  - 炉は32x32にしたくなったため、052はアイコンとして使う

- [x] 053 **堆肥場**（32x32、3段階スプライト）
  - 木製の四角い枠（コンポストボックス）。段階に応じて内容物が変化:
    - 段階1（投入直後）: 緑〜黄緑色の有機物（草や葉）が積まれている
    - 段階2（発酵中）: 茶色に変色し、少し湯気が出ているイメージ
    - 段階3（熟成完了）: 黒〜濃い茶色の均一な堆肥が詰まっている
  - 参考: [Category:Compost bins (Wikimedia Commons)](https://commons.wikimedia.org/wiki/Category:Compost_bins)

- [x] 054 **脱穀機**（32x16・横長）
  - 千歯扱き（せんばこき）をモデルにした手動式。丸太の台座に硬木の歯（くし状）が横一列に並んでいる。大豆の茎を歯にあてがって引き抜くことで莢が外れる仕組み。歴史的にも初期の千歯扱きは竹歯であり、金属不要。
  - 参考: [千歯扱き (Wikipedia)](https://ja.wikipedia.org/wiki/%E5%8D%83%E6%AD%AF%E6%89%B1%E3%81%8D)
  - 画像資料

      - このアングルで描いてください。台座のところはこの画像よりも小さく、上の歯のところはおおきくして描いてください。
    - 一応、類似資料です。
      - https://ja.wikipedia.org/wiki/%E5%8D%83%E6%AD%AF%E6%89%B1%E3%81%8D#/media/%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB:Japanese_old_threshing_machine,Senba-koki,Katori-city,Japan.JPG

- [x] 055 **搾油機**（32x32）
  - 木製の縦型スクリュープレス機。太い木の柱に螺旋状のネジが通っており、上から押し付けて素材から油を搾り出す。中世ヨーロッパの亜麻仁油・オリーブ油搾油機のイメージ。
  - 参考: [Category:Oil presses (Wikimedia Commons)](https://commons.wikimedia.org/wiki/Category:Oil_presses)
  - 参考: [Category:Screw presses (Wikimedia Commons)](https://commons.wikimedia.org/wiki/Category:Screw_presses)

- [x] 056 **浸漬槽**（48x16・横長）
  - 長方形の木製の水槽。水が満たされており、亜麻の束が水平に漬けられている。水面は青みがかった色。水場（川・池）の近くに設置されるイメージ。

- [x] 057 **叩き台**（16x16）
