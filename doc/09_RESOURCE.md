## アイコンと地図上のエンティティスプライト

基本は16px x 16pxのトップビューで作る。
pngフォーマットで、RGBA8888。
背景透過。

- 道具
  - [ ] くわ（インベントリのアイコンのみ）
    - じょうろ、鎌、ピッケル、斧、シャベルはありものを使うので新たには作らない
  - [ ] 手アイコン(インベントリのアイコンのみ)
  - [ ] 作業台(インベントリ)
  - [ ] 作業台（地図上のエンティティスプライト）
    - 作業台のエンティティスプライトは32x16の横長で作る
