# Stella Garden - ゲーム設定資料

## 1. 世界観・背景ストーリー

### 1.1 時代設定
遠い未来、人類は宇宙への開発拠点を広げている。地球の資源枯渇が深刻化し、各国の企業が競って惑星開拓に乗り出していた。日本のとある商社も「惑星開拓課」を設立し、新たな資源の確保を目指している。

### 1.2 主人公とその使命
主人公は惑星開拓課の社員であり、後輩の女性社員とともにある辺境惑星への調査・開拓任務を命じられた。この惑星は資源の有無すら未調査で、会社からの期待値は低い。そのため、割り当てられた予算は最低限であり、限られたリソースでの自給自足と資源開発が求められる。

### 1.3 ゲームの目的
プレイヤー（主人公）の目的は以下の通り：
1. **惑星での自給自足基盤を確立する** - 地球からの支援に頼らず、生活できる状態を作る
2. **資源を開発し、地球へ送る** - 開発した資源を地球に送ることで会社での評価を高める
3. **惑星を発展させる** - 入植者を受け入れられる街を作り、持続可能な開拓地にする

**評価システム:**
- 地球に資源を送る → 評価が**上がる**
- 地球に支援物資を要求する → 評価が**下がる**
- ロボットや道具の追加貸与を受ける → 評価が**下がる**
- 緊急食糧支援を要求する → 評価が**大きく下がる**（運搬費用が莫大）

評価が上がることで、より多くのロボットの貸与枠が得られ、開発を加速できる。

## 2. ゲームシステム

### 2.1 ロボットシステム

#### 2.1.1 ロボットの基本仕様
- **外見**: 女性型のヒューマノイドロボット
- **動力**: 電気（拠点の太陽電池で充電）
- **メンテナンス**: 基本的にメンテナンスフリー
- **貸与**: 会社から貸与される。評価が上がるごとに貸与枠が増える

#### 2.1.2 ロボットへの命令システム
ロボット（単体または群）に対して、複数の作業命令を与えることができる。

**命令の特徴:**
- 複数の命令をキューに登録できる
- 命令には依存関係があり、先行タスクが完了してから次のタスクに取りかかる
- スケジューリングはASAP（As Soon As Possible）方式
- アロケーション（どのロボットにどの仕事を割り当てるか）は自動最適化
  - 将来的にILP（整数線形計画法）のようなアルゴリズムを使用する可能性あり

**命令の例:**
- 「この範囲の木を伐採する」
- 「伐採後、この場所に畑を作る」
- 「畑ができたら、小麦の種を植える」

#### 2.1.3 ロボットの動作
- ロボットはゆっくりと作業を進める（チルな雰囲気を演出）
- プレイヤーがログアウトしている間も作業を継続する（放置ゲーム要素）
- 作業の進捗状況は視覚的に確認できる

### 2.2 主人公による直接作業

#### 2.2.1 基本操作
主人公自身も道具を使って直接開拓・開発を行える。

**操作方法（未確定）:**
- 道具を選択 → 対象ブロック/エリアをクリック
- クリック連打 or 長押しで作業実行
- 作業の種類に応じて適切な道具を使い分ける

**作業の例:**
1. **シャベル** で整地
2. **鍬** で土地を耕す
3. **種** を植える
4. **じょうろ** で水をかける
5. **鎌** で収穫

#### 2.2.2 自動化ツールの導入
初期段階から、ある程度の自動化ツールを使用できる可能性あり。例えば：
- 自動散水装置
- 自動収穫機
- 簡易運搬ロボット

ただし、これらの貸与も評価に影響する。

### 2.3 資源と生産

#### 2.3.1 一次産業（初期フェーズ）

**農業（最優先）:**
- **目的**: 地球から独立した食糧生産基盤の確立
- **持参した種**: 小麦、米、各種野菜
- **作業**: 耕作、植え付け、水やり、収穫

**牧畜:**
- **持参した家畜**: 牛、豚、鶏（それぞれ数つがい）
- **目的**: 肉、卵、乳製品の自給
- **作業**: 飼育、繁殖管理、収穫

**林業:**
- 木材の伐採と植林
- 建材や燃料の確保

**惑星固有の生物資源:**
- その惑星特有の動物・植物も存在
- 一部は農耕・牧畜に利用可能
- 地球に送る新規資源としても価値がある

#### 2.3.2 鉱業（中期フェーズ）

**探索システム:**
生活基盤が整った後、鉱物資源の探索に移行する。

**探索方法（検討中）:**
1. **ロボットによる探索**: 主人公が指定した領域を自動的に探索
2. **主人公による探索**:
   - マインクラフト方式（3D掘削）
   - テラリア方式（2D横スクロール）
   - より簡易的な抽象化された探索システム
   - **現時点では未確定**

**鉱物資源の種類:**
- 鉄鉱石、銅鉱石、金、銀
- レアメタル、宝石類
- 惑星固有の鉱物

#### 2.3.3 二次産業（後期フェーズ）

**製造・加工:**
大規模開発には、現地でのロボットや道具の生産が必要になる。

**生産の仕組み:**
- 主人公は既にレシピ（設計図）を所有している
- 必要な資源を集め、開発道具を使って組み立てる
- 例: ロボット、高度な自動化装置、建築資材

**生産可能なもの:**
- 追加のロボット
- 高度な農業機械
- 採掘装置
- 精錬施設
- 建築物・インフラ

#### 2.3.4 三次産業（発展フェーズ）

**観光業:**
鉱物資源が乏しい惑星でも、美しい景観や特有の生態系を活かした観光開発が可能。

**街づくり:**
- 入植者のための住居、職場を建設
- インフラ整備（道路、電力網、水道）
- 商業施設、娯楽施設の建設

### 2.4 流通・輸送システム

#### 2.4.1 惑星→地球の輸送
- 開発した資源量に応じて、会社が自動的にトランスポーターを設置
- 主人公の報告により自動処理される
- 流通の滞りは発生しない（プレイヤーは気にしなくてよい）

#### 2.4.2 惑星内の流通
- **プレイヤーが管理する必要がある**
- 資源の保管、運搬、配分を計画する
- ロボットに運搬命令を出す
- （将来的に）自動運搬システムの構築

#### 2.4.3 地球→惑星の支援物資
- 緊急時や開発加速のため、地球に物資を要求できる
- ただし、要求するたびに評価が下がる
- 緊急食糧支援は特に評価への影響が大きい

## 3. ゲームの進行フロー

### Phase 1: 生存基盤の確立（序盤）
1. 惑星に降り立つ
2. 後輩とともに拠点を設営
3. 初期ロボットを起動
4. 農業・牧畜を開始し、食糧を自給
5. 簡易的な住居と設備を建設

**目標**: 地球からの支援なしで生活できる状態を作る

### Phase 2: 資源探索と開発（中盤）
1. 生活が安定したら、鉱物資源の探索を開始
2. 有望な鉱床を発見
3. 採掘・精錬設備を建設
4. 資源を地球に送り始める
5. 評価が上がり、ロボット貸与枠が増える

**目標**: 安定した資源供給ラインを確立する

### Phase 3: 産業の多角化と発展（後半）
1. 二次産業（製造業）を立ち上げる
2. 現地でロボットや道具を生産
3. （鉱物が乏しい場合）観光業や特産品開発
4. 入植者を受け入れる準備
5. 街づくりと社会インフラの整備

**目標**: 持続可能で自立した惑星コロニーを作る

### Phase 4: 完全自立と繁栄（エンドゲーム）
1. 大規模な入植地が完成
2. 多様な産業が稼働
3. 地球への主要な資源供給拠点となる
4. 会社での評価が最高レベルに達する
5. （可能なら）新しい惑星の開拓へ

**目標**: 惑星開拓のモデルケースとなる

## 4. ゲームの特徴・魅力

### 4.1 チルで癒される体験
- ロボットがゆっくりと作業する様子を眺める
- 放置している間も開発が進む安心感
- 無理なく自分のペースで楽しめる

### 4.2 戦略性と自動化の楽しさ
- ロボットへの命令を計画的に組み立てる
- 限られたリソースで効率的に開発する
- 自動化が進むにつれて加速する成長の実感

### 4.3 キャラクターとの絆
- 後輩の女性社員と一緒に困難を乗り越える
- ロボットたちが働く姿に愛着が湧く
- 孤独な惑星で、仲間との絆を感じる

### 4.4 探索と発見のワクワク感
- 未知の惑星の生態系を発見
- 鉱物資源を探し当てる達成感
- 自分だけの惑星を創り上げる喜び

### 4.5 長期的なやりこみ要素
- 評価システムによる段階的な成長
- 多様な産業の組み合わせ
- 効率化の追求
- 美しい景観づくり

## 6. 開発上の留意点

### 6.1 スモールスタート原則
- まずは最小限の機能（農業、基本的なロボット命令、簡単な資源管理）から実装
- 遊びながら必要な要素を追加していく
- 完璧を目指さず、楽しさを優先

### 6.2 チルな雰囲気の維持
- 急かされない、プレッシャーのないゲームデザイン
- 失敗してもやり直しが効くシステム
- ポジティブなフィードバックを重視

### 6.3 開発者のメンタルケア
- 無理のないペースで開発を進める
- できなかった週があっても問題なし
- 自分が楽しめることを最優先

## 7. ゲーム内用語集

| 用語 | 説明 |
|------|------|
| **惑星開拓課** | 主人公が所属する商社の部署 |
| **評価** | 主人公の会社での評価。資源を送ると上がり、支援を要求すると下がる |
| **トランスポーター** | 惑星と地球を結ぶ物資輸送装置。会社が自動設置 |
| **女性型ロボット** | 開拓作業を行う人型ロボット。会社から貸与される |
| **貸与枠** | 使用できるロボットの上限数。評価が上がると増える |
| **ASAP スケジューリング** | できるだけ早く完了するよう作業順を最適化する仕組み |
| **一次産業** | 農業、林業、鉱業など、自然から資源を得る産業 |
| **二次産業** | 製造業。資源を加工して道具や製品を作る産業 |
| **三次産業** | サービス業。観光、商業など |
| **惑星固有種** | その惑星にしか存在しない動植物 |
