# 灌漑システム設計

## 1. 設計方針

### 1.1 背景

- 現在実装されているのは、じょうろを使った手動での水やりのみ
- 毎日の水やりは手間が大きく、栽培面積が広がると管理が破綻する
- 自動化の段階を「手動→半自動→全自動」に設計し、各段階にそれぞれ楽しさを持たせたい
- Factorioのように、段階的な自動化がプレイヤーの成長体験を生むことを目指す

### 1.2 基本原則

- doc/10_RIVER.md の水システム（水面＝海面方式）と整合すること
- doc/04_FEASIBILITY_STUDY.md の自動化設計（水車・歯車・カム等）と接続すること
- 水のシミュレーション（水量計算・フラッドフィル等）は行わない
- 灌漑の制御には「水門の開閉」という物理的操作を基本とする

## 2. 水の挙動の拡張

### 2.1 現在の水の挙動

- 地形生成時: `h < horizonHeight` のタイルに水を配置
- ゲーム中: 掘った結果 `h < horizonHeight` かつ **隣接タイルに水がある** 場合に水になる
- 山中で水平線以下まで掘っても、水に隣接していなければ水は出ない

### 2.2 水源と流水の区別（新規）

水タイルを2種類に区別する:

| 種別 | テレインタイプ | 生成タイミング | 性質 |
|---|---|---|---|
| 水源 (waterSource) | `TERRAIN_TYPES.waterSource` | 地形生成時のみ | 永続。BFSの起点。埋めると不可逆に消滅 |
| 流水 (flowedWater) | `TERRAIN_TYPES.flowedWater` | プレイヤーが掘った時 | 水源からBFSで到達可能な場合のみ存在 |

**水源の破壊:**

- プレイヤーが水源タイルを土で埋めると、その水源は不可逆に消滅する
- 水源消滅時、関連する流水タイルを全水源から再計算（BFS）し、到達不能になったタイルの水を除去する
- 水源を埋める操作は稀なため、再計算のコストは問題にならない

### 2.3 素掘り水路と石組み水路

導水路に2つの段階を設ける:

| 種類 | コスト | 効果 | フレーバー |
|---|---|---|---|
| 素掘り水路 | 無料（掘るだけ） | 水は流れるが、**水源からBFS距離N（3〜5マス程度）で浸透して消える** | 土の溝に水を流すと地面に染み込む |
| 石組み導水路（レンガ導水路） | 粘土→焼きレンガが必要 | 水源からの**距離制限なし**で水が流れる | 石やレンガで固めれば漏水しない |

**設計意図:**

- 「掘れば水が流れる」という直感は維持する
- 序盤は素掘りで川のすぐ隣に小さな畑を作れる（短い距離なら素掘りで十分）
- 大規模灌漑には石組み導水路が必要 → リソース投資が必要になる
- 水量シミュレーション不要。水源からのBFS距離でカウントするだけ
- 制約の理由が物理的に納得できる（土に染み込む vs 防水された水路）

## 3. 灌漑の段階

### 3.1 段階一覧

| フェーズ | 灌漑方法 | プレイヤーの手間 | 必要な設備 |
|---|---|---|---|
| 序盤① | じょうろで手動水やり（現在実装済み） | 毎日、1マスずつ | じょうろ |
| 序盤② | 川沿いに素掘り水路を掘り、水門で手動開閉 | 毎日、水門を開け閉め | 素掘り水路 + 水門 |
| 中盤① | 石組み導水路 + 畝間パイプで散水範囲拡大 | 毎日、水門を開け閉め（範囲は広い） | 焼きレンガ導水路 + パイプ |
| 中盤② | 水車＋カムで水門を自動開閉（doc/04の仕組み） | 設置のみ、あとは放置 | 水車 + 歯車 + カム |
| 後半 | ノーリアで高台にも揚水、大規模灌漑 | 設計のみ | ノーリア + 導水路 + 自動水門 |

### 3.2 序盤①: じょうろ（現在実装済み）

- 手動で1マスずつ水やり
- 最も手間がかかるが、最初はこれしかない
- 栽培面積が広がるほど負担が増え、自動化への動機になる

### 3.3 序盤②: 水門の手動開閉

- 川から素掘り水路を掘り、水門エンティティを設置する
- 水門を開く → 水路に水が流れ、隣接する畑に水が供給される
- 水門を閉じる → 水が止まる
- **じょうろより明確に楽**（畑全体に一括で水やりできる）
- **でも完全放置はできない**（毎日開け閉めが必要）
- **次の自動化へのモチベーションになる**（「この開け閉めも自動化したい！」）

### 3.4 中盤①: 石組み導水路 + 散水パイプ

#### 導水路

- 焼きレンガで作った石組み導水路は距離制限なく水を運べる
- 川から離れた場所にも大規模な畑を作れるようになる

#### 散水パイプ（畝間水路）

- 導水路から分岐して畑の中に設置する細い水路
- パイプの伸びる方向と**直角方向にnブロック**（n=3程度）まで水が供給される
- 6マスごとに1本のパイプで済むため、畑面積のロスは約14%
- 実際の畝間灌漑（furrow irrigation）に近い感覚

```
イメージ:
  水水水水水水水水水  ← 導水路（水源からの水）
  　　　↓
  　[パイプ/畝間水路]  ← 導水路から分岐、地面に設置
  　畑畑畑畑畑畑畑畑  ← パイプの左右nマスに水供給
  　畑畑畑畑畑畑畑畑
  　畑畑畑畑畑畑畑畑
  　[パイプ/畝間水路]  ← もう一本
  　畑畑畑畑畑畑畑畑
  　畑畑畑畑畑畑畑畑
  　畑畑畑畑畑畑畑畑
```

### 3.5 中盤②: 水車＋カムによる水門自動開閉

- doc/04_FEASIBILITY_STUDY.md のカム＋カウンター機構を使用
- 水車の回転力で水門を定期的に開閉する
- 設置すれば完全に自動化され、プレイヤーの介入は不要
- 「設計して組み上げる楽しさ」がここにある

### 3.6 後半: ノーリアによる揚水

- doc/10_RIVER.md のノーリア設計に準拠
- 川の水を高台に汲み上げ、そこから導水路で配水
- 農地を水平線レベル以外にも拡張できるようになる

## 4. 水浸しロジック

### 4.1 基本ルール

- 導水路から水を供給し続けると、作物が水浸しになる
- 一日のうちn時間以上水が供給されると、作物の発育が悪化する
- 「水門を開けっ放しにすれば楽」とはならない設計

### 4.2 作物ごとの耐水性（案）

- 作物ごとに水浸し耐性を変える
- 例: 大豆は水に弱い（6時間で発育停止）、ジャガイモはそこそこ耐える（12時間）
- 畑のレイアウトを作物ごとに変える必要が生まれ、農業設計の深みが増す
- 水門の開閉タイミングを間違えると一部の作物がダメになるリスク → 自動化の動機がさらに強まる

### 4.3 水門による制御

- 水門を開く → 水が流れ、畑に水が供給される
- 適切な時間が経過したら水門を閉じる → 水が止まる
- 序盤は手動で開閉（毎朝開けて、夕方閉める、など）
- 中盤以降は水車＋カムで自動制御

## 5. リソース: 粘土と焼きレンガ

### 5.1 粘土の位置づけ

- 粘土は**汎用的な川辺リソース**として設計する
- 用途: 焼きレンガ（導水路）、防水層、その他の建材
- 川辺の土地にランダムで粘土が混在する

### 5.2 粘土の供給

- 耕していない川辺の土地に、時間経過で粘土が再生成される
- 土地を耕して畑にすると、そのタイルでは粘土は発生しない
- **川辺の土地の用途競合**:
  - 畑にする（農業用）
  - 粘土採取エリアとして残す（建材用）
  - 導水路の経路にする（水利用）
- この競合はプレイヤーの判断を生む良いリソース配分の問題

### 5.3 粘土→焼きレンガの加工

- 粘土を焼窯で焼いてレンガにする
- レンガを使って石組み導水路を設置する
- 焼窯自体は最初から作成可能（スキルツリーの制限はない、リソースの制約のみ）

### 5.4 川辺の土地のゾーニング

実際の川辺集落の土地利用に近い体験が自然に生まれる:

```
  川川川川川川川川川川川  ← 川（水源）
  粘粘畑畑畑畑畑畑粘粘  ← 一部を粘土採取用に残す
  畑畑畑畑畑畑畑畑畑畑  ← 農地
  [導水路]===[水門]===  ← 導水路と水門
  畑畑畑畑畑畑畑畑畑畑  ← 農地（導水路から灌漑）
  畑畑畑畑畑畑畑畑畑畑
```
