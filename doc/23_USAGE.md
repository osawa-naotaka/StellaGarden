# Stella Garden プレイガイド

> **このドキュメントの目的**
>
> Stella Garden を初めてプレイする人向けの手順書である。
> ゲームの目的から始まり、袋詰め大豆の安定出荷を達成するまでの流れを順に説明する。

---

## 1. ゲームの目的

Stella Garden は、未開拓惑星で農業を発展させていくチルな Factorio ライクゲームである。

プレイヤーは地球側の企業から派遣された調査担当者として惑星に降り立つ。ここでの活動は単なる生存ではなく、**「この惑星で何ができるか」を地球へ示す実証実験**でもある。じゃがいもを安定生産できる、大豆を加工して出荷できる、亜麻から繊維・布・袋を作れる——そういった実績を積み上げることが、惑星の本格投資に値することを証明する。

当面のゴールは、**新しい取引先を順次開放し、最終的に袋詰め大豆を安定的に出荷できる体制を整えること**である。

---

## 2. 基本操作

### 移動とカメラ

| 操作 | 内容 |
|---|---|
| `WASD` | プレイヤーの移動 |
| マウス移動 | カーソルの移動 |
| マウスホイール | ズームイン・ズームアウト |

### アクション

| 操作 | 内容 |
|---|---|
| 左クリック（空の手） | フィールドのインタラクト（道具なし） |
| 左クリック（道具を持った状態） | 道具を使って対象にインタラクト |
| `E` キー | インベントリの開閉 |
| `Esc` キー | キャンセル・選択解除 |

### ツールバーと道具

画面下部のツールバーにアイテムや道具を入れておくと、その道具やアイテムを使って対象にインタラクトできるようになる。

- **くわ**: 草地を耕して畑（soil）にする。四方が同じ高さ（＝平ら）な土地のみ耕せる
- **鎌**: 作物の収穫、草刈り
- **斧**: 木の伐採、施設の撤去
- **ピッケル**: 隕鉄・石の採取
- **シャベル**: 土地を削る（土を採取する）一部削れない土地がある
- **じょうろ**: 作物への水やり

### クラフトと施設配置

インベントリを開いた状態でサイドバー上部に表示されているアイテムをクリックして選択するとクラフトメニューが表示される。そのアイテムを右クリックすると実際にクラフトが行われる。
施設アイテムをツールバーに入れてから右クリックすると、フィールドに配置できる。

最初に作るべき施設は**作業台**である（素手で木材×4からクラフト可能）。

### 土地の成形

シャベルを持って左クリックすると、対象タイルの土を1段削って採取できる。  
土のアイテムを持って左クリックすると、対象タイルに土を1段盛ることができる。  
これにより、農地の造成や水路の掘削が可能になる。
土地の造成には少しルールがある。隣接した土地の高さの差が1以内になるような造成のみが可能。つまり、急な斜面は作ることができない。

## 3. じゃがいもの育て方

じゃがいもは序盤の主力作物であり、最初から出荷可能な唯一の作物である。

### 栽培手順

1. **耕す**: くわを持って草地（grass）に左クリック → 畑（soil）になる。4方が同じ高さ（＝平ら）な土地のみ畑にできる
2. **植える**: じゃがいもを持って畑に左クリック → 植え付け完了
3. **成長を待つ**: 約5ゲーム内日数（リアルタイム15分程度）で成熟する
4. **収穫する**: **鎌**を持って成熟したじゃがいもに左クリック → じゃがいもと茎が得られる

### 水やりについて

じゃがいもは**水やりなしでも育つ**。ただし、じょうろで水やりをすると収量がボーナス増加する。他の作物と違い、水切れによる枯死はない。

### 種イモの管理

収穫したじゃがいもの一部は必ず**次の植え付け用に残しておく**こと。全て出荷してしまうと次が植えられなくなる。出荷に回す量と、次の種イモとして確保する量のバランスが重要なリソース管理の基本となる。

---

## 4. 輪作について

同じ土地にじゃがいもを連続して植えると、**連作障害**により収量が大幅に低下する。2〜3回連続で植えると枯れてしまうこともある。

この問題を避けるために、**輪作**——異なる作物を交互に植えること——が必要になる。

### ひまわりを間に挟む

最も手軽な対策は、じゃがいもの間の1サイクルに**ひまわり**を植えることである。

ひまわりはじゃがいもと比べて成長が早く（約3ゲーム内日数）、連作リセッターとして最も効率が良い。

### ひまわりの栽培

1. くわで耕す
2. ひまわりの種を持って左クリックで植え付け
3. **毎日じょうろで水やりが必要**（水切れ3日で枯死するため、じゃがいもと違い水やりは必須）
4. 成熟したら鎌で収穫 → ひまわりの茎と種が得られる

収穫した種は次の植え付けに回すこと。茎は肥料の原料になる（次章参照）。

---

## 5. 肥料について

肥料を植え付け前の畑に使うと、作物の収量が大幅に向上する。化学肥料は使えない環境のため、現地の有機資源から自給する。

### 草木灰（カリウム肥料）

**じゃがいもとの相性が特に良い**肥料。以下の手順で入手する。

**原料となるもの（焚き火で燃やす）**:

| 原料 | 入手方法 | 変換率 |
|---|---|---|
| 木の幹 | 斧で木を伐採 | 幹 ×1 → 草木灰 ×1 |
| ひまわりの茎 | ひまわりを鎌で収穫 | 茎 ×5 → 草木灰 ×1 |
| じゃがいもの茎 | じゃがいもを鎌で収穫 | 茎 ×5 → 草木灰 ×1 |

焚き火は石×4を素手でクラフトして作成できる。焚き火に原料を入れると草木灰が得られる。

草木灰を持って耕地に左クリックすると施肥できる。**施肥のタイミングは植え付け前に1回のみ**。

### 堆肥

全作物に効く万能肥料だが、効果は草木灰より弱く、大量投入が必要。

堆肥場（木材×4→作業台）に有機物を投入して数日発酵させると堆肥が得られる。

**堆肥場に投入できるもの**: ひまわりの茎、じゃがいもの茎、森の落ち葉（手で拾う）、各種作物残渣など

茎を「草木灰にするか、堆肥にするか」はプレイヤーの戦略的選択になる。

### 油粕（将来入手可能）

大豆や亜麻の種を搾油機で加工したときの副産物。亜麻との相性が特に良い。搾油機の解禁後に利用できる。

## 6. 出荷について

収穫した作物は**転移ゲート**を通じて地球側に出荷する。転移ゲートは最初から所持している。

### 出荷の手順

1. インベントリ（`E`キー）を開き、転移ゲートのアイテムを選択
2. フィールドの任意の場所に右クリックで設置
3. 設置した転移ゲートを右クリックしてUIを開く
4. 「プレイヤーのインベントリ」から「地球側インベントリ」へ出荷したいアイテムを移す
5. **ゲーム内毎朝5時**に出荷が行われ、地球側インベントリにある品物に応じてスコアが加算される

### スコアについて

各品物には単価が設定されている。加工度が高いほど単価は高い。序盤はじゃがいものみがスコア対象だが、取引先がアンロックされると出荷可能な品目が増える。
アンロックされていない品目も全て出荷自体は可能なことに注意すること。アンロック前でも出荷はできるが、ポイントは1個あたり1ptと最低限のため、大きな損になってしまう。

---

## 7. 取引先のアンロック

出荷を重ねて累計スコアが上がると、新しい取引先（＝出荷できる品目）が順次開放される。一度アンロックした品目は失われない。

### アンロックの流れ

```
Tier 1: じゃがいも（最初から出荷可能）
  ↓ じゃがいもを一定量出荷
Tier 2: 大豆（生）
  ↓ 大豆を一定量出荷
Tier 3: 亜麻仁油 ＆ 大豆油（同時にアンロック）
  ↓ 亜麻仁油を一定量出荷
Tier 4: 糸
  ↓ 糸を一定量出荷
Tier 5: 布
  ↓ 布を一定量出荷
Tier 6: 袋詰めじゃがいも ＆ 袋詰め大豆（同時にアンロック）★ゴール
```

各段階で生産体制を整え、次の Tier に向けた新しい作物・施設の導入を進めていく。

## 8. 大豆の育て方

じゃがいもの出荷量が基準を超えると、大豆が出荷可能になる。

### 栽培手順

1. くわで耕す
2. 大豆の種を持って植え付け
3. **毎日じょうろで水やり**（水切れ3日で枯死）
4. 約4ゲーム内日数で成熟 → 鎌で収穫 → 茎付き大豆が得られる

### 脱穀機の作成

収穫した茎付き大豆は、そのままでは出荷できない。**脱穀機**でさやから豆をはずす必要がある。

**脱穀機のクラフトレシピ**:

| 手順 | 必要なもの | 結果 |
|---|---|---|
| 準備 | 木材 ×1 → 作業台 | 硬木の歯 ×1 |
| 本体 | 木材 ×2 ＋ 硬木の歯 ×1 → 作業台 | 脱穀機 |

脱穀機を設置して茎付き大豆を入れると、大豆と茎に分離される。

脱穀後の大豆を転移ゲートへ移して出荷すると評価が上がり、次の Tier 3（亜麻仁油・大豆油）のアンロックに近づく。

---

## 9. 鉄製道具の製作

亜麻仁油や搾油機の製作には、金属加工が必要になる。

### 必要な素材と入手方法

| 素材 | 入手方法 |
|---|---|
| 隕鉄 | フィールドに点在する隕鉄をピッケルで採取（有限資源） |
| 粘土 | 川沿いの粘土タイルをシャベルで採取 |
| 石 | フィールドに点在する石をピッケルで採取 |
| 木炭 | 炭焼き窯で木材から生産 |

### 製作手順

#### ① 炭焼き窯で木炭を作る

```
木材 ×12 ＋ 茎 ×2 ＋ 土 ×2 → 素手で作成 → 炭焼き窯（使い捨て）
炭焼き窯をフィールドに配置 → 数日で火が消え、木炭ができる（シャベルで回収）
```

炭焼き窯は使い捨てで、完成後に土が回収される。木炭は高温燃料であり、炉での鍛造に必須。

#### ② 炉を作る

```
粘土 ×8 ＋ 石 ×4 → 素手で作成 → 炉
```

炉は専用UIを持つ施設。原材料スロット・燃料スロット・結果スロットがある。

#### ③ 石の金床を作る

```
石 ×4 → 作業台 → 石の金床
```

#### ④ 鍛造して刃を得る

1. 炉をフィールドに配置し、右クリックすることで、炉UIを開く
2. 原材料スロットに**隕鉄**を入れる
3. 燃料スロットに**木炭**を入れる
4. 数ゲーム内日数で**赤熱した隕鉄**が生成される
5. 結果スロットから回収する
6. **石の金床に赤熱した隕鉄を左クリック**してインタラクト → **刃**が得られる

#### ⑤ 刃から各種道具を作る

```
刃 ×1 ＋ 木材 ×1 → 作業台 → 鉄のくわ / 鎌 / 斧 / シャベル / ピッケル / ノミ / 割り刃
```

## 10. 搾油機の製作と油の生産

鉄製道具が揃ったら、搾油機を作って油を生産できるようになる。

### のみと割り刃の役割

**のみ**と**割り刃**は特別な道具で、**作業台のツール指定欄**に入れることで、これらが必要なレシピが解禁される。

- **割り刃**: 木材を板に加工する（`木材 → 作業台 ＋ 割り刃 → 板`）
- **のみ**: 木ネジ棒・車軸・木枠を加工する（`木材 → 作業台 ＋ のみ → 木ネジ棒`など）

### 搾油機のクラフト

```
木ネジ棒 ×1（のみを使って作業台で加工）
板 ×4（割り刃を使って作業台で加工）
→ 作業台 → 搾油機
```

### 搾油機の使い方

搾油機に以下の原料を入れると、油と油粕が得られる。

| 原料 | 産出物 |
|---|---|
| 大豆 | 大豆油 ＋ 油粕 |
| 亜麻の種 | 亜麻仁油 ＋ 油粕 |

大豆油・亜麻仁油はともに Tier 3 でアンロックされる出荷品。亜麻仁油の出荷を重ねると Tier 4（糸）がアンロックされる。

## 11. 灌漑（畝間水路）

じょうろによる手動水やりは最初の手段だが、農地が広がると毎日の水やりが大きな手間になる。**畝間水路**を使えば、自動的に毎朝作物に水を供給できる。

### 畝間水路の作成

割り刃を使って板を作り、板から畝間水路を作成する。

### 畝間水路の仕組み

1. 畝間水路の一部が**水タイル（川・水面）に隣接**していると水が供給される
2. 隣接点から**最大16マス**まで水が伝播する
3. 畝間水路の**伸びる方向と直交する方向に3マス**の耕地（soil）へ毎朝水が供給される

```
例: 横向きの畝間水路を川沿いに設置した場合

  川川川川川川川川川川川
        ↓
  [畝間水路→→→→→→→→]   ← 横向き（川に隣接）
  畑畑畑畑畑畑畑畑畑畑   ↕ 上下3マスに毎朝散水
  畑畑畑畑畑畑畑畑畑畑   ↕
  畑畑畑畑畑畑畑畑畑畑   ↕
```

### 畝間水路の向きと散水方向

畝間水路には**横向き**と**縦向き**があり、設置時に選択する。

| 向き | 散水方向 |
|---|---|
| 横向き | 上下3マス |
| 縦向き | 左右3マス |

L字・T字・十字の接続部分は水を導くだけで散水しない。直線・端末部分のみが散水する。

## 12. 亜麻の糸と布

亜麻仁油（Tier 3a）のアンロック後、亜麻を本格的に育て始めることで、糸・布へのサプライチェーンが開ける。

### 亜麻の栽培

1. くわで耕す
2. 亜麻の種を持って植え付け
3. **毎日じょうろで水やり**（水切れ3日で枯死）
4. 約7ゲーム内日数で成熟 → 鎌で収穫 → **亜麻の茎**と**亜麻の種**が得られる

収穫した種の一部は次の植え付けに残すこと。茎は繊維加工ラインへ回す。

> **亜麻の茎は焚き火で燃やせない**。茎は繊維採取の必須原料であるため、草木灰の原料にはできない（他の作物の茎と異なる点）。

### 繊維の加工手順

亜麻の茎から糸・布を作るには複数の工程が必要になる。各施設は**板**（割り刃が必要）から作成できる。

| 手順 | 施設 | 投入 | 産出 |
|---|---|---|---|
| ① レッティング | 浸漬槽（板×8＋粘土×2→作業台） | 亜麻の茎 | 浸漬済み亜麻（数日かかる） |
| ② 繊維分離 | 叩き台（木材×1→作業台＋割り刃） | 浸漬済み亜麻 | 亜麻繊維 |
| ③ 紡績 | 紡ぎ車（板×2＋車軸×1→作業台） | 亜麻繊維 | 亜麻糸 |
| ④ 製布 | 織機（板×4＋木枠×2→作業台） | 亜麻糸 | 布 / 亜麻の袋 |

糸（Tier 4）・布（Tier 5）の順にアンロックされるため、先に糸を出荷してから布を目指す流れになる。

---

## 13. 袋詰め大豆（当面のゴール）

布（Tier 5）を一定量出荷すると、**袋詰めじゃがいも**と**袋詰め大豆**が同時にアンロックされる。

### 袋の作成

織機で亜麻糸を使って**亜麻の袋**を作成する。

### 袋詰め大豆の作成

```
大豆 ×64 ＋ 亜麻の袋 ×1 → 作業台 → 袋詰め大豆 ×1
```

袋詰め大豆は現時点で最も高単価の出荷品（じゃがいもの50倍のスコア）。これを安定出荷できる状態にすることが当面のゴールになる。

### 袋詰め大豆が意味するもの

袋詰め大豆を生産するには、以下の**全てのラインが稼働している**必要がある。

- 大豆ライン: 栽培 → 脱穀
- 亜麻ライン: 栽培 → レッティング → 繊維分離 → 紡績 → 製袋
- 肥料ライン: 堆肥・草木灰・油粕の循環
- 灌漑ライン: 大豆・亜麻への安定した水やり

袋詰め大豆の安定出荷は、この惑星上で完全なサプライチェーンが回っていることの証明になる。
