# Stella Garden プレイガイド

> **このドキュメントの目的**
>
> Stella Garden を初めてプレイする人向けの手順書である。
> ゲームの目的から始まり、袋詰め大豆の安定出荷を達成するまでの流れを順に説明する。

---

## 1. ゲームの目的

Stella Garden は、未開拓惑星で農業を発展させていくチルな Factorio ライクゲームである。

プレイヤーは地球側の企業から派遣された調査担当者として惑星に降り立つ。ここでの活動は単なる生存ではなく、**「この惑星で何ができるか」を地球へ示す実証実験**でもある。じゃがいもを安定生産できる、大豆を加工して出荷できる、亜麻から繊維・布・袋を作れる——そういった実績を積み上げることが、惑星の本格投資に値することを証明する。

当面のゴールは、**新しい取引先を順次開放し、袋詰め大豆を安定的に出荷できる体制を整えること**である。これは完全なサプライチェーンが回ったことの証明となる第一の集大成である。

その先には、加工・物流・農作業を**水車動力と台車で自動化**して生産を拡大する道（§14〜§16）と、塩・麦・麹から味噌・醤油・酒・酢を生み出す**第3の生産軸＝発酵**（§17）が広がっている。最高級品である醤油の安定出荷が、現時点での最終的な到達点となる。

## 2. 基本操作

### 移動とカメラ

| 操作 | 内容 |
|---|---|
| `WASD` | プレイヤーの移動 |
| マウス移動 | カーソルの移動 |
| マウスホイール | ズームイン・ズームアウト |

### アクション

| 操作 | 内容 |
|---|---|
| 左クリック（空の手） | フィールドのインタラクト（道具なし） |
| 左ホールド（道具を持った状態） | 道具を使って対象にインタラクト |
| 右クリック | クリックした施設のUI(サイドバー)を開く |
| `E` キー | インベントリの開閉 |
| `Esc` キー | キャンセル・選択解除 |

### インベントリ

| 操作 | 内容 |
|---|---|
| 左クリック（スロット） | スロットのアイテムを持ち上げ・別スロットに配置・同一スタックに統合 |
| 右クリック(配置可能な施設) | 施設をフィールド上に配置するモードに入る |

### 施設サイドバー

| 操作 | 内容 |
|---|---|
| 左クリック（スロット） | スロットのアイテムを持ち上げ・配置 |
| Ctrl + 右クリック | クリックしたアイテムと同種のアイテムを全て、その逆側のインベントリへ移動する |

### ツールバーと道具

画面下部のツールバーにアイテムや道具を入れておくと、その道具やアイテムを使って対象にインタラクトできるようになる。

- **くわ**: 草地を耕して畑（soil）にする。四方が同じ高さ（＝平ら）な土地のみ耕せる
- **鎌**: 作物の収穫、草刈り
- **斧**: 木の伐採、施設の撤去
- **ピッケル**: 隕鉄・石の採取
- **シャベル**: 土地を削る（土を採取する）一部削れない土地がある
- **じょうろ**: 作物への水やり
- **大豆、じゃがいも、亜麻の種**: 作物を植え付けする

### クラフトと施設配置

インベントリを開いた状態でサイドバー上部に表示されているアイテムをクリックして選択するとクラフトメニューが表示される。そのアイテムを右クリックすると実際にクラフトが行われる。
クラフトしたアイテムはインベントリに追加される。

クラフトしたアイテムのうち、一部のアイテムはフィールド上にエンティティとして配置できる。このような施設アイテムを配置するには、インベントリ上のアイコンを右クリックする。
そうすると、施設配置モードに入り、フィールド上をクリックすることで任意の場所へ配置することができる。
施設は平らな場所にしか配置できない。

最初に作るべき施設は**作業台**である（素手で木材×4からクラフト可能）。

### 施設のサイドバーUI

ほとんどの施設は、フィールド上で**右クリック**すると画面右側からサイドバーUIがスライドインする。
このUIを通じて、施設にアイテムを投入したり、出来上がった成果物を取り出したりする。

施設のUIには2つのタイプがある。

#### タイプA: 手動処理型（押し続けて加工）

対象施設: **脱穀機 / 搾油機 / 叩き台 / 紡ぎ車 / 織機 / 金床**

- **入力スロット**にアイテムを置き、**「処理」ボタンを押し続ける**と、一定間隔で1サイクルずつ加工が進む
- ボタンを押した瞬間ではなく、ボタンの背景バーが満タンになったタイミングで初めて1サイクル分の加工が実行される
- 入力切れ・出力スロット満杯になると自動で停止する
- ボタンから指を離すと進行が止まる
- 加工結果は**出力スロット**に積まれるので、ここから自分のインベントリに移して回収する

#### タイプB: 日次処理型（仕込んで日数を待つ）

対象施設: **堆肥場 / 浸漬槽 / 焚き火 / 炭焼き窯**

- **入力スロット**にレシピが要求する数だけアイテムを入れておくと、その時点から進行日数のカウントが始まる
- ゲーム内で **毎朝5時** に1日ぶん進む
- 必要日数が経過すると、自動的に**出力スロット**に成果物が生成される
- 進行中の進捗は UI の進捗バーで確認できる
- 出力スロットが満杯の場合は、回収するまで進行が止まる

#### 共通操作

- スロット間のアイテム移動はインベントリと同じ操作（左クリックで全量、右クリックで1個）
- サイドバーが開いている間も、フィールド上で別の施設を右クリックすれば、UIが切り替わる
- `Esc` キー、または UI 左上の `×` ボタン、または別の施設の右クリックで UI を閉じる

#### 施設の回収（斧）

入出力スロットが空のときに限り、設置済みの施設は**斧でインタラクト（左クリック）するとアイテム化して回収**できる。回収した施設はインベントリに戻り、別の場所に置き直せる。

- 置き場所を間違えても、斧で回収して再配置すればよい（壊して作り直す必要はない）
- 入出力スロットに中身が残っている施設は回収できない（先に中身を取り出す）
- 台車も同様に、中身が空のときに斧で回収できる（§15 参照）

### 土地の成形

シャベルを持って左クリックすると、対象タイルの土を1段削って採取できる。  
土のアイテムを持って左クリックすると、対象タイルに土を1段盛ることができる。  
これにより、農地の造成や水路の掘削が可能になる。
土地の造成には少しルールがある。隣接した土地の高さの差が1以内になるような造成のみが可能。つまり、急な斜面は作ることができない。

## 3. じゃがいもの育て方

じゃがいもは序盤の主力作物であり、最初から出荷可能な唯一の作物である。

### 栽培手順

1. **耕す**: くわを持って草地（grass）に左クリックホールド → 畑（soil）になる。4方が同じ高さ（＝平ら）な土地のみ畑にできる
2. **植える**: じゃがいもを持って畑に左クリックホールド → 植え付け完了
3. **成長を待つ**: 約5ゲーム内日数（リアルタイム15分程度）で成熟する
4. **収穫する**: **鎌**を持って成熟したじゃがいもに左クリックホールド → じゃがいもと茎が得られる

### 水やりについて

じゃがいもは**水やりなしでも育つ**。他の作物と違い、水切れによる枯死はない。

### 種イモの管理

収穫したじゃがいもの一部は必ず**次の植え付け用に残しておく**こと。全て出荷してしまうと次が植えられなくなる。出荷に回す量と、次の種イモとして確保する量のバランスが重要なリソース管理の基本となる。

---

## 4. 輪作について

同じ土地にじゃがいもを連続して植えると、**連作障害**により収量が大幅に低下する。2〜3回連続で植えると枯れてしまうこともある。

この問題を避けるために、**輪作**——異なる作物を交互に植えること——が必要になる。

### ひまわりを間に挟む

最も手軽な対策は、じゃがいもの間の1サイクルに**ひまわり**を植えることである。

ひまわりはじゃがいもと比べて成長が早く（約3ゲーム内日数）、連作リセッターとして最も効率が良い。

### ひまわりの栽培

1. くわで耕す
2. ひまわりの種を持って左クリックホールドで植え付け
3. **毎日じょうろで水やりが必要**（水切れ3日で枯死するため、じゃがいもと違い水やりは必須）
4. 成熟したら鎌で収穫 → ひまわりの茎と種が得られる

収穫した種は次の植え付けに回すこと。茎は肥料の原料になる（次章参照）。

---

## 5. 肥料について

肥料を植え付け前の畑に使うと、作物の収量が大幅に向上する。化学肥料は使えない環境のため、現地の有機資源から自給する。

### 草木灰（カリウム肥料）

**じゃがいもとの相性が特に良い**肥料。**焚き火**で原料を1日燃やすと得られる。

焚き火は石×4を素手でクラフトして作成できる。

**焚き火のレシピ（日次処理型）**:

| 入力スロット | 出力スロット（1日後） |
|---|---|
| 木の幹 ×4 | 草木灰 ×4 |
| 茎（ひまわり / じゃがいも） ×20 | 草木灰 ×4 |

入力スロットに対応するアイテムを必要数だけ投入すると、翌朝には出力スロットに草木灰が出来上がっている。

> 茎は20個必要だが、燃焼1サイクルで一気に灰4個が得られる。

草木灰を持って耕地に左クリックすると施肥できる。**施肥のタイミングは植え付け前に1回のみ**。

### 堆肥

全作物に効く万能肥料だが、効果は草木灰より弱く、大量投入が必要。

堆肥場は木材×4 + 作業台でクラフトできる。

**堆肥場のレシピ（日次処理型）**:

| 入力スロット | 出力スロット（4日後） |
|---|---|
| 茎 ×10 | 堆肥 ×1 |
| 落ち葉 ×10 | 堆肥 ×1 |
| 作物残渣 ×10 | 堆肥 ×1 |

**堆肥場に投入できるもの**: ひまわりの茎、じゃがいもの茎、森の落ち葉（手で拾う）、各種作物残渣

茎を「草木灰にするか、堆肥にするか」はプレイヤーの戦略的選択になる。

### 油粕

大豆や亜麻の種を搾油機で加工したときの副産物。亜麻との相性が特に良い。Tier 3（搾油機解禁後）で利用できるようになる。

## 6. 出荷について

収穫した作物は**転移ゲート**を通じて地球側に出荷する。転移ゲートは最初から所持している。

### 出荷の手順

1. インベントリ（`E`キー）を開き、転移ゲートのアイテムを右クリックで選択、配置モードに入る
2. フィールドの任意の場所に左クリックで設置
3. 設置した転移ゲートを右クリックしてUIを開く
4. 「プレイヤーのインベントリ」から「地球側インベントリ」へ出荷したいアイテムを移す
5. **ゲーム内毎朝5時**に出荷が行われ、地球側インベントリにある品物に応じてスコアが加算される

### スコアについて

各品物には単価が設定されている。加工度が高いほど単価は高い。序盤はじゃがいものみがスコア対象だが、取引先がアンロックされると出荷可能な品目が増える。
アンロックされていない品目も全て出荷自体は可能なことに注意すること。アンロック前でも出荷はできるが、ポイントは1個あたり1ptと最低限のため、大きな損になってしまう。

---

## 7. 取引先のアンロック

出荷を重ねて累計スコアが上がると、新しい取引先（＝出荷できる品目）が順次開放される。一度アンロックした品目は失われない。

### アンロックの流れ

```
Tier 1: じゃがいも（最初から出荷可能）
  ↓ じゃがいもを一定量出荷
Tier 2: 大豆（生）
  ├→（繊維・包装軸）
  │   ↓ 大豆を一定量出荷
  │  Tier 3: 亜麻仁油 ＆ 大豆油（同時にアンロック）
  │   ↓ 亜麻仁油を一定量出荷
  │  Tier 4: 糸
  │   ↓ 糸を一定量出荷
  │  Tier 5: 布
  │   ↓ 布を一定量出荷
  │  Tier 6: 袋詰めじゃがいも ＆ 袋詰め大豆（同時にアンロック）★第一の集大成
  │
  └→（発酵軸 — §17）
      塩 ──→ 麹 ──→ 味噌（三軸合流）──→ 醤油（四軸合流）★最終ゴール
                  └──→ 麦焼酎（樽熟成で高品質）／酢（並行の嗜好品ライン）
```

各段階で生産体制を整え、次の Tier に向けた新しい作物・施設の導入を進めていく。
繊維・包装軸と発酵軸は大豆（Tier 2）以降に分岐し、並行して進められる。発酵軸の詳細は §17 を参照。

## 8. 大豆の育て方

じゃがいもの出荷量が基準を超えると、大豆が出荷可能になる。

### 栽培手順

1. くわで耕す
2. 大豆の種を持って植え付け
3. **毎日じょうろで水やり**（水切れ3日で枯死）
4. 約4ゲーム内日数で成熟 → 鎌で収穫 → 茎付き大豆が得られる

### 脱穀機の作成

収穫した茎付き大豆は、そのままでは出荷できない。**脱穀機**でさやから豆をはずす必要がある。

**脱穀機のクラフトレシピ**:

| 手順 | 必要なもの | 結果 |
|---|---|---|
| 準備 | 木材 ×1 → 作業台 | 硬木の歯 ×1 |
| 本体 | 木材 ×2 ＋ 硬木の歯 ×1 → 作業台 | 脱穀機 |

**脱穀機の使い方（手動処理型）**: 設置した脱穀機を右クリックでUIを開き、入力スロットに茎付き大豆を入れて「処理」ボタンを押し続ける。1個あたり大豆×1と茎×1に分離されて、それぞれ出力スロットに溜まる。

脱穀後の大豆を転移ゲートへ移して出荷すると評価が上がり、次の Tier 3（亜麻仁油・大豆油）のアンロックに近づく。

## 9. 鉄製道具の製作

亜麻仁油や搾油機の製作には、金属加工が必要になる。

### 必要な素材と入手方法

| 素材 | 入手方法 |
|---|---|
| 隕鉄 | フィールドに点在する隕鉄をピッケルで採取（有限資源） |
| 粘土 | 川沿いの粘土タイルをシャベルで採取 |
| 石 | フィールドに点在する石をピッケルで採取 |
| 木炭 | 炭焼き窯で木材から生産 |

### 製作手順

#### ① 炭焼き窯で木炭を作る

```
木材 ×4 ＋ 土 ×12 → 素手で作成 → 炭焼き窯
```

**炭焼き窯の使い方（日次処理型）**: フィールドに配置し、右クリックでUIを開く。入力スロットに**木の幹×12**を入れると、4日後に出力スロットに**木炭×4**が出来上がる。出力を取り出せば再び使えるので、何度でも繰り返し利用できる。

#### ② 炉を作る

```
粘土 ×8 ＋ 石 ×4 → 素手で作成 → 炉
```

炉は専用UIを持つ施設。原材料スロット・燃料スロット・結果スロットがある。

#### ③ 石の金床を作る

```
石 ×4 → 作業台 → 石の金床
```

#### ④ 鍛造して刃を得る

1. 炉をフィールドに配置し、右クリックすることで、炉UIを開く
2. 原材料スロットに**隕鉄**を入れる
3. 燃料スロットに**木炭**を入れる
4. ゲーム内日数で**赤熱した隕鉄**が生成される
5. 結果スロットから回収する
6. **石の金床を右クリックでUIを開く**（手動処理型）。入力スロットに**赤熱した隕鉄**を入れて「処理」ボタンを押し続けると、出力スロットに**刃**が生成される

#### ⑤ 刃から各種道具を作る

```
刃 ×1 ＋ 木材 ×1 → 作業台 → 鉄のくわ / 鎌 / 斧 / シャベル / ピッケル / ノミ / 割り刃
```

## 10. 搾油機の製作と油の生産

鉄製道具が揃ったら、搾油機を作って油を生産できるようになる。

### のみと割り刃の役割

**のみ**と**割り刃**は特別な道具で、**作業台のツール指定欄**に入れることで、これらが必要なレシピが解禁される。

- **割り刃**: 木材を板に加工する（`木材 → 作業台 ＋ 割り刃 → 板`）
- **のみ**: 木ネジ棒・車軸・木枠を加工する（`木材 → 作業台 ＋ のみ → 木ネジ棒`など）

### 搾油機のクラフト

```
木ネジ棒 ×1（のみを使って作業台で加工）
板 ×4（割り刃を使って作業台で加工）
→ 作業台 → 搾油機
```

### 搾油機の使い方（手動処理型）

搾油機を右クリックでUIを開く。入力スロットに大豆または亜麻の種を必要数入れて、「処理」ボタンを押し続けると油と油粕が得られる。

| 入力スロット | 出力スロット（メイン） | 出力スロット（副産物） |
|---|---|---|
| 大豆 ×8 | 大豆油 ×1 | 油粕 ×1 |
| 亜麻の種 ×8 | 亜麻仁油 ×1 | 油粕 ×1 |

大豆油・亜麻仁油はともに Tier 3 でアンロックされる出荷品。亜麻仁油の出荷を重ねると Tier 4（糸）がアンロックされる。

## 11. 灌漑（畝間水路）

じょうろによる手動水やりは最初の手段だが、農地が広がると毎日の水やりが大きな手間になる。**畝間水路**を使えば、自動的に毎朝作物に水を供給できる。

### 畝間水路の作成

割り刃を使って板を作り、板から畝間水路を作成する。

### 畝間水路の仕組み

1. 畝間水路の一部が**水タイル（川・水面）に隣接**していると水が供給される
2. 隣接点から**最大16マス**まで水が伝播する
3. 畝間水路の**伸びる方向と直交する方向に3マス**の耕地（soil）へ毎朝水が供給される

```
例: 横向きの畝間水路を川沿いに設置した場合

  川川川川川川川川川川川
        ↓
  [畝間水路→→→→→→→→]   ← 横向き（川に隣接）
  畑畑畑畑畑畑畑畑畑畑   ↕ 上下3マスに毎朝散水
  畑畑畑畑畑畑畑畑畑畑   ↕
  畑畑畑畑畑畑畑畑畑畑   ↕
```

### 畝間水路の向きと散水方向

畝間水路には**横向き**と**縦向き**があり、設置時に選択する。配置モード中にvキーを推すたびに、縦向きと横向きがトグルする。しかし、2個以上、水路を接続すると、自動的にその接続トポロジーに従って縦向き、横向き、L字、T字、十字の接続様式が変化する。

| 向き | 散水方向 |
|---|---|
| 横向き | 上下3マス |
| 縦向き | 左右3マス |

L字・T字・十字の接続部分は水を導くだけで散水しない。直線・端末部分のみが散水する。

## 12. 亜麻の糸と布

亜麻仁油（Tier 3a）のアンロック後、亜麻を本格的に育て始めることで、糸・布へのサプライチェーンが開ける。

### 亜麻の栽培

1. くわで耕す
2. 亜麻の種を持って植え付け
3. **毎日じょうろで水やり**（水切れ3日で枯死）
4. 約7ゲーム内日数で成熟 → 鎌で収穫 → **亜麻の茎**と**亜麻の種**が得られる

収穫した種の一部は次の植え付けに残すこと。茎は繊維加工ラインへ回す。

> **亜麻の茎は焚き火で燃やせない**。茎は繊維採取の必須原料であるため、草木灰の原料にはできない（他の作物の茎と異なる点）。

### 繊維の加工手順

亜麻の茎から糸・布を作るには複数の工程が必要になる。各施設は**板**（割り刃が必要）から作成できる。

| 手順 | 施設 | タイプ | 投入 | 産出 |
|---|---|---|---|---|
| ① レッティング | 浸漬槽（板×8＋粘土×2→作業台） | 日次処理（3日） | 亜麻の茎 ×8 | 浸漬済み亜麻 ×8 |
| ② 繊維分離 | 叩き台（木材×1→作業台＋割り刃） | 手動処理 | 浸漬済み亜麻 ×1 | 亜麻繊維 ×1 |
| ③ 紡績 | 紡ぎ車（板×2＋車軸×1→作業台） | 手動処理 | 亜麻繊維 ×1 | 亜麻糸 ×1 |
| ④ 製布 | 織機（板×4＋木枠×2→作業台） | 手動処理 | 亜麻糸 ×8 | 布 ×1 |

各施設は右クリックで UI が開く。日次処理型の浸漬槽は仕込んで3日待つ、手動処理型の他3施設は「処理」ボタンを押し続けて加工する。

浸漬槽は水タイルに隣接している場所にしか置けないので注意すること。

糸（Tier 4）・布（Tier 5）の順にアンロックされるため、先に糸を出荷してから布を目指す流れになる。

## 13. 袋詰め大豆（当面のゴール）

布（Tier 5）を一定量出荷すると、**袋詰めじゃがいも**と**袋詰め大豆**が同時にアンロックされる。

### 袋の作成

布と糸から作業台で**亜麻の袋**を作成する。

```
布 ×1 ＋ 亜麻糸 ×1 → 作業台 → 亜麻の袋 ×1
```

### 袋詰め大豆の作成

```
大豆 ×64 ＋ 亜麻の袋 ×1 → 素手 → 袋詰め大豆 ×1
```

袋詰め大豆は現時点で最も高単価の出荷品（じゃがいもの50倍のスコア）。これを安定出荷できる状態にすることが当面のゴールになる。

### 袋詰め大豆が意味するもの

袋詰め大豆を生産するには、以下の**全てのラインが稼働している**必要がある。

- 大豆ライン: 栽培 → 脱穀
- 亜麻ライン: 栽培 → レッティング → 繊維分離 → 紡績 → 製袋
- 肥料ライン: 堆肥・草木灰・油粕の循環
- 灌漑ライン: 大豆・亜麻への安定した水やり

袋詰め大豆の安定出荷は、この惑星上で完全なサプライチェーンが回っていることの証明になる。

## 14. 水車動力による加工の自動化

手動処理型の加工施設（脱穀機・搾油機など）は、UIの「処理」ボタンを押し続けている間しか動かない。施設が増えてくると、付きっきりでボタンを押すのは大きな手間になる。**水車**の回転動力を使えば、この加工を自動化できる。

水動力の加工機械は、**原料を入れておくだけで毎朝5時に1日ぶんの加工が自動で進む**。プレイヤーはボタンを押す必要がなく、たまに成果物を回収するだけでよい。

### 動力の流れ

動力は次の順に伝わる。

```
水車（水の上）─ シャフト ─ シャフト ─ … ─ 加工機械
```

1. **水車**を水面に設置すると、水流で自動的に回転動力を生む
2. **シャフト**を水車から機械までつなぐと、回転動力が運ばれる
3. 動力が届いた**加工機械**が自動で動くようになる

### 水車

水車は動力源。**水車が水タイルに乗る**ように設置する。縦向き・横向きがあり、配置モード中に `v` キーで切り替えられる。設置すれば自動的に回り続ける（燃料は不要）。

### シャフト

シャフトは回転動力を隣のタイルへ伝える部品。水車から機械まで、タイルを連ねて敷設する。

- 隣り合うシャフト同士は**自動的に接続**し、直線・曲がり角の形が自動で選ばれる。縦向き、横向きがあり、配置モード中に `v` キーで切り替えられる。
- 角を曲げて動力の向きを変えたり、途中で分岐させて複数の機械へ配ったりできる
- **1台の水車から複数の機械を同時に駆動できる**

### 加工機械

水動力で動く加工機械は次の5種類。いずれも**右クリックでUIを開き、入力スロットに原料を入れておく**。

| 機械 | 入力 → 出力 |
|---|---|
| 自動脱穀機 | 茎付き大豆 → 大豆 ＋ 茎 |
| スクリュー式搾油機 | 大豆 ×8 → 大豆油 ＋ 油粕 ／ 亜麻の種 ×8 → 亜麻仁油 ＋ 油粕 |
| スカッチングミル | 浸漬済み亜麻 → 亜麻繊維 ＋ 屑 |
| 紡績機 | 亜麻繊維 → 糸 |
| 自動織機 | 糸 ×8 → 布 |

各機械は**入力8スロット・出力16スロット**を持つ。手動処理型より大量の原料をまとめて仕込んでおける。

### 自動加工のしくみ

- 動力が届いている機械は、**毎朝5時に入力スロットの中身を一括で加工**し、結果を出力スロットに積む
- シャフトがつながっておらず動力が来ていない機械は、完全に停止する
- 出力スロットが満杯になると、その分の加工は行われない（回収すれば再開する）

> 手動処理型の施設とレシピ自体は同じだが、水動力版は付きっきりの操作が不要になる点が大きく異なる。出荷量を伸ばす段階では、手動版から水動力版への置き換えが大きな省力化になる。

### 動力部品のクラフト

水車や機械の素材には、いくつかの中間部品が必要になる。これらは**作業台**で作る（一部は**ノミ**が必要）。**扱き歯**だけは作業台ではなく、金床で赤熱した隕鉄から鍛造する（第9章参照）。

| 部品 | レシピ | 備考 |
|---|---|---|
| 木製歯車 | 板 ×1 → 木製歯車 ×2 | ノミが必要 |
| ベベルギア | 木製歯車 ×1 ＋ 木の幹 ×1 | ノミが必要 |
| シャフト | 木の幹 ×1 ＋ ベベルギア ×1 → シャフト ×2 | |
| 木製ホイール | 板 ×4 ＋ シャフト ×1 | ノミが必要 |
| プーリー | 板 ×1 ＋ シャフト ×1 | |
| 扱き歯 | 金床で赤熱した隕鉄から鍛造 | 金床UIで出力を選択 |
| ドラム | 板 ×4 ＋ シャフト ×1 ＋ 扱き歯 ×4 | |

主要施設のレシピ:

| 施設 | レシピ |
|---|---|
| 水車 | 板 ×8 ＋ 木製ホイール ×2 ＋ シャフト ×1 |
| 自動脱穀機 | ドラム ×1 ＋ 木の枠 ×2 ＋ 木製歯車 ×2 ＋ 板 ×4 ＋ シャフト ×1 |
| スクリュー式搾油機 | 板 ×4 ＋ 木ネジ棒 ×2 ＋ 木の枠 ×2 ＋ 木製歯車 ×2 ＋ シャフト ×1 |
| スカッチングミル | 板 ×4 ＋ 木製ホイール ×1 ＋ 木の枠 ×2 ＋ シャフト ×1 |
| 紡績機 | 板 ×4 ＋ 木製ホイール ×1 ＋ プーリー ×4 ＋ 木の枠 ×2 ＋ ロープ ×2 ＋ シャフト ×1 |
| 自動織機 | 板 ×4 ＋ 木の枠 ×4 ＋ 木製ホイール ×1 ＋ プーリー ×1 ＋ 木製歯車 ×1 ＋ シャフト ×1 |

## 15. ウインチと台車、ステーションによるアイテムの自動搬送

加工機械を並べても、原料を機械に入れ、成果物を運び出す作業が残る。**台車（カート）**を使えば、この物流を自動化できる。

考え方は**ケーブルカー**に近い。レールの上に台車を置き、**ウインチ**が水車の回転動力でケーブルを巻き取って台車を引っ張る。台車にはインベントリがあり、線路脇の**ステーション**を通過するたびに自動で積み下ろしが行われる。

### レールを敷く

台車はレールの上を走る。

- レールは**一本道**として敷設する。ケーブルで引く方式のため、**分岐・合流はできない**
- レールを敷いたタイルは耕せない（畑と物流経路は両立しない）
- 隣り合うレールは自動的に接続し、直線・曲がり角の形が選ばれる
  - Vキーにより縦レールと横レールを選ぶことができる
### ウインチで台車を引く

ウインチは台車の動力源。

- 動かしたい経路の**終点側にウインチを1個**置く
- ウインチにシャフトを通じて水車の回転動力を伝える
- 動力が届いたウインチは、隣接するレールから順に**牽引力を伝播**させ、レール上の台車を終点（ウインチ側）へ引き寄せる

台車は終点に着くとそれ以上進めず、自然に停止する。台車を始点に戻したいときは、**斧で台車をインタラクトするとアイテム化して回収**できる（台車の中身が空のときのみ）。回収した台車は好きな場所に再配置できる。

### 台車を往復させる

一本道の**両端にそれぞれウインチを置く**と、台車を行き来させることができる。ただし、向かい合うウインチが同時に牽引すると力が打ち消し合うため、**動かしたい方向のウインチにだけ動力を供給する**必要がある。

本来はこの動力の切り替えに**クラッチ**（シャフトの途中で回転を伝達／切断する部品）を使う想定だが、**現時点ではクラッチは未実装**である。代わりに、**ウインチへつながるシャフトをつけ外しする**ことで、同じことが手動でできる。

1. 終点A側のウインチへシャフトをつなぐ → 台車が終点Aへ向かう
2. 台車が着いたら、A側のシャフトを斧で外し、終点B側のウインチへシャフトをつなぐ → 台車が終点Bへ戻る

シャフトのつけ外しは手間がかかるが、台車を斧で回収して置き直すよりは手軽な往復手段になる。クラッチが実装されれば、この切り替えはワンクリックで行えるようになる。

### 台車

- レールの上に台車を**右クリックで配置**する（レール上にしか置けない）
- 設置した台車を**右クリックすると台車のUIが開く**。インベントリスロットと、農作業用のアタッチメントスロット（第16章参照）がある
- 1つのレール（一本道）に複数の台車を置くことができる

### ステーションで積み下ろし

ステーションはレール脇に置く搬送装置。**台車と、ステーションをはさんで反対側にあるエンティティ**との間でアイテムを移動する。

- ステーションを**レールに隣接**して設置し、その**反対側に積み下ろし対象のエンティティ**（チェスト・堆肥場など）を置く
- 台車がステーション横のレールを**通過した瞬間**に、1回ぶんのアイテム移動が行われる（台車は停止しない）
- ステーションには**フォーク**が付いており、これがアイテムをすくって運ぶ

積み込み・降ろしのどちらになるかは、設置時の**フォークの初期位置（向き）**で決まる。配置モード中に `v` キーで向きを切り替えられる。

| フォークの初期位置 | 動作 |
|---|---|
| 対象エンティティ側 | エンティティ → 台車（積み込み） |
| 台車（レール）側 | 台車 → エンティティ（降ろし） |

> **覚え方**: フォークがある側が「アイテムを出す側」になる。フォークをチェスト側に置けばチェストから台車へ、フォークをレール側に置けば台車からチェストへ運ばれる。

同じチェストや堆肥場に対し、積み込み用と降ろし用のステーションを別々の辺に並べて置くこともできる。

### ステーションで積み下ろしできるエンティティ

自身のインベントリを持つエンティティが対象になる。

- 通常チェスト
- 堆肥場・浸漬槽・焚き火・炭焼き窯（日次処理型の施設）
- 自動脱穀機・スクリュー式搾油機などの水動力加工機械（第14章）

降ろし側では、**受け入れ可能なアイテムだけが移動**する。たとえば堆肥場には堆肥の原料（茎・落ち葉・作物残渣）しか入らないため、それ以外のアイテムは台車に残る。アイテムの仕分けは、どのステーションをどこに置くかという**レイアウトの工夫**で行う。

### レシピ

| 部品・施設 | レシピ |
|---|---|
| ロープ | 糸 ×4 → ロープ ×1（素手） |
| レール | 木の幹 ×2 ＋ ロープ ×1 → レール ×4（割り刃が必要） |
| ウインチ | ドラム ×1 ＋ 木製歯車 ×1 ＋ プーリー ×1 ＋ 木の枠 ×1 ＋ ロープ ×2 |
| 台車 | 板 ×4 ＋ 木製ホイール ×2 ＋ 木の枠 ×1 |
| ステーション | 板 ×4 ＋ 木製歯車 ×2 |

## 16. 台車を利用した農作業の自動化

台車は、アイテムの運搬だけでなく、**通過した畑タイルへの農作業**も自動で行える。自動化できるのは**施肥・植え付け・収穫**で、台車の**アタッチメントスロット**に入れた道具で動作が切り替わる。

台車は、進行方向に対して**左右1タイルずつ**に作業を行う。耕した畑の合間を縫ってレールを敷き、台車を通過させることで農作業をほぼ自動化できる。

```
進行方向 ↑
  畑 [レール] 畑      ← 進行方向の左右1タイルずつに作業
  ↑          ↑
 作業       作業
```

### 施肥・植え付け（アタッチメントなし）

施肥と植え付けには本来**スプレッダー**を装着するが、**現時点ではスプレッダーが未実装のため、アタッチメントスロットは空欄のままにする**。

アタッチメントが空欄の台車は、インベントリの中身に応じて次のように動作する。

- **肥料**（草木灰・堆肥・油粕）を入れておくと、通過した畑タイルに**施肥**する
- **種**（じゃがいも・大豆・亜麻・ひまわりの種）を入れておくと、通過した畑タイルに**植え付け**する
- すでに施肥済み／作物が植わっているタイル、連作疲労が限界のタイルには何もしない

### 収穫（鎌を装着）

収穫には本来**ハーベスター**を装着するが、**現時点ではハーベスターが未実装のため、代わりに鎌をアタッチメントスロットに入れる**。

- 鎌を装着した台車が通過すると、左右の畑の**成熟した作物を自動で収穫**する
- 収穫物は**台車のインベントリに格納**される（インベントリが満杯だと、そのタイルの作物は収穫されない）

> 収穫後の台車インベントリは、ステーション（第15章）を使ってチェストや加工機械へ自動で降ろせる。「収穫 → 運搬 → 加工」を台車とステーションでつなげば、農作業から出荷直前までを通して自動化できる。

## 17. 発酵・醸造（第3の生産軸）

袋詰め大豆まで到達したら、**発酵**という新しい生産軸に挑戦できる。食糧軸（じゃがいも・大豆）・繊維軸（亜麻 → 糸 → 布）に並ぶ第3の軸であり、塩と麦という2つの新要素を起点に、味噌・醤油・酒・酢といった高級品を生み出す。

発酵の特徴は**「仕込んで放置 → 数日〜数十日後に完成」という待ちの工程**にある。付きっきりの操作は不要で、静かに熟成していく桶を眺めるのがチルなエンドゲームの絵になる。待ち時間は早回し UI で調整できる。

### 塩を作る（塩田）

発酵軸全体の入口となるのが**塩**である。

- **塩田**は2×2の施設で、**水タイルに隣接する陸タイル**に設置できる（海／川の区別はない）
- 動力・燃料は不要。設置後、**一定のゲーム内日数ごとに塩が貯まる**（受動）
- プレイヤーが塩田をインタラクトして、貯まった塩を取り出す

塩は味噌・醤油・酒・酢のすべてに必要な必須素材になる。

### 麦を育てる

麹の材料となる新作物が**麦**である。大豆・亜麻と同じ操作系で栽培できる。

1. くわで耕す
2. 麦の種を持って植え付け
3. **毎日じょうろで水やり**（水切れ3日で枯死）
4. 約4ゲーム内日数で成熟 → 鎌で収穫 → **麦（粒）＋ 麦わら（茎）** が得られる

収穫した麦の一部は次の植え付け用の種に残すこと。**麦わらは焚き火で焼いて草木灰にできる**（茎×5 → 草木灰×1。亜麻の茎と違い焼却可）ほか、堆肥の原料にもなる。

### 焚き火で蒸す・炒る

発酵の前処理として、大豆や麦を加熱加工する。これは**既存の焚き火を拡張**して行う。

- 焚き火には従来の**燃料スロット**に加えて、**素材スロット**が追加される
- 素材スロットに大豆や麦を入れておくと、燃料を消費しつつ**1日経過するごとに数個ずつ加熱加工**される
- 一度蒸した／炒った素材は、その後時間が経っても**戻らない**（劣化なし）
- 燃料は木材でよい（高温は不要なので木炭は要らない）

| 素材 | 産物 | 用途 |
|---|---|---|
| 大豆 | 蒸し大豆 | 味噌・醤油 |
| 麦 | 蒸麦 | 麹・麦もろみ |
| 麦 | 炒り麦 | 醤油 |

### 麹を仕込む（麹室）

**麹室**は、蒸麦に麹菌を繁殖させて中間素材「麹」を量産する2×2の施設。

- レシピ（日次処理型）: **蒸麦 ＋ 麹（種）→ 麹**（好気性・2〜3日）
- 麹は**種麹を兼ねる**（種イモ方式）。初回は麹を持ち込み、完成した麹の一部を次の仕込みの種に取り分けて循環させる。在庫が尽きると次が仕込めなくなる

麹は多数の発酵桶に供給する基盤素材であり、回転の速い生産設備として機能する。

### 発酵桶で醸す

**発酵桶**は、味噌・醤油・酒・酢を熟成させる長期の設備。

- 見た目は**全品目で同一の樽**。中で何を熟成させているかは**カーソルホバーで現れるプロパティ表示**（品目・熟成残り日数）で判別する
- 動力・燃料は不要。**複数を同時並列で寝かせられる**
- 仕込んでから品目ごとの日数が経過すると完成する。出力が満杯のときは回収するまで進行が止まる

**主なレシピ（仮の初出荷日数）**:

| 品目 | 投入 | 設備 | 産出 | 日数 |
|---|---|---|---|---|
| 味噌 | 蒸し大豆 ＋ 塩 ＋ 麹 | 発酵桶（嫌気） | 味噌 | 約10日 |
| 醤油 | 蒸し大豆 ＋ 炒り麦 ＋ 塩 ＋ 麹 | 発酵桶 → 搾油機 | 醤油もろみ → 搾る → 醤油 ＋ 醤油粕 | 約12日 |
| 麦もろみ | 麹 ＋ 蒸麦 | 発酵桶（嫌気） | 麦もろみ（酒・酢の中間体） | 約5日 |
| 酢 | 麦もろみ | 発酵桶（好気・空気に触れさせる） | 酢 | 約5日 |

> **味噌＝三軸合流**（大豆＋塩＋麹）、**醤油＝四軸合流**（大豆＋麦＋塩＋麹）であり、醤油が現時点で最も工程が長い最高級品になる。醤油もろみの圧搾は**搾油機を流用**する（油を搾るのと同じ圧力搾汁）。副産物の醤油粕は油粕と同様、内部肥料として扱う。

### 麦焼酎を蒸留する（蒸留器）

麦もろみをさらに加工すると、高単価の嗜好品**麦焼酎**が作れる。

- **蒸留器**は燃料を使う新施設。焚き火と同じく**燃料スロット＋素材スロット**を持ち、**1日経過するごとに麦もろみを数個消費して麦焼酎を1個産出**する（蒸留で量が凝縮するため複数→1個）
- 蒸留した麦焼酎を**発酵桶に戻して「樽熟成」**させると、寝かせた日数に応じて品質・単価が上がる（熟成麦焼酎）

### 出荷とアンロック

発酵軸の出荷品は、おおむね **塩 → 麹 → 味噌 → 醤油** の順にアンロックされる（§7 のツリー参照）。麦焼酎・酢は麹のアンロック後に味噌と並行して開放される嗜好品ラインである。

- **醤油**: 四軸合流かつ最長チェーンの最高級品。現スコープの価格ピナクル
- **麦焼酎**: それに次ぐ高単価。樽熟成で品質を伸ばせる
- **味噌**: 三軸合流。布を超える単価
- **酢**: 麦もろみから作るが、日常調味料ゆえ安価

発酵品の自動化（焚き火・麹室・発酵桶・蒸留器への原料自動投入）は、§15 の台車・ステーションの仕組みで接続できる想定である。
