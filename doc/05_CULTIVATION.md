# 農作物の栽培設計 - Stella Garden

## 1. 設計方針

### 1.1 背景
惑星開拓という設定上、化学肥料が手に入らない環境での農業を想定する。限られた持ち込み資源と、惑星現地で調達可能な有機資源のみで農業を成立させる必要がある。

### 1.2 目標
- 単に種をまいて収穫するだけの単調なループを避け、**多段階の工程**と**作物間の依存関係**によりFactorioライクな生産チェーンを実現する
- 序盤から終盤にかけて段階的に農業が発展する流れを作る
- 各作物に明確な役割を持たせ、どれも「育てる理由」があるようにする

---

## 2. 主要作物

### 2.1 ジャガイモ（序盤・食糧自給用）

#### 選定理由
- 痩せた土地でも育つ代表的な作物であり、未開拓惑星の初期作物として説得力がある
- カロリー生産効率が非常に高く、食糧自給の基盤に最適
- 「まずジャガイモで食糧確保 → 余裕が出たら輸出品を作る」という段階感を生み出せる

#### 栽培工程
1. **整地** — 土をくわで耕す
2. **植え付け** — 種イモ（収穫したイモの一部を切ったもの）を土に埋める。畝立て（土を盛り上げて排水性を確保）は植え付け時に自動で行われる
3. **芽かき** — 芽が出すぎた場合に間引く（ゲームでは省略可能）
4. **土寄せ** — 成長に合わせて根元に土を盛る。イモが日光に当たると緑化して毒（ソラニン）が生じるため重要
5. **収穫** — 地上部が枯れてきたら掘り起こす
6. **乾燥・選別** — 泥を落として大きさで選別

#### ゲームメカニクスとしてのポイント
- **種イモシステム**: 収穫したイモの一部を次の種イモに回す必要がある。全部食べてしまうと次が植えられないというリソース管理のジレンマが生まれる
- **土寄せ工程**: 追加の作業工程として存在し、実行しないとイモが緑化して品質低下するペナルティを設定できる
- **連作障害**: ジャガイモはナス科で、同じ場所で連作すると病気が出やすい。輪作の必然性が生まれ、畑のレイアウト計画に戦略性が加わる
- **保存性**: 冷暗所に置けば長期保存可能。食糧備蓄システムとの相性が良い

#### 肥料との相性
- リン酸とカリウムを好む
- 草木灰（カリウム源）との相性が良い
- 窒素が多すぎると葉ばかり茂ってイモが育たない → 肥料の種類によって収量が変わる仕組みに活用可能

---

### 2.2 大豆（中盤以降・主力輸出品）

#### 選定理由
- 根粒菌による窒素固定が可能で、窒素肥料が乏しい環境でも育てやすい
- たんぱく源・油脂・飼料と多用途で価値が高い
- 場合によってはバイオディーゼルの原料にもなりうる
- 加工工程が多く、自動化しがいのある作物

#### 栽培工程
1. **整地・耕作**
2. **緑肥（ひまわり）の栽培** — 土壌改良のための前作
3. **ひまわりの漉き込み** — 堆肥化して土壌に有機物を投入
4. **大豆の植え付け**
5. **水やり・管理**
6. **収穫**
7. **脱穀** — 莢から豆を取り出す
8. **精選** — 不純物や不良品を取り除く
9. **袋詰め** — 亜麻の袋に詰める（亜麻との依存関係）
10. **出荷**

#### ゲームメカニクスとしてのポイント
- **工程の多段階性**: 10段階の工程があり、どこを自動化するかの選択が戦略となる
- **精選と品質**: 精選工程を省略すると不純物の混入率が高くなり出荷時の評価が下がる。手間をかけるか省略するかの判断が生まれる
- **根粒菌による窒素固定**: 大豆を育てた後の土地は窒素が豊富になり、後作の他の作物が育ちやすくなる。輪作体系にメリットを与える
- **亜麻との依存関係**: 袋詰め工程で亜麻の袋が必要になり、亜麻を育てないと大豆が出荷できないというサプライチェーンが形成される

#### 肥料について
- 窒素は根粒菌で自給できるが、リン酸やカリウムは外部から必要
- 油粕（アブラナや亜麻の搾油副産物）を肥料として活用可能

---

### 2.3 亜麻 / フラックス（中盤・工業原料）

#### 選定理由
- 繊維が取れる（布・ロープ・袋 → 工業的・インフラ的用途）
- 亜麻仁油も取れる（塗料・防水剤・食用）
- 食糧ではない「工業作物」としてバリエーションを提供
- 他の作物の出荷に必要な袋を供給する、サプライチェーンの要となる

#### 栽培工程
1. **整地・耕作** — 普通に耕す
2. **種まき** — 繊維用は密植、種子用はやや疎植
3. **成長** — 約100日程度。青い小花が咲く（視覚的に美しい）
4. **収穫** — 繊維用は根ごと引き抜く（刈り取りではない）。種子用は種が熟してから刈り取り
5. **レッティング（浸漬）** — 収穫した茎を水に数日〜数週間浸けて、繊維以外の部分を微生物に分解させる。亜麻加工の最大の特徴
6. **繊維の分離（スカッチング）** — 乾燥させて叩き、繊維を取り出す
7. **紡績** — 繊維を糸にする

#### ゲームメカニクスとしてのポイント
- **レッティング工程と水場の必要性**: 水場（池・水路）の近くに加工施設を置く必要があり、施設配置に地理的な制約が生まれる
- **繊維用 vs 種子用の選択**: 同じ亜麻でも栽培方法（密植/疎植）によって得られるものが変わる
  - 密植 → 高品質な繊維が多く取れるが種子は少ない
  - 疎植 → 種子（亜麻仁油の原料）が多く取れるが繊維の質は落ちる
  - → 同じ作物で2つの生産ラインが作れる
- **青い花畑の景観**: 一面の亜麻畑は視覚的にとても美しく、風景コレクション要素との相性が良い
- **加工の多段階性**: 収穫→レッティング→乾燥→繊維分離→紡績と工程が多く、自動化の設計しがいがある

#### 生産ラインの分岐
```
亜麻（繊維用・密植） → 引き抜き → レッティング → 乾燥 → 繊維分離 → 紡績 → 亜麻糸 → 織機 → リネン布 → 袋/衣類
                                                                        └→ 作業台で撚り合わせ → ロープ
亜麻（種子用・疎植） → 刈り取り → 脱穀 → 搾油 → 亜麻仁油（塗料/防水剤） + 油粕（肥料）
```

## 3. 補助作物・緑肥

### 3.1 ひまわり（緑肥）

#### 役割
- 大豆の前作として土壌改良に使用
- 深い根で土壌を物理的にほぐす（硬盤破砕効果）
- 地上部のバイオマスを土に漉き込むことで有機物を投入し、土壌微生物の環境を整える

#### 注意点
- ひまわり自体は窒素固定をしない（マメ科ではない）
- 窒素補給が目的ではなく、土壌の物理的改良と有機物投入が主な役割
- 惑星の未開拓土壌という設定では「有機物投入で微生物環境を整える」という理由付けで十分な説得力がある

#### ゲーム上の位置づけ
- 大豆を植える前の「準備工程」として機能
- ひまわりを漉き込んだ土地は土壌品質が上がり、大豆の収量が向上する
- ひまわり自体も視覚的に映える（黄色い花畑）

### 3.2 アブラナ（検討中・油粕肥料源）

#### 構想
- アブラナを育てて収穫→搾油→菜種油（燃料/食用）＋油粕（肥料）
- 油粕は窒素を多く含む有機肥料として使える
- 副産物の連鎖でFactorioライクな生産チェーンを強化

#### 生産ライン
```
アブラナ栽培 → 収穫 → 搾油 → 菜種油（燃料/食用） + 油粕（肥料）
```

#### 現時点のステータス
- 大豆・亜麻・ジャガイモの3作物で十分なサプライチェーンが構築できるため、初期実装では見送りの可能性あり
- 大豆自体も搾油→油粕のラインを持てるため、役割が重複する懸念
- 菜種油がバイオ燃料として独自の用途を持てるなら差別化可能

- 蜜源植物でもあり、養蜂システムを導入する場合に相性が良い

## 5. 肥料体系

化学肥料が使えない環境で、以下の有機肥料を自給する体系を構築する。

### 5.1 窒素源
- **大豆の根粒菌**: 大豆栽培時に土壌に窒素が固定される（後作への恩恵）
- **油粕**: 大豆または亜麻の搾油副産物。窒素を多く含む
- **緑肥の漉き込み**: ひまわり等のバイオマスを投入

### 5.2 カリウム源
- **草木灰**: 伐採した木材や作物の残渣を燃やして得られる。ジャガイモとの相性が特に良い

### 5.3 リン酸源
- **骨粉**: 牧畜が発展した後に入手可能（将来実装）
- **油粕**: リン酸も若干含む

### 5.4 肥料の入手方法

| 肥料 | 主な栄養素 | 入手方法 | 特徴 |
|------|-----------|---------|------|
| 堆肥 | N・P・K（バランス型） | 有機物を堆肥場で発酵（下記参照） | 万能だが効果が弱い。大量に必要 |
| 緑肥 | N（中）、有機物 | ひまわり等を栽培し土に漉き込む | 土壌の物理的改良効果もある |
| 油粕 | N（高）、P（中） | 大豆・亜麻の搾油副産物 | 即効性があり少量で効く |
| 草木灰 | K（高）、P（中） | 伐採した木材を燃やす | 窒素を含まないのが特徴 |

### 5.4.1 各肥料の生産詳細と持続可能性

※ゲーム内時間の前提: リアルタイム約10分 = ゲーム内1日。作物は数日〜数十日で成長する。

#### 堆肥

**生産方法:** 有機物を堆肥場（施設）に投入し、発酵期間を経て堆肥になる。

**原料と供給源:**

| 原料 | 入手方法 | 供給の持続性 | 備考 |
|------|---------|------------|------|
| ひまわり | 専用畑で栽培し刈り取り | 高（栽培し続ける限り供給） | 漉き込み（緑肥）にせず堆肥場に運ぶ |
| 落ち葉 | 森の周囲で自動蓄積 | 高（森を維持していれば毎年発生） | 伐採不要。森を残す理由になる |
| 雑草 | 未開拓地の整地時に刈り取り | 低（開拓が進むと減少） | 序盤の一時的な供給源 |
| 作物残渣 | 各作物の収穫時に副産物として発生 | 中（農業規模に比例） | 単体では量が少ないが補助的に蓄積 |
| 伐採副産物（枝葉・樹皮） | 木を伐採した際に幹とは別に発生 | 中（伐採頻度に依存） | 幹→木材/草木灰、枝葉→堆肥と分岐 |

**緑肥との使い分け（ひまわりの場合）:**
- **緑肥（漉き込み）**: その場の土壌を直接改良する。手間が少なく手軽だが、効果はその畑に限定される
- **堆肥化**: 刈り取って堆肥場で発酵させ、任意の畑に持っていける。「肥料の輸送」が可能だが、堆肥場の施設と発酵時間が必要

**ひまわり堆肥畑の運用:**
広大なひまわり畑を確保し、刈り取って堆肥を大量生産する方式。ひまわり畑は実質的な休耕地として機能し、輪作ローテーションにも組み込める。広い土地が必要だが、序盤に堆肥を安定供給する主力手段となる。

#### 草木灰

**生産方法:** 伐採した木材を燃やして灰にする。

**持続可能性の課題:**
- 木は種から育つのに比較的長い日数がかかるため、伐採し続けると森が枯渇する
- 持続的に供給するには、ある程度の広さの森を確保し、計画的に植林を続ける必要がある
- 序盤は開拓のための伐採で副次的に得られるが、中盤以降は植林→伐採のサイクルを確立する必要がある

**森の二択:**
森の利用方法に戦略的な選択が生まれる:

```
森 ─→ 伐採 ─→ 幹 → 木材（建材）
  │           └→ 燃焼 → 草木灰（カリウム肥料）
  │         枝葉・樹皮 → 堆肥の原料
  │         ※森が減る。植林で再生が必要
  │
  └→ 維持 ─→ 落ち葉 → 堆肥の原料
              落果（種子）→ 植林用の苗木に
              ※森が残る。持続可能だが草木灰は得られない
```

序盤は開拓のために伐採が中心だが、ある程度発展した後は「植林して森を維持管理する」方が肥料（堆肥）の安定供給に繋がる。伐採と維持のバランスを考える転換点が生まれ、「自然との共生」的なテーマにもなる。

#### 油粕

**生産方法:** 大豆・亜麻の搾油工程で副産物として発生する。

**持続可能性:**
- 特別に何かを育てる必要はなく、大豆や亜麻の生産ラインに組み込まれている
- ただし、油粕の生産量は搾油量に比例するため、肥料としての必要量とのバランス調整が必要
- 主に亜麻の肥料として使用（○の相性）し、余剰分を他に回す運用が基本

#### 緑肥

**生産方法:** 作付け予定の畑にひまわりを栽培し、育ったらそのまま漉き込む。

**持続可能性:**
- ひまわりは比較的短い日数で育つため、輪作のルーチンに組み込みやすい
- 原料の調達が不要（畑に直接植えるだけ）で手間が最も少ない
- ただし、畑を1サイクル分ひまわりに使うため、その間は他の作物を植えられない

### 5.5 肥料×作物の相性マトリックス

各作物が求める栄養素の傾向:
- **ジャガイモ**: カリウム重視。窒素過多は逆効果（葉ばかり茂ってイモが育たない）
- **大豆**: 窒素は根粒菌で自給できる。リン酸・カリウムが欲しい
- **亜麻**: バランス型だが、窒素がやや多めだと繊維の質が良くなる

| 肥料 | ジャガイモ | 大豆 | 亜麻 | 備考 |
|------|-----------|------|------|------|
| 堆肥 | ○ | ○ | ○ | 万能だが効果が弱く、大量投入が必要。序盤の入門肥料 |
| 緑肥 | △ | △ | ○ | 窒素供給が主。大豆は窒素自給できるため恩恵が薄い |
| 油粕 | × | △ | ○ | 窒素が高い。ジャガイモには逆効果。亜麻の繊維品質向上に最適 |
| 草木灰 | ○ | ○ | △ | カリウムが高い。ジャガイモとの相性が特に良い |
| 無肥料 | × | × | × | 育たないわけではないが収量が大幅に低下（基本の3〜4割程度） |

**凡例:**
- **○（効果的）**: 収量が十分に向上する
- **△（普通）**: 効果はあるが限定的、または過不足がある
- **×（逆効果/非効率）**: マイナス効果、または実用にならないほど収量が低い

**設計意図:**
- 堆肥は全作物に○だが、大量に必要なため手間がかかる。序盤はこれで凌ぎ、慣れたプレイヤーは専用肥料に切り替える動機が生まれる
- 油粕は亜麻には最適だがジャガイモには逆効果。間違えるとペナルティがあることで肥料選択に戦略性が生まれる
- 草木灰はジャガイモの親友。伐採→燃焼→施肥のラインが序盤の基本ループとなる
- 大豆は根粒菌のおかげでどの肥料でもそこそこ育つが、最大収量を得るには堆肥か草木灰が必要

### 5.6 連作障害

同じ作物を同じ場所で連続して栽培すると、土壌の病原菌蓄積や栄養素の偏りにより収量が低下する。

#### 作物ごとの連作耐性

| 作物 | 連作耐性 | 空けるべき年数 | 連作時のペナルティ |
|------|---------|--------------|------------------|
| ジャガイモ | 弱い | 2〜3年 | 収量低下＋病気リスク |
| 大豆 | 普通 | 1〜2年 | 収量低下（緩やか） |
| 亜麻 | 非常に弱い | 5〜6年 | 収量が激減、長期間同じ場所に植えられない |

#### ゲームメカニクスとしての連作障害

- **無肥料 + 連作なし**: 収量が大幅に低い（×）が、一応育つ
- **無肥料 + 連作**: 収量がさらに低下し、2回目以降はほぼゼロまたは枯死
- **肥料あり + 連作**: 肥料で多少は補えるが、連作ペナルティは完全には打ち消せない
- **肥料あり + 輪作**: 最大収量。これが理想的な農業形態

連作障害の存在により、プレイヤーは複数の畑を確保して輪作計画を立てる必要がある。特に亜麻は連作に非常に弱いため、広い農地の確保と長期的な土地利用計画が重要になる。

### 5.7 ゲームメカニクスとしての肥料まとめ

- 作物ごとに必要な栄養素のバランスが異なり、適切な肥料の選択が戦略となる
- 不適切な肥料は逆効果もありうる（例: ジャガイモに油粕→窒素過多で葉ばかり茂る）
- 肥料の自給体系を構築すること自体がゲームの中間目標となる
- 連作障害と輪作の仕組みにより、畑のレイアウトと作付け計画に長期的な戦略性が生まれる

## 6. 作物間の依存関係とサプライチェーン

### 6.1 全体構造

```
ジャガイモ ──→ 食糧自給（生存基盤・序盤の最重要作物）
  │              ← 草木灰（カリウム肥料）を施肥すると収量向上
  │
亜麻 ─────→ 繊維 → 紡績 → リネン布 → 袋・ロープ（インフラ）
  │          種子 → 搾油 → 亜麻仁油（塗料/防水剤） + 油粕（肥料）
  │
ひまわり ──→ 漉き込み → 土壌改良（大豆の前作）
  │
大豆 ─────→ 脱穀 → 精選 → 袋詰め（亜麻の袋が必要）→ 輸出（評価UP）
               搾油 → 大豆油（食用/燃料） + 油粕（肥料）
```

### 6.2 ゲーム進行の流れ

**序盤: 食糧確保フェーズ**
1. ジャガイモを植えて食糧自給の基盤を作る
2. 種イモの管理（食べる分と次に植える分のバランス）を学ぶ
3. 伐採した木材を燃やして草木灰を作り、ジャガイモの肥料として使い始める

**中盤: サプライチェーン構築フェーズ**
4. 亜麻の栽培を開始し、繊維を生産する
5. ひまわりを緑肥として育て、土壌改良を行う
6. 大豆の栽培を開始する
7. 亜麻から袋を作り、大豆の出荷体制を整える

**中盤〜後半: 自動化・最適化フェーズ**
8. 各工程の自動化（フィージビリティスタディのPhase 1〜3と連動）
9. 輪作体系の確立（連作障害の回避）
10. 肥料の自給体制の最適化
11. 大量生産・大量出荷による評価向上

### 6.3 輪作体系の例

連作障害を避けるため、以下のような輪作が考えられる:

```
Year 1: ひまわり（緑肥）→ 漉き込み → 大豆
Year 2: ジャガイモ
Year 3: 亜麻
Year 4: ひまわり（緑肥）→ 漉き込み → 大豆
...
```

同じ畑で毎年異なる作物を育てることで、土壌の健全性を維持しつつ全ての作物を生産し続ける。プレイヤーは複数の畑を並行管理し、それぞれの輪作サイクルをずらすことで毎年全作物を収穫できる体制を構築する。

## 8. 種子循環システム

### 8.1 基本方針

全ての作物・樹木は初期に種子を持ち込んで開始する。持続可能な農業のために、栽培・収穫の過程で次世代の種子を確保できる仕組みとする。種子の管理は「食べる/使う分」と「次に植える分」のリソース管理のジレンマを生む。

### 8.2 作物ごとの種子取得方法

| 作物 | 種子の取得方法 | 備考 |
|------|--------------|------|
| ジャガイモ | 収穫したジャガイモの一部を種イモとして残す | 種子ではなく栄養繁殖。食糧と種イモの配分が重要 |
| 大豆 | 脱穀で得た大豆の一部を種として残す | 収穫物＝種。出荷/搾油/種のバランス管理 |
| 亜麻 | 鎌で刈り取り（種子用収穫）で亜麻の種を取得 | 繊維用（シャベル）で収穫すると種は得られない or 少量 |
| ひまわり | 鎌で刈り取り時にひまわりの種が分離して得られる | 緑肥として漉き込むと種は得られない |
| 樹木 | 森を維持していると落果として自動蓄積。拾って回収 | 伐採では種は得られない。森の維持が植林の前提条件 |

### 8.3 種子管理のゲームメカニクス

**リソース配分のジレンマ:**
- ジャガイモ: 全部食べると次が植えられない。食糧と種イモの配分を常に考える
- 大豆: 出荷・搾油・種の三方向に振り分ける必要がある
- 亜麻: 繊維用に全部引き抜くと種が確保できない。一部は必ず種子用に鎌で収穫する必要がある

**種子が得られない操作:**
- ひまわりの緑肥漉き込み → 種子は得られない。種の在庫がなくなると次のひまわりが植えられなくなる
- 亜麻のシャベル収穫（繊維用） → 種子は得られない、または少量のみ
- 樹木の伐採 → 種子は得られない。森を全て伐採すると植林できなくなる

**設計意図:**
- 「目先の利益のために全て消費すると持続不可能になる」という構造を自然に学べる
- 種子の備蓄管理がゲームの基礎的なリソース管理スキルとなる
- 特に樹木は「森を全て伐採→種子がなくなる→植林できない→草木灰も堆肥原料も得られなくなる」という取り返しのつきにくい失敗パターンを生む（ただしゲームオーバーにはならない。地球から種子を再購入できるが評価が下がる、など救済手段を用意する）
