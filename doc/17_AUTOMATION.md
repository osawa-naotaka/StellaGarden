# 自動化システム設計（フィージビリティスタディ）

> 本ドキュメントは `doc/04_FEASIBILITY_STUDY.md` の自動化設計を踏まえ、フィージビリティスタディの範囲で実装する自動化システムの具体的な設計をまとめたものである。
>
> **位置づけ**
>
> このドキュメントは、現在の自動化設計の**正式仕様寄りの文書**である。  
> ただし、フィージビリティスタディ段階の文書であるため、将来実装や未確定事項も含む。
>
> **旧検討案との関係**
>
> - `doc/08_UNDER_CONSIDERATION.md` にある、井戸・太陽電池・スプリンクラー・自動耕作機などを中心とした初期ガジェット案は、**検討履歴として残っているが現在は不採用**である
> - 本ドキュメントでは、それらの近代的・抽象的な自動化案ではなく、**水車・シャフト・クラッチ・ケーブル牽引・台車**を中心とした、より物理的で視覚的な自動化を正式方針として扱う
>
> **最新前提として読むべき関連文書**
>
> - `doc/16_IRRIGATION.md` — 灌漑、水門、導水路、畝間水路
> - `doc/18_FUEL.md` — 木材と木炭の燃料体系
> - `doc/20_FORGE.md` — 炉UIと鍛造フロー
> - `doc/21_AUTO_FERTILIZATION.md` — 物流ループ・施肥ループ・台車アタッチメント拡張
>
> **この文書を読む際の前提**
>
> - 動力源は主に**水車**
> - 灌漑は**水門・導水路・畝間水路**を中心に構成する
> - 物流は**台車＋ループ＋ステーション**で視覚的に表現する
> - 自動化は「完成済みの万能機械を置く」のではなく、**どう動かすかをプレイヤーが設計する**方向を重視する

## 1. 設計方針

### 1.1 背景

- 手動農業（じょうろ、鍬、鎌）は栽培面積の拡大に伴い管理が破綻する
- `doc/15_RE_SYNOPSIS.md` の格付けシステムにより、出荷量の増加がプレイヤーの目標となる
- 出荷量を増やすには農作業の自動化が不可欠
- フィージビリティスタディでは、**近代的な電力設備やホッパー的物流ではなく、水力と機械要素を中心にした自動化**を採用する
- 燃料は存在するが、その主用途は `doc/18_FUEL.md` にあるように木炭を使う加熱・加工系であり、本ドキュメントで扱う農作業自動化の主動力は水車である

### 1.2 基本原則

- 動力源は**水車**を中心とする（本ドキュメントのスコープでは農作業自動化の主動力）
- `doc/04_FEASIBILITY_STUDY.md` のケーブル牽引システム（ループレール方式）を採用
- プレイヤーが「何を動かすか」は既製品（クラフトレシピ）、「どう動かすか」はプレイヤーの設計
- スキルツリーの制限はない。リソースが揃えば最初から作成可能
- 将来の拡張（蒸気機関・コンバイン等）の余地は残すが、本スコープには含めない
- `doc/08_UNDER_CONSIDERATION.md` にある範囲型ガジェット自動化は採用せず、**物理的な配置・接続・巡回が見えること**を優先する

### 1.3 「需要を報酬にする」設計との一貫性

- `doc/15_RE_SYNOPSIS.md` で決定した通り、会社からモノは与えられない
- 自動化機械はすべて**プレイヤーが自分で作る**
- 水車の動力、亜麻のロープ、現地の木材と石で機械を組み上げる
- 将来的に鉱業が解放されれば、プレイヤーが掘った石炭で蒸気機関を動かせる可能性はあるが、それは「会社からの投資」ではなく「プレイヤーの自力開発」

### 1.4 自動化の段階設計

手動→半自動→全自動の各段階にそれぞれ楽しさを持たせる:

| 段階 | 状態 | 楽しさ |
|---|---|---|
| 手動 | 全て手作業 | 農業の基本を体で覚える |
| 半自動 | ケーブル牽引 + 手動アタッチメント交換 | 「機械が代わりにやってくれる」快感 |
| 全自動 | 転車台 + ピンシリンダーで作業プログラム | 設計の工夫で全てが自動で回る達成感 |

**フィージビリティスタディのスコープ**: 手動 → 半自動まで。全自動（転車台・ピンシリンダー）は将来実装。

> **補足**  
> `doc/21_AUTO_FERTILIZATION.md` では、この「半自動」の考え方をさらに発展させ、  
> 収穫だけでなく **残渣物流・堆肥化・施肥** までループ化する設計が追加されている。  
> したがって本ドキュメントは、農作業自動化の基礎仕様として読み、物流・施肥の拡張は後続文書で補完する。

## 2. 動力系

### 2.1 水車（動力源）

| 項目 | 仕様 |
|---|---|
| 設置条件 | 水タイル（海面レベル）と土地タイルにまたがって設置。縦方向の場合は左または右が水タイルで、逆側が土地タイル |
| 動力 | 水流により自動的に回転（抽象化。設置すれば動作する） |
| 出力 | 回転力を隣接するシャフトに伝達 |
| サイズ | 3x2(横方向) or 2x3(縦方向) |

水車は回転力を生む主要なソース。1台の水車から複数のシャフトラインに分岐可能。

> **補足**  
> 本ドキュメントでは水車を農作業自動化の主動力として扱う。  
> 将来的には `doc/18_FUEL.md` にある燃料系や、さらに先の蒸気機関などの拡張余地はあるが、  
> 少なくとも現在の正式な農業自動化の基礎は **水車起点** である。

### 2.2 シャフト（動力伝達）

| 項目 | 仕様 |
|---|---|
| 役割 | 回転力を隣接タイルに伝達 |
| 設置 | 地面に設置。直線的に連結 |
| 方向転換 | 直角方向への分岐が可能（ベベルギア相当） |
| 素材（案） | 木材 |

水車からの回転力を、畑の端（ケーブル起点）や加工施設まで運ぶ。

### 2.3 クラッチ（動力ON/OFF）

| 項目 | 仕様 |
|---|---|
| 役割 | シャフトの回転力伝達をON/OFFする |
| 操作 | 手動（プレイヤーがクリック/インタラクト） |
| 将来拡張 | カム連動による自動ON/OFF |

クラッチはドッグクラッチ方式（`doc/04` 参照）。シャフトラインの途中に設置し、必要な時だけ動力を伝達する。

### 2.4 動力系の接続図

```
水車（水タイルに隣接）
  │
  シャフト ─── シャフト ─── シャフト ─── ...
                  │
               クラッチ（手動ON/OFF）
                  │
               シャフト → 各機械へ
```

## 3. ケーブル牽引システム

### 3.1 概要

`doc/04_FEASIBILITY_STUDY.md` のループレール方式を採用。固定動力源（水車）からケーブルで台車を牽引し、畑全面を自動的にカバーする。

### 3.2 構成エンティティ

#### レール

| 項目 | 仕様 |
|---|---|
| 役割 | 台車の走行経路を定義 |
| 設置 | 畑の上にループ状に敷設 |
| 素材（案） | 木材 + 鉄（少量） |

蛇行する1本の連続レールを畑に敷き、台車がレール上を周回する:

```
  ┌──────────────────────┐
  │  ←←←←←←←←←←←←←←←←  │
  │                      │
  │  →→→→→→→→→→→→→→→→  │
  │                      │    ← 蛇行する1本の連続レール
  │  ←←←←←←←←←←←←←←←←  │
  │                      │
  │  →→→→→→→→→→→→→→→→  │
  └──────────────────────┘
      ↑ 始点 = 終点（ループ）
```

レールの下のタイルは畑として使用可能（レールは地面の上に乗っているだけ）。

#### ケーブル（ウィンチ）

| 項目 | 仕様 |
|---|---|
| 役割 | シャフトの回転力を台車の直線運動に変換 |
| 設置 | レールの始点に設置。シャフトと接続 |
| 動作 | ロープを巻き取り、台車を牽引する |
| 素材（案） | 木材 + 亜麻ロープ |

亜麻ロープを動力伝達に使用する点は、`doc/04` の歴史的根拠（亜麻ベルト）に基づく。亜麻の栽培→ロープ生産→自動化に使用、という循環が生まれる。

#### 台車

| 項目 | 仕様 |
|---|---|
| 役割 | レール上を移動し、装着されたアタッチメントで農作業を行う |
| 設置 | レール上に配置 |
| 動作 | ケーブルに牽引されてレール上を移動 |
| アタッチメント | 1つのアタッチメントを装着可能。手動で付け替え |
| 素材（案） | 木材 + 鉄 |

台車がレールのループを1周すると、畑の全面に対してアタッチメントに応じた作業が実行される。

### 3.3 トリップレバー（自動停止）

レールの始点（= 終点）にトリップレバーを設置:

```
  台車の進行方向 →→→

                        ┌─ トリップレバー（ピボットで固定）
                        │    ↑ 台車が押すと倒れる
  ══════════════════════╪═══════
                        │
                        └─→ リンク棒 → クラッチ切断
```

- 台車がループを1周して始点に戻ると、トリップレバーを押し倒す
- リンク棒を介してクラッチが自動的に切断される
- 台車が自動停止し、プレイヤーがアタッチメントを交換できる状態になる

### 3.4 操作フロー

1. プレイヤーが台車にアタッチメントを装着（例: プラウ）
2. プレイヤーがクラッチをONにする
3. ケーブルが台車を牽引し、ループレールを1周
4. 畑全面に対して耕起が実行される
5. トリップレバーでクラッチが自動切断、台車が停止
6. プレイヤーがアタッチメントを交換（例: シードドリル）
7. 再びクラッチON → 全面に植え付け → 自動停止
8. 以降、必要な作業分だけ繰り返す

## 4. アタッチメント（農具）

### 4.1 フィージビリティスタディ対象

3作物（ジャガイモ・大豆・亜麻）の農作業に必要なアタッチメント:

| アタッチメント | 作業 | 動力要件 | 対応作物 | 素材（案） |
|---|---|---|---|---|
| プラウ | 耕起 | 牽引のみ | 全作物共通 | 木材 + 鉄 |
| シードドリル | 小粒種子の植え付け | 牽引（車輪回転で繰出し） | 大豆・亜麻 | 木材 + 鉄 + 歯車 |
| ポテトプランター | 種イモの植え付け | 牽引（車輪回転で繰出し） | ジャガイモ | 木材 + 鉄 + 歯車 |
| リッジャー | 土寄せ・畝立て | 牽引のみ | ジャガイモ | 木材 + 鉄 |
| ハーベスター | 収穫（掘り取り） | 牽引のみ | 全作物共通 | 木材 + 鉄 + チェーン |

### 4.2 動力要件の簡略化

`doc/04` ではハウムトッパー（茎刈り）に回転動力が必要とされているが、フィージビリティスタディでは以下のように簡略化する:

- **ハウムトッパーは省略**: ジャガイモの収穫前に、プレイヤーが手動で鎌を使って茎を刈る
- **全アタッチメントは牽引のみで動作**: 台車が進むことで車輪が回転し、その回転からギアで繰出し機構を駆動する仕組み（シードドリル、ポテトプランター）
- これにより、ケーブルで引っ張るだけで全ての農作業が実行可能

### 4.3 作物ごとの作業フロー

#### ジャガイモ

```
1. [プラウ]            耕起（牽引のみ）
       ↓
2. [ポテトプランター]  種イモ植え付け（牽引 + 車輪回転）
       ↓
3. [リッジャー]        土寄せ・畝立て（牽引のみ）
       ↓
   （成長期間: 水門で灌漑。5日間）
       ↓
4. [鎌で茎刈り]        手動作業（フィージビリティスタディでは手動）
       ↓
5. [ハーベスター]      掘り取り（牽引のみ）
```

台車による自動作業: 3回（耕起・植付・収穫） + 手動1回（茎刈り） + 手動1回（土寄せ）
→ アタッチメント交換とクラッチONを計3〜5回

#### 大豆

```
1. [プラウ]            耕起（牽引のみ）
       ↓
2. [シードドリル]      種まき（牽引 + 車輪回転）
       ↓
   （成長期間: 水門で灌漑。4日間）
       ↓
3. [ハーベスター]      収穫（牽引のみ）
```

台車による自動作業: 3回（耕起・種まき・収穫）

#### 亜麻

```
1. [プラウ]            耕起（牽引のみ）
       ↓
2. [シードドリル]      種まき（牽引 + 車輪回転）
       ↓
   （成長期間: 水門で灌漑。7日間）
       ↓
3. [ハーベスター]      収穫（牽引のみ。亜麻は根ごと引き抜く）
```

台車による自動作業: 3回（耕起・種まき・収穫）

## 5. 加工機械

### 5.1 概要

加工機械は定置型。シャフトに直結して設置し、原料を投入すれば自動的に加工が行われる。ケーブル牽引系とは異なり、移動の仕組みは不要。

### 5.2 加工機械一覧

| 機械 | 入力 | 出力（メイン） | 出力（副産物） | 動力接続 |
|---|---|---|---|---|
| 搾油プレス | 大豆 or 亜麻種子 | 大豆油 or 亜麻仁油 | 油粕 | シャフト直結 |
| スカッチングミル | レッティング済み亜麻 | 亜麻繊維 | 屑（残渣） | シャフト直結 |
| 紡績機 | 亜麻繊維 | 糸 | — | シャフト直結 |
| 自動織機 | 糸 | リネン布 | — | シャフト直結 |
| 脱穀機 | 亜麻の茎と種 or 茎付き大豆 | 亜麻の種 or 大豆 | 茎 or 亜麻の茎 | シャフト直結 |

> **補足**  
> 鍛造系の加工は本ドキュメントの主題ではない。  
> 炉・木炭・赤熱した隕鉄・金床による刃の生成は、現在は `doc/20_FORGE.md` を正とする。  
> したがって、ここでいう「加工機械」は主に **農産物・工業作物の加工ライン** を指す。

### 5.3 加工の操作フロー

1. プレイヤーが原料を機械に投入する
2. 機械がシャフトから動力を受け、自動的に加工を行う
3. 完成品が機械から排出される（プレイヤーが回収）

加工機械は「設置してシャフトにつなげば動く」というシンプルな構成。プレイヤーの判断は「どの機械をどこに配置するか」「原料の投入タイミング」に集中する。

### 5.4 レッティング（亜麻の浸漬）

亜麻の繊維加工にはレッティング（水に浸けて外皮を腐らせる）工程が必要。これは機械ではなく水タイルに隣接した施設（レッティングプール）で行う:

- 収穫した亜麻をレッティングプールに投入
- 一定のゲーム内日数が経過すると完了
- 動力不要（水に浸けるだけ）

### 5.5 インターフェース仕様（手動処理 UI）

各加工機械は **右クリックで開くサイドバー UI**（カテゴリ2: 手動処理 UI）を持つ。
詳細は `doc/12_UI.md` §13.1 を参照。

| 機械 | 入力スロット | 出力スロット（メイン） | 出力スロット（副産物） |
|---|---|---|---|
| スクリュー式搾油機 | 1（大豆 / 亜麻の種） | 1（大豆油 / 亜麻仁油） | 1（油粕） |
| スカッチングミル（叩き台） | 1（浸漬済み亜麻） | 1（亜麻繊維） | なし |
| 紡績機 | 1（亜麻繊維） | 1（糸） | なし |
| 自動織機 | 1（糸） | 1（リネン布） | なし |
| 脱穀機 | 1（茎付き大豆） | 1（大豆） | 1（茎） |

**制約:**
- 出力スロット（メイン・副産物とも）が満杯の場合、処理は実行されない（自動停止）
- プレイヤーは任意のタイミングでスロットの中身を確認・取り出し可能
- 入力スロットはレシピで定義された itemId のみ受け付ける（複数レシピ対応の場合は配置時に既存スタックの itemId と一致が必要）

### 5.6 処理トリガーと処理量

**処理トリガー:** UI 内の「処理」ボタンを **押している間** だけ、レシピごとに定められた間隔で1サイクルずつ処理する。

**1サイクルあたりの処理量:** レシピで定義（例: 搾油機は大豆8 → 大豆油1 + 油粕1）。

**処理間隔:** レシピごとに 600〜1000ms。

| 機械 | 処理間隔 | 1サイクルの入力 / 出力 |
|---|---|---|
| 脱穀機 | 600ms | 茎付き大豆 ×1 → 大豆 ×1 + 茎 ×1 |
| 搾油機 | 800ms | 大豆 ×8 → 大豆油 ×1 + 油粕 ×1（亜麻の種でも同様） |
| 叩き台 | 600ms | 浸漬済み亜麻 ×1 → 亜麻繊維 ×1 |
| 紡績機 | 800ms | 亜麻繊維 ×1 → 糸 ×1 |
| 織機 | 1000ms | 糸 ×8 → 布 ×1 |

**処理条件（全て満たす場合に処理を実行）:**
1. プレイヤーが UI を開いて「処理」ボタンを押下している
2. 入力スロットに対応レシピがあり、必要数 ≥ 入る
3. 全ての出力スロットに、出力する分の余裕がある

**スケーリング:** 大量処理が必要な場合は同種の機械を複数台並列に設置するか、間隔の早い機械を選ぶ。

**自動織機のレシピ:** リネン布専用。袋は手動クラフト（リネン布 + 糸）で作成する。自動織機では袋を生産しない。

> **動力系との関係（将来）**  
> 現状の手動処理 UI は、プレイヤーが UI を開いてボタンを押す手動操作を前提とする。
> 将来、シャフト経由で水車に接続されている時は「処理ボタン押下と同等の駆動」を自動化する拡張が考えられるが、
> フィージビリティスタディのスコープ外。

## 6. 動力系の統合

### 6.1 水車からの動力分配

1台の水車から複数の用途に動力を分配する:

```
水車（水タイルに隣接）
  │
  シャフト（メインライン）
  │
  ├─── クラッチA ─── シャフト → ケーブル（ウィンチ）→ 台車（畑の自動化）
  │
  ├─── クラッチB ─── シャフト → カム → 水門（灌漑の自動開閉）
  │
  ├─── シャフト → スクリュー式搾油機
  │
  ├─── シャフト → スカッチングミル
  │
  ├─── シャフト → 紡績機
  │
  └─── シャフト → 織機
```

- 畑の自動化と灌漑はクラッチで個別にON/OFF可能
- 加工機械は常時稼働（原料が投入された時のみ実質的に動作）
- 水車1台で全てを駆動可能（フィージビリティスタディの規模では十分）

### 6.2 亜麻ロープの循環

自動化システムの中に、亜麻の栽培→加工→自動化への利用という循環が生まれる:

```
亜麻の栽培
  ↓
亜麻繊維（スカッチング）
  ↓
糸（紡績）
  ├── → 布 → 麻袋 → 出荷用
  └── → ロープ → ケーブル牽引に使用 → 畑の自動化 → 亜麻の栽培（循環）
```

この循環は `doc/04` の「川から始まる技術の連鎖」の核心部分であり、ゲームのサプライチェーンに深みを与える。

## 7. プレイヤー体験

### 7.1 1日の流れ（半自動化された中盤のイメージ）

```
朝:
  1. 水門を開ける（or 自動開閉を眺める）
  2. 必要な農具アタッチメントを台車に装着
  3. クラッチON → 台車が畑を1周 → 自動停止
  4. （必要なら）アタッチメントを交換して再度クラッチON

昼:
  5. 収穫物を加工機に投入（搾油プレス、スカッチングミル等）
  6. 加工完了品を回収

夕方:
  7. 水門を閉める
  8. 完成品を出荷
```

### 7.2 手動 vs 半自動の比較

| 作業 | 手動 | 半自動（ケーブル牽引） |
|---|---|---|
| 耕起 | 鍬で1マスずつ | アタッチメント装着 + クラッチON → 全面自動 |
| 植え付け | 種を1マスずつ手植え | アタッチメント交換 + クラッチON → 全面自動 |
| 水やり | じょうろで1マスずつ | 水門の開閉（全面一括） |
| 収穫 | 鎌で1マスずつ | アタッチメント交換 + クラッチON → 全面自動 |
| 搾油 | 手動プレス（1個ずつ） | 原料投入 → 自動加工 |

### 7.3 チルな雰囲気との両立

`doc/04` のチルな雰囲気との両立方針を継承:

- **眺める楽しさ**: 水車が回る、ケーブルが台車を引く、台車が畑を巡る
- **音の心地よさ**: 水のせせらぎ、歯車のカチカチ、台車のゴトゴト
- **急がなくていい**: 水力は自然のペース。プレイヤーが離席しても加工機は動き続ける
- **失敗が致命的でない**: アタッチメントを間違えても作物が壊滅するわけではない

## 9. doc/15 格付けシステムとの関連

### 9.1 格付けと自動化の対応

| 格付け | 主な自動化状態 | ボトルネック |
|---|---|---|
| D級 | 全て手動。じょうろ・鍬・鎌 | 栽培面積が小さく、手動で間に合う |
| C級 | 水門による半自動灌漑。畑の自動化を構築中 | 大豆の加工ライン構築が課題 |
| B級 | ケーブル牽引 + 加工機械が稼働 | 亜麻の複合ラインの管理が複雑 |
| A級 | 全ラインが半自動で稼働。効率化を追求 | 大規模生産のための設計最適化 |
| S級 | 将来: 全自動化（転車台・ピンシリンダー） | 入植船受け入れのインフラ整備 |

### 9.2 自動化がプレイヤーを次の格付けに導く

- D級: 手動の大変さが灌漑の自動化（水門）への動機になる
- C級: 灌漑が楽になった分、大豆の加工に集中できる。出荷量が増え始める
- B級: ケーブル牽引で農作業が半自動化。亜麻の複合ラインに取り組む余裕が生まれる
- A級: 全品目の大規模生産。出荷量の最大化を目指して設計を最適化する
