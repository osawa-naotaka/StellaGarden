# ユーザーストーリー - Stella Garden

このドキュメントは2026/2/28時点で廃止。フィジビリティスタディを先に行い、その結果をふまえて改めてこのドキュメントを作成する。

## 1. ユーザーペルソナ

### プライマリーペルソナ：大河るり
- **役割**: 開発者兼唯一のユーザー（初期段階）
- **背景**: 
  - Vtuberとして活動中で、週一で動画を投稿している
  - 現在求職中で、開発に充てる時間はあるがメンタルの調子に波がある
  - チルなゲームが好きで、癒されながら遊べる体験を求めている
  - プログラミングスキルはあるが、無理なく楽しみながら開発したい
- **ニーズ**:
  - 思いついた時に軽く触れて、少しだけ楽しめるゲーム
  - かわいい女の子のミニキャラが動く様子を眺めて癒されたい
  - 自動化要素で「進んでいる」実感を得たい
  - 無理なく開発を進められる、スモールスタートな設計
- **ペインポイント**:
  - 既存ゲームは毎日ログインを強制されてプレッシャーに感じる
  - 最適化を考えすぎて疲れてしまう複雑なゲームは避けたい
  - メンタルの調子が悪い時に無理をしたくない
  - サーバー運用コストをかけたくない

## 2. エピック（大項目）

1. **初回プレイ体験** - ゲームを起動して基本操作を理解し、最初の惑星開拓を始める
2. **資源収集と自動化** - 資源を集め、施設を配置して自動化の基礎を構築する
3. **キャラクターとの交流** - 女の子キャラと会話し、愛着を育む
4. **惑星開拓の拡張** - より多くの施設や資源を使って惑星を発展させる
5. **収集とカスタマイズ** - コレクション要素を楽しみ、自分好みの惑星を作る
6. **データ管理と共有** - ゲームの進捗を保存し、SNSで共有する

## 3. ユーザーストーリー詳細

### エピック1: 初回プレイ体験

#### US-1.1: ゲームを起動して世界観を理解する
**As a** 新規プレイヤー  
**I want to** ゲームを起動して、簡単なストーリーとチュートリアルを見る  
**So that** 何をするゲームなのか、どんな雰囲気なのかを理解できる

**受け入れ条件:**
- [ ] ゲーム起動時にタイトル画面が表示される
- [ ] 「新しく始める」ボタンからゲームを開始できる
- [ ] 簡単な導入ストーリー（主人公と助手の女の子が惑星に降り立つ）が表示される
- [ ] チュートリアルで基本操作（ズーム、パン、クリック）を学べる
- [ ] チルで牧歌的な雰囲気が伝わるBGMとビジュアルが表示される

#### US-1.2: マップを見渡して操作に慣れる
**As a** 新規プレイヤー  
**I want to** マップを自由にズーム・パンして探索する  
**So that** 惑星の様子を把握し、操作に慣れることができる

**受け入れ条件:**
- [ ] クオータービュー（真上視点, isometric）のマップが表示される
- [ ] マウスホイールまたは2本指ピンチでズームイン/アウトできる
- [ ] ドラッグ操作でマップをパンできる
- [ ] マップ上に初期配置の資源ポイント（木、石など）が表示される
- [ ] ミニキャラの女の子が画面内に表示され、簡単なアニメーションをしている

#### US-1.3: 初めての女の子キャラと出会う
**As a** 新規プレイヤー  
**I want to** 助手の女の子キャラと会話する  
**So that** キャラクターに親しみを感じ、ゲームの目的を理解できる

**受け入れ条件:**
- [ ] ミニキャラをクリックすると、立ち絵とダイアログが表示される
- [ ] 女の子が「先輩、一緒に頑張りましょう！」的なセリフを言う
- [ ] ボーイッシュで前向きなキャラクター性が伝わる
- [ ] ダイアログを閉じるとゲーム画面に戻れる

### エピック2: 資源収集と自動化

#### US-2.1: 手動で資源を収集する
**As a** プレイヤー  
**I want to** マップ上の資源ポイントをクリックして資源を集める  
**So that** 施設建設に必要な資源を即座に入手できる

**受け入れ条件:**
- [ ] 木材、石材などの資源ポイントがマップ上に配置されている
- [ ] 資源ポイントをクリックすると、資源が増加する（視覚的フィードバック付き）
- [ ] 収集した資源の量が画面上部のUIに表示される
- [ ] クリックした際に気持ちいいエフェクト（パーティクル、サウンド）が発生する
- [ ] 資源ポイントは一定時間後に再生成される

#### US-2.2: ~~自動収集される資源を確認する~~(廃止)
廃止理由: 限られたリソースを使いつくすことなく、新たに木や作物を育て収穫することで持続可能なゲームを実現したい。そのため、自動でどこからか資源を取得することはやめたい。  
**As a** プレイヤー  
**I want to** 時間経過で自動的に資源が増えるのを確認する  
**So that** ゲームを放置していても進捗があることを実感できる

**受け入れ条件:**
- [ ] ゲーム開始時から、資源が少しずつ自動増加する
- [ ] 一定時間ごとに「+5木材」のようなポップアップが表示される
- [ ] ゲームを閉じて再度開いた時、経過時間分の資源が加算される（上限あり）
- [ ] 「おかえりなさい！この間に○○を集めました」的なメッセージが表示される

#### US-2.3: 最初の施設を建設する
**As a** プレイヤー  
**I want to** 収集した資源を使って施設を建設する  
**So that** 自動化の第一歩を踏み出せる

**受け入れ条件:**
- [ ] 画面下部またはサイドに「建設メニュー」が表示される
- [ ] 建設可能な施設（採掘場、農場など）がアイコンで表示される
- [ ] 施設を選択すると、必要な資源と効果が表示される
- [ ] マップ上の任意の空きタイルに施設を配置できる
- [ ] 配置後、施設が建設され、ミニキャラがそこに向かうアニメーションが再生される

#### US-2.4: 施設の自動化効果を確認する
**As a** プレイヤー  
**I want to** 建設した施設が自動で資源を生産するのを見る  
**So that** 自動化の効果を実感し、さらに施設を増やしたくなる

**受け入れ条件:**
- [ ] 施設が稼働すると、定期的に資源が生産される
- [ ] ミニキャラが施設と資源ポイントの間を行き来するアニメーションが表示される
- [ ] 施設をクリックすると、生産量や稼働状況が確認できる
- [ ] 施設が多いほど資源生産が加速することが視覚的に分かる

#### US-2.5: 施設を配置換えする
**As a** プレイヤー  
**I want to** 建設済みの施設を別の場所に移動する  
**So that** レイアウトを試行錯誤し、自分好みの配置を楽しめる

**受け入れ条件:**
- [ ] 施設を長押し（またはクリック&ホールド）すると、掴んで移動できる
- [ ] ドラッグ中、配置可能な場所がハイライト表示される
- [ ] 配置換えは無料または少額のコストで実行できる
- [ ] 配置換え後も施設の機能は維持される

### エピック3: キャラクターとの交流

#### US-3.1: 女の子キャラに話しかける
**As a** プレイヤー  
**I want to** いつでもミニキャラをクリックして会話できる  
**So that** キャラクターとの繋がりを感じ、癒される

**受け入れ条件:**
- [ ] ミニキャラをクリックすると立ち絵とダイアログが表示される
- [ ] セリフは時間帯（朝、昼、夜）に応じて変化する
- [ ] 開発の進捗度に応じてセリフが変わる（「まだ始まったばかりですね」→「だいぶ発展してきました！」）
- [ ] たまに女の子の日常が垣間見えるセリフがある（「今日は眠いです…」など）

#### US-3.2: キャラクターの成長を感じる
**As a** プレイヤー  
**I want to** 惑星開拓が進むにつれて、女の子が成長する様子を見る  
**So that** 一緒に歩んでいる実感を得られる

**受け入れ条件:**
- [ ] 特定のマイルストーン（施設数、資源量など）達成時にイベントが発生する
- [ ] 女の子が「できることが増えました！」的な報告をしてくれる
- [ ] セリフに自信や成長が表れる変化がある
- [ ] （後追い実装）新しいスキルやアクションが解放される

#### US-3.3: キャラクターとの距離感を楽しむ
**As a** プレイヤー  
**I want to** 女の子キャラとフレンドリーだけど適度な距離感の関係を築く  
**So that** 健全で長続きする愛着を感じられる

**受け入れ条件:**
- [ ] セリフは親しみやすいが、過度にロマンチックではない
- [ ] 「先輩」と呼ぶなど、適度な上下関係が保たれる
- [ ] たまに失敗や悩みを見せる人間味がある
- [ ] プレイヤーに感謝や尊敬を示すセリフがある

### エピック4: 惑星開拓の拡張

#### US-4.1: 新しい資源を発見する
**As a** プレイヤー  
**I want to** 探索や開発を進めることで新しい資源を発見する  
**So that** ゲームに新鮮さを感じ、さらなる開拓意欲が湧く

**受け入れ条件:**
- [ ] 特定の条件（施設の建設、エリアの探索など）で新資源が解放される
- [ ] 新資源発見時に「新しい資源を見つけました！」的な通知が表示される
- [ ] 女の子が新資源について説明してくれる
- [ ] 新資源を使った施設が建設可能になる

#### US-4.2: より高度な施設を建設する
**As a** プレイヤー  
**I want to** 複数の資源を組み合わせた高度な施設を建設する  
**So that** より効率的な自動化と達成感を得られる

**受け入れ条件:**
- [ ] 複数資源を必要とする施設が建設メニューに追加される
- [ ] 高度な施設はより高い生産効率を持つ
- [ ] 建設時に特別なアニメーションやエフェクトが表示される
- [ ] 女の子が「すごいですね！」的な反応をする

#### US-4.3: 惑星の景観が変化するのを楽しむ
**As a** プレイヤー  
**I want to** 開発が進むにつれて惑星の見た目が発展していくのを見る  
**So that** 視覚的な達成感と愛着を感じられる

**受け入れ条件:**
- [ ] 施設が増えると、惑星全体が賑やかになる
- [ ] 開発度に応じて背景やエフェクトが変化する（花が咲く、道ができるなど）
- [ ] ズームアウトして全体を見渡すと、自分が作った世界を実感できる

### エピック5: 収集とカスタマイズ

#### US-5.1: 風景コレクションを集める
**As a** プレイヤー  
**I want to** 特定の条件で美しい風景を発見し、コレクションする  
**So that** なんとなくの目標を持ちながら、チルに楽しめる

**受け入れ条件:**
- [ ] 特定の時間帯・天候・施設配置で「風景ポイント」が発生する
- [ ] 風景ポイントに近づくと「!」マークが表示される
- [ ] スクリーンショット機能で風景を保存できる
- [ ] 保存した風景はギャラリーで閲覧できる
- [ ] コレクション数が表示されるが、報酬はない（純粋な収集の楽しみ）

#### US-5.2: レア資源・生物を発見する
**As a** プレイヤー  
**I want to** たまに珍しい資源や生物を見つける  
**So that** 探索のワクワク感を味わえる

**受け入れ条件:**
- [ ] 資源収集時に低確率でレアアイテムが見つかる
- [ ] レア発見時に特別なエフェクトと通知が表示される
- [ ] 女の子が「珍しいものを見つけました！」と報告してくれる
- [ ] 図鑑に登録され、説明文が読める
- [ ] 実用的な効果はなく、純粋にコレクション要素

#### US-5.3: 女の子の衣装を変更する
**As a** プレイヤー  
**I want to** 開発が進むと新しい衣装を作成し、女の子に着せられる  
**So that** 見た目のカスタマイズを楽しめる

**受け入れ条件:**
- [ ] 特定の条件で新衣装が解放される
- [ ] 衣装メニューから着せ替えができる
- [ ] 衣装変更は性能に影響しない（見た目のみ）
- [ ] ミニキャラと立ち絵の両方が変更される
- [ ] 女の子が衣装について感想を言う

### エピック6: データ管理と共有

#### US-6.1: ゲームの進捗を保存する
**As a** プレイヤー  
**I want to** ゲームを閉じても進捗が保存される  
**So that** いつでも安心して中断・再開できる

**受け入れ条件:**
- [ ] ゲーム状態はローカルストレージに自動保存される
- [ ] 保存は定期的（数分ごと）と手動（メニューから）の両方が可能
- [ ] 保存成功時に小さな通知が表示される
- [ ] 再起動時に前回の続きから再開できる

#### US-6.2: クラウドにバックアップする
**As a** プレイヤー  
**I want to** オプションでクラウドにデータをバックアップする  
**So that** 端末を変えても続きから遊べる

**受け入れ条件:**
- [ ] 設定メニューから「クラウド同期」を有効化できる
- [ ] 同期時にCloudflare D1にデータが保存される
- [ ] 別端末からログインして続きをプレイできる
- [ ] 同期の成功/失敗が通知される

#### US-6.3: 風景や進捗をSNSに投稿する
**As a** プレイヤー  
**I want to** ゲーム内の風景やスクリーンショットをSNSに投稿する  
**So that** 自分の惑星を他の人と共有し、楽しさを広げられる

**受け入れ条件:**
- [ ] スクリーンショット機能がある
- [ ] 撮影した画像をダウンロードできる
- [ ] （オプション）X（Twitter）やDiscordへの直接投稿機能
- [ ] 画像に「#StellaGarden」などのハッシュタグが自動付与される
- [ ] プレイヤー情報は含まれない（プライバシー配慮）

#### US-6.4: データをリセットする
**As a** プレイヤー  
**I want to** 必要に応じてゲームをリセットして最初からやり直す  
**So that** 新鮮な気持ちで再スタートできる

**受け入れ条件:**
- [ ] 設定メニューに「データリセット」オプションがある
- [ ] リセット前に確認ダイアログが表示される
- [ ] リセット後は完全に初期状態に戻る
- [ ] クラウドバックアップも削除するか選択できる
