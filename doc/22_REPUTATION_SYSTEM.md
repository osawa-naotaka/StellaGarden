## 1. 設計方針

### 1.1 背景

これまでの実装では、出荷可能な全ての品目が一律でポイントに変換される設計だった。
このため以下の問題が生じていた:

- プレイヤーに「次に何を目指すか」という方向性が示されない
- 加工度の違いがプレイヤーに伝わらない
- `03_SYNOPSIS.md` の「需要を報酬にする」設計が活かされていない

本書では、出荷品目ごとに**アンロック条件**と**スコア（単価）**を設定し、
プレイヤーが「次のアンロックを目指して生産チェーンを伸ばす」という方向性を持って遊べる
システムを定義する。

### 1.2 基本原則

- **アンロックは累積出荷量で進行する** — 一度アンロックされた品目は失われない（チル原則）
- **加工度が高いほど単価が高い** — より長いサプライチェーンを経由した品ほど評価が高い
- **スキルツリーは採用しない** — アンロックは技術習得ではなく市場の信用獲得を意味する
- **フィージビリティ範囲のゴールは「袋詰め大豆」** — 全サプライチェーンが結節する最終目標
- **取引先別の需要差は導入しない（初期実装）** — まずは単一の市場として実装し、将来の拡張点として残す

## 2. 設定面の前提: 転移ゲートと包装

### 2.1 転移ゲートと劣化

出荷物は地球（または他の星系）への**転移ゲート**を通じて輸送される。
転移ゲートは輸送時間こそかからないが、**通過時に商品が劣化する**という設定を採用する。

このため:

- **裸の状態で出荷した商品は劣化が激しく、買い取り単価は低い**
- **密封された容器（袋・瓶）に入った商品は劣化を抑えられ、本来の価値で取引できる**

これにより、「なぜ袋詰めや瓶詰めが必要なのか」という疑問が物理的に正当化される。

### 2.2 袋詰めの二重の価値

袋詰めには、転移ゲート対策という**物理的価値**に加えて、
**サプライチェーン完成度の証明**という意味も持たせる。

> 袋詰め大豆を出荷できるということは、この惑星単独で
> 「作物栽培 → 加工 → 繊維工業 → 包装 → 出荷」までの
> 完全な垂直統合サプライチェーンが回っていることを示す。
> これは入植適性の最も強い証拠であり、地球側の評価が大きく跳ね上がる。

つまり、袋詰め大豆は単なる「大豆 + 袋」ではなく、
**「これを安定供給できる惑星基盤の証明書」としての価値**を持つ。
Factorio で言うロケット打ち上げに近い、記号的な意味を持つ。

### 2.3 油の容器について（ペンディング）

油類（大豆油・亜麻仁油）は液体のため袋詰めできず、
本来であれば瓶などの密封容器が必要になる。

**初期実装の方針**: 油類の容器は実装上の例外として「暗黙に瓶に入っている」前提で扱う。
プレイヤーから見て「油は瓶詰めされているんだろうな」で違和感がない。

**将来の拡張方針**: フィージビリティスタディの後半で、
ガラス瓶（`05_CULTIVATION.md` の砂 + 草木灰のレシピ）を
油の出荷条件として明示的に要求する案を検討する。
油の出荷チェーンが伸びる代わりに、油の単価をさらに引き上げることで
「面倒だが価値が高い」というバランスを取る。

## 3. 出荷品とアンロックチェーン

### 3.1 アンロック構造の全体像

```
Tier 1: じゃがいも
  ↓ じゃがいもの累積出荷
Tier 2: 大豆（生）
  ↓ 大豆（生）の累積出荷  ── 並行アンロック ──
  ├→ Tier 3a: 亜麻仁油
  └→ Tier 3b: 大豆油
       ↓ 亜麻仁油の累積出荷
Tier 4: 糸
  ↓ 糸の累積出荷
Tier 5: 布
  ↓ 布の累積出荷  ── 並行アンロック ──
  ├→ Tier 6a: 袋詰めじゃがいも
  └→ Tier 6b: 袋詰め大豆 ★フィージビリティ範囲のゴール
```

### 3.2 各 Tier の詳細

#### Tier 1: じゃがいも

- **アンロック条件**: ゲーム開始時から出荷可能
- **位置づけ**: 序盤の唯一の出荷品。生存基盤の確立と同時に出荷実績を積む
- **特徴**: 最低単価。アンロックハードルも最低（10〜15分のプレイで Tier 2 に到達できる程度を目安）

#### Tier 2: 大豆（生）

- **アンロック条件**: じゃがいもの累積出荷量が閾値達成
- **位置づけ**: 「未袋詰めの脱穀済み大豆」。脱穀機による加工は必要だが、袋は不要
- **特徴**: じゃがいもより単価が高い。袋詰め大豆（Tier 6b）よりは大幅に低い

#### Tier 3a: 亜麻仁油 / Tier 3b: 大豆油（並行アンロック）

- **アンロック条件**: 大豆（生）の累積出荷量が閾値達成
- **位置づけ**: 搾油機の導入を促す段階。プレイヤーは大豆ライン（油）と亜麻ライン（油 + 種栽培）の
  どちらを先に伸ばすか選べる
- **特徴**:
  - 亜麻仁油は亜麻という新作物の導入が必要。亜麻栽培そのもののハードルが高い
  - 大豆油は既存の大豆ラインを延伸するだけで済む
  - プレイヤーは「楽な大豆油から始めるか、将来のために亜麻に手を出すか」を選択する

#### Tier 4: 糸

- **アンロック条件**: 亜麻仁油の累積出荷量が閾値達成
- **アンロックの意味**: 「亜麻栽培の実績が認められて繊維市場が開く」
- **設計上の補足**: 亜麻仁油の出荷時点で、プレイヤーは既に亜麻栽培を行っている。
  栽培時に副産物として茎が得られている（堆肥にしているか、廃棄しているか）。
  Tier 4 のアンロックは「既に手元にある亜麻の茎を繊維化する動機」を提供する

#### Tier 5: 布

- **アンロック条件**: 糸の累積出荷量が閾値達成
- **位置づけ**: 織機の導入を促す。糸そのものより布の方が単価が高い
- **特徴**: 布は出荷品でありつつ、Tier 6 の「袋」の素材でもある。
  プレイヤーは「布のまま売るか、袋にしてさらに加工するか」を選べる

#### Tier 6a: 袋詰めじゃがいも

- **アンロック条件**: 布の累積出荷量が閾値達成
- **位置づけ**: 序盤に作ったじゃがいも畑を後半でも活用できるようにする「呼び戻し設計」
- **特徴**: 単価は中程度。袋詰め大豆より低いが、生じゃがいも（Tier 1）より大幅に高い

#### Tier 6b: 袋詰め大豆 ★ゴール

- **アンロック条件**: 布の累積出荷量が閾値達成（Tier 6a と同時アンロック）
- **位置づけ**: フィージビリティ範囲の最終目標。全生産ラインの結節点
- **特徴**: 最高単価。「大豆ライン + 亜麻ライン + 包装ライン」の全てが揃って初めて生産可能

### 3.3 並行アンロックの設計意図

完全な一本道ではなく、Tier 3 と Tier 6 で並行アンロックを置いている。
これは以下の効果を狙っている:

- プレイヤーに**選択肢**を与える（「今日は大豆ラインを伸ばそう」「次は亜麻に手を出そう」）
- 同時アンロックは**2品目まで**に制限し、認知負荷を抑える
- 並行ラインの片方が他方の前提条件にならないため、プレイヤーは自分のペースで遊べる

### 3.4 出荷チェーンに含めない品目

`15_RE_SYNOPSIS.md` の出荷品目一覧には含まれているが、本書では出荷対象としない品目:

| 品目 | 理由 |
|---|---|
| 油粕（大豆・亜麻） | 既に内部肥料として使用されている。出荷すると肥料供給が崩れる |
| ロープ | 自動化（ケーブル牽引）の内部資材として使用される |

これらは将来的に出荷品として追加する余地はあるが、初期実装では内部消費資材として扱う。

## 4. スコア設計の方針

### 4.1 スコアの基本原則

- **加工度の階段的上昇**: 各 Tier ごとに単価が明確に上がっていく
- **同 Tier 内では加工度に応じて差をつける**: 例えば Tier 6 内では袋詰めじゃがいも < 袋詰め大豆
- **スキップ動機を作る**: 上位 Tier がアンロックされると、下位 Tier を続ける旨味が薄れる
  - ただし、袋詰めじゃがいも・袋詰め大豆のように「下位の素材を使った高位品」が用意されている品目は例外

### 4.2 スコアの相対序列（仮の目安）

具体的な数値は実装後のプレイテストで調整するが、相対序列の目安は以下の通り:

| Tier | 品目 | 相対スコア（じゃがいも = 1 として） |
|---|---|---|
| 1 | じゃがいも | 1 |
| 2 | 大豆（生） | 3 |
| 3a | 亜麻仁油 | 8 |
| 3b | 大豆油 | 6 |
| 4 | 糸 | 12 |
| 5 | 布 | 20 |
| 6a | 袋詰めじゃがいも | 15 |
| 6b | 袋詰め大豆 | 50 |

ポイント:
- **袋詰め大豆が突出して高い**（袋詰めじゃがいもの 3 倍以上）
- **亜麻仁油 > 大豆油**（亜麻栽培のハードルを単価で報いる）
- **袋詰めじゃがいも > 布**（袋詰めという完成形態の価値を示す）

### 4.3 アンロック閾値の考え方

「次のアンロックまで何個出荷すればいいか」ではなく、
「**次のアンロックまで何分プレイすればいいか**」という時間感覚で設計する。

| 段階 | 想定プレイ時間 |
|---|---|
| Tier 1 → 2 | 10〜15 分（最初のアンロックは早めに体感させる） |
| Tier 2 → 3 | 20〜30 分 |
| Tier 3 → 4 | 30〜45 分（亜麻栽培という新作物の導入が必要） |
| Tier 4 → 5 | 30 分前後 |
| Tier 5 → 6 | 30 分前後 |

具体的な閾値（「じゃがいも 100 個」など）は、実装後にプレイテストで調整する。
この時間感覚を物差しとして数値を決める。

## 5. ゴール: 袋詰め大豆の意義

### 5.1 なぜ袋詰め大豆がゴールなのか

袋詰め大豆を出荷可能にするには、以下の**全てのライン**が稼働している必要がある:

1. **大豆ライン**: 栽培 → 脱穀 → 精選
2. **亜麻ライン**: 栽培 → レッティング → 繊維分離 → 紡績 → 織り → 縫製
3. **肥料ライン**: 堆肥・草木灰・油粕の循環（両ラインの維持に必要）
4. **灌漑ライン**: 大豆も亜麻も水やり必須（畝間水路の整備）

つまり袋詰め大豆は、**惑星上の全生産システムが整っていることの集約的な証明**である。
Factorio におけるロケット打ち上げが「全技術の集大成」であるように、
袋詰め大豆は「フィージビリティ範囲の生産チェーンの集大成」になる。

### 5.2 ゴール到達後の体験

袋詰め大豆をアンロックして安定出荷できるようになっても、ゲームは終わらない:

- 自動化（`17_AUTOMATION.md`）による生産規模拡大
- 灌漑インフラ（`16_IRRIGATION.md`）の最適化
- 入植船受け入れ条件（`15_RE_SYNOPSIS.md` S 級）への到達準備
- 景観の整備、後輩キャラとの交流

**袋詰め大豆 = フィージビリティ範囲のゴール** であり、
**入植船到達 = ゲーム全体のゴール** という二段構えになる。

## 6. 将来の拡張余地

本書のスコープ外として、将来の検討事項を以下に記しておく。

### 6.1 油の瓶詰め化（ガラス瓶の必須化）

`05_CULTIVATION.md` で定義される**ガラス瓶**（砂 + 草木灰 + 木炭 + 炉）を、
油類の出荷に必須の容器として要求する案。

- 油の出荷チェーンが大幅に伸びる（砂採取・草木灰増産・炉での高温加工）
- その代わり油の単価を引き上げる
- 「油は手間がかかるが報酬も大きい」という位置づけになる
- 砂を将来的に**海岸タイル限定資源**にすると、立地戦略の意味も増す

### 6.2 砂の海岸タイル化

初期実装では砂は粘土と同様に「川沿いランダム生成」とするが、
将来的に「砂は海岸タイル限定」と分離する案。

- 海岸線の存在価値が高まる（拠点立地の選択肢に意味が生まれる）
- 川沿い農地と海岸沿い加工施設という地理的多様性が生まれる
- 6.1 の油の瓶詰め化と組み合わせると、油生産が地理的にも複雑化する

### 6.3 取引先別の需要システム

初期実装では「単一の市場」として扱うが、将来的に取引先（バイヤー）ごとに
買取品目・量・単価を分ける案。

- 例: 織物商は糸・布を高く買う、画材屋は亜麻仁油を高く買う
- プレイヤーは「どこに何を売るか」というミニ最適化に取り組める
- チル感を壊さない範囲で「ちょっと考える楽しさ」を足せる
- `15_RE_SYNOPSIS.md` の 2.3 節にある取引先案が、本格的に活きる段階

### 6.4 袋詰め品カテゴリの拡張

袋というインフラが整うと、他の袋詰め品も追加できる余地がある。

- 袋詰め小麦粉（小麦が将来作物として追加された場合）
- 袋詰めひまわりの種（ひまわり油がペンディング解除された場合）
- 袋詰め塩（塩が資源として導入された場合）

「袋詰めできるか」が新しい作物・加工品の出荷可能性の判断軸になる。

### 6.5 ひまわり油（ペンディング）

ひまわりの種から油を絞って出荷する案は検討したが、**初期実装では見送る**。

理由: ひまわりは現在「連作障害対策・堆肥原料の純粋なサポート作物」として
役割が明確に定まっている。ひまわり油を出荷可能にすると、ひまわりが
じゃがいもの完全上位互換（速い + 出荷収入もある）になり、作物間のバランスが崩れる。

将来実装する場合は、

- ひまわり油はかなり後期の Tier に置く
- 単価設計でじゃがいもとの直接競合を避ける

などの調整が必要。
