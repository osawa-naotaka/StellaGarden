## 2. 操作一覧

### 2.1 フィールド操作

| 操作 | 入力 | 備考 |
|------|------|------|
| 移動（左） | `A` または `←` | 斜め移動時は自動で正規化（速度一定） |
| 移動（右） | `D` または `→` | 同上 |
| 移動（上） | `W` または `↑` | 同上 |
| 移動（下） | `S` または `↓` | 同上 |
| ズームイン | マウスホイール上 | ズームステップ: 0.1 |
| ズームアウト | マウスホイール下 | 同上 |
| インベントリ開閉 | `E` キー | 開いているときにも `E` で閉じる |
| インタラクト | 右クリック | 選択中ツールに応じた操作を実行 |

### 2.2 インタラクト（右クリック）の動作詳細

選択中ツールによって右クリックの効果が変わる。

| 選択ツール | 対象 | 効果 |
|-----------|------|------|
| `hand`（素手） | - | 何もしない |
| `watering_can`（じょうろ） | 耕地（soil） | 湿った耕地（wetSoil）に変化 |
| `hoes`（くわ） | 草/土（entityなし） | 耕地（soil）に変化。3x3の平坦な範囲が必要 |
| `hoes`（くわ） | 耕地上の作物 | 作物を除去（アイテムとして回収されない） |
| `shovel`（シャベル） | 草/土（entityなし） | dirtアイテムを1個取得し、地形を1段下げる。3x3が安全な場合のみ |
| `shovel`（シャベル） | 亜麻（成熟時） | 亜麻の種・亜麻茎・茎を収穫 |
| `shovel`（シャベル） | ジャガイモ（成熟時） | ジャガイモ・茎を収穫 |
| `axe`（斧） | 木 | 丸太1個 + 葉2〜4個を取得 |
| `axe`（斧） | 施設（forge以外） | 施設を撤去してインベントリに回収 |
| `pickaxe`（ピッケル） | forge（炉） | 炉を撤去してインベントリに回収 |
| `sickle`（鎌） | 大豆（成熟時） | 大豆・茎を収穫 |
| `sickle`（鎌） | ひまわり（成熟時） | ひまわりの種・茎を収穫 |
| 種アイテム | 耕地/湿った耕地 | 作物を植え付け（インベントリから1個消費） |
| 肥料アイテム | 耕地/湿った耕地（肥料なし） | 土壌に肥料を施す（インベントリから1個消費） |
| `dirt`（土） | 草/土の上 | dirtをインベントリから1個消費して1段盛る。3x3が安全な場合のみ |

**注意事項:**
- 作物の収穫量は肥料の種類・連作疲労・散水回数に応じて変動する（詳細は 05_CULTIVATION.md 参照）
- 水源ブロック（waterSource）はあらゆるツールで操作不可

### 2.3 ツールバー操作

| 操作 | 入力 |
|------|------|
| スロット選択 | 左クリック |

ツールバーは画面下部中央に常時表示される。選択中スロットは白い太枠で強調表示。スロット数は10（手スロット1 + アイテムスロット9）。インベントリを開くとインベントリウィンドウ下部にもツールバー（アイテムスロット9個）が表示される。

### 3.2 インベントリ内の操作

| 操作 | 入力 | 効果 |
|------|------|------|
| アイテムをピックアップ | スロットを左クリック | スロットのアイテム全量をカーソルに持つ |
| ピックアップ中に別スロットへ置く | 左クリック | カーソルのアイテムとスロットの中身を全交換 |
| 同スロットを再クリック | 左クリック | 元のスロットに戻す（キャンセル） |
| アイテムを1個ピックアップ | スロットを右クリック（ピックアップなし） | 1個だけカーソルに持つ |
| ピックアップ中に1個置く | スロットを右クリック（ピックアップ中） | 対象スロットに1個置く |
| 配置可能アイテムを配置モードへ | スロットを右クリック（配置可能アイテム） | インベントリを閉じ、配置モードへ遷移 |
| ピックアップキャンセル | `Escape` キー | カーソルのアイテムを元スロットに戻す |
| インベントリを閉じる | `E` キー | ピックアップ中の場合も元スロットに戻す |

### 3.3 配置モード

インベントリで配置可能アイテムを右クリックすると、配置モードに入る。

| 操作 | 入力 |
|------|------|
| 配置位置の確定 | 左クリック（配置可能位置のみ） |
| 配置キャンセル | `Escape` キー |

- カーソルに追従する半透明のプレビューが表示される
- 配置可能な位置: 緑のオーバーレイ表示
- 配置不可の位置: 赤のオーバーレイ表示
- 配置可能条件: 草/土/耕地タイル、エンティティなし、施設サイズ全域が同一高さ

## 4. クラフトUI（設計）

### 4.1 基本方針

インベントリUIにタブを追加し、クラフト機能を統合する。作業台の有無によって表示されるレシピが変わる。

| 開き方 | タブのデフォルト | 表示されるレシピ |
|--------|----------------|----------------|
| `E` キー | インベントリタブ | （クラフトタブ切替で）素手/石で作れるもの |
| 作業台を右クリック | クラフトタブ | 素手/石を含む全レシピ |

### 4.2 作業台のインタラクト

フィールドに配置した作業台を**右クリック**することで、クラフトタブが開いた状態のインベントリ/クラフトUIが開く。右クリックはフィールド上のインタラクト（`interact_world`）として統一されており、マイクラと同じ操作感となる。

### 4.3 UIレイアウト

```
┌──────────────────────────────────────────┐
│ [インベントリ] [クラフト]                        │ ← タブ
├──────────────────────────────────────────┤
│ 左ペイン（インベントリ）        │ 右上（レシピ一覧） │
│                         │ ┌──┬──┬──┬──┐  │
│  8×8 グリッド              │ │  │  │  │  │  │ ← 作成可能な
│                         │ ├──┼──┼──┼──┤  │   道具アイコン
│                         │ │  │  │  │  │  │
│                         │ └──┴──┴──┴──┘  │
│                         ├───────────────┤
│                         │ 右下（素材一覧） │
│                         │ [アイコン] x3   │
│                         │ [アイコン] x1   │
└──────────────────────────────────────────┘
```

### 4.4 クラフトタブの操作

| 操作 | 入力 | 効果 |
|------|------|------|
| レシピを選択 | 右上パネルのアイコンを左クリック | そのレシピを選択。右下に必要素材を表示 |
| 選択してクラフト（1個） | 右上パネルのアイコンを右クリック | レシピを選択し、即座に1個クラフト。インベントリから必要素材を消費し、成果物を追加 |

**右上パネルのアイコン表示:**
- 素材が足りているレシピ: 通常表示
- 素材が足りないレシピ: グレーアウト（選択は可能だが右クリックでのクラフトは不可）

**右下パネルの素材表示:**
- レシピ未選択: 空欄
- レシピ選択時: 必要素材のアイコン＋必要数テキストを一覧表示

### 4.5 インベントリタブとクラフトタブの切り替え

- タブをクリックして切り替える
- `E` キーでUIを閉じるのはどちらのタブでも共通
- `Escape` キーはピックアップのキャンセルのみ（タブは閉じない）

### 4.6 素手クラフトと作業台クラフトの分類（doc/11_TOOL.md より）

| クラフト方法 | 表示条件 | 代表的なレシピ |
|-------------|---------|--------------|
| 素手 | 常に表示（作業台不要） | 作業台、焚き火、炭焼き窯、炉 |
| 作業台 | 作業台を右クリックした場合のみ | 堆肥場、脱穀機、石のハンマー、道具各種、施設各種 |
