# フィージビリティスタディ

## 目的
実際にゲームが楽しいものになるのか確認したい。そのために、簡易実装でゲームを作成し、テストプレイで楽しさを確認したい。

### 農作物の育成

まず生活の基盤を整えるために、農作物の育成を考える。育成は、手動でひとつずつやる方法と、自動化する方法の二種類を考える。
農作物は成長すると種を2個生成し、これにより、種スタックをどんどん増やすことができる
農作物は、主人公が食べることで少しずつ減る。この減るスピードより作るスピードを上げるのが最初の目的となる。

本当は料理のフェーズが入ったりするはずだが、それは省略する

- [x] isometricの地形画像を購入し、スプライトとして表示する
- [x] シンプレックスノイズによる地形生成
  - シードを固定し、毎回同じ地形を生成させる
  - ボクセルマップとして生成する
  - 土の土地と海のみ生成
- [x] ボクセルを二次元に投影し、isometricのタイルをスプライトにして敷き詰めて土地として表示
  - オクルージョンは考慮せず、奥行きの深いものから順にすべてスプライトとして描画する
- [x] 土地の上に主人公を表示
  - 待機アニメーションを表示
- [x] isometricな土地のスプライト1個1個に対し、透明部分以外に当たり判定を設定して、クリック可能にする
- [x] ドラッグによるスクロール、ホイールによる拡大縮小
- [x] 主人公に小さい矩形を設定し当たり判定とする。矩形外は当たり判定外とする
- [x] 土地のマウスクリックによる主人公の移動
- [x] 樹木生成と表示
  - 適切な生成方法がまだわからないのでLLMと相談する
- [x] 画面下部にツールバーを表示
  - じょうろ、斧、ピッケル、くわ、いも、土などのアイテムを表示する
- [x] eキーを押すと画面中央にインベントリを表示
  - 8x8の64項目のインベントリに対して、ツールバーとのアイコンの置き換えなどができるようにする
  - インベントリはescキーもしくはeキーで閉じる
- [x] 樹木表示
- [x] 斧で樹木をインタラクト（右クリック）すると樹木を削除し、樹木スタック数を+1する
- [x] アイテム：シャベルを選び、土地をインタラクトすると土地を削除し、土スタックを+1する
- [x] アイテム：土を選び、土地をインタラクトすると土地を追加し、土スタックを-1する
  - 本当は荒地にすべきだが、今回は省略して盛った土地は即草になる
- [x] くわで土地をインタラクトすると土地の種類を草から土に変更する。
- [x] 耕した土地に対して芋を選びインタラクトすると、土地に種芋を植える
- [x] 種芋を植えてから一定時間経過（ゲーム内リアルタイムで数日？1日は10分くらいとする）すると、農作物のスプライトを成長段階に合わせて作成し表示する
- [x] 伐採コマンドで農作物をクリックすると収穫し、芋スタックを+1~+3する
  - 定期的に水やりをしていると芋スタックの増え方を+2~+4に変更する
  - 定期的に水やり=ゲーム内リアルタイム1日のうちに1回以上水やりをしていること
  - 水やりをすると土地が濡れたスプライトになる。1日経過すると普通の耕地に戻る
  - 1日の経過は、きっちり1日ではなく、ゲーム内で一日が始まる時間（朝、1日のタイマーのリセットタイミング）をまたいだ時に一日経過とする
    - そのため、初日はすぐにカウントアップする可能性はあるが、それは許容する
- [ ] 農作物スタックを定期的に-1する
- [ ] 農作業の自動化アイディアを考える
  - 単純に水やり装置を置く、とか、トラクターを配置する、とかでもいいかもしれないが、できればマイクラのように、水を流すと農作物を水流で収穫でき、ホッパーを使って集めることができる、みたいなことをやりたい
  - かなり難しいと思う
  - プログラム言語の要素からアイディアを取得したい。全体としてヴィジュアルプログラミングみたいなことをしたい
