# フィージビリティスタディ

## 目的
実際にゲームが楽しいものになるのか確認したい。そのために、簡易実装でゲームを作成し、テストプレイで楽しさを確認したい。

### 農作物の育成

まず生活の基盤を整えるために、農作物の育成を考える。育成は、手動でひとつずつやる方法と、自動化する方法の二種類を考える。
農作物は成長すると種を2個生成し、これにより、種スタックをどんどん増やすことができる
農作物は、主人公が食べることで少しずつ減る。この減るスピードより作るスピードを上げるのが最初の目的となる。

本当は料理のフェーズが入ったりするはずだが、それは省略する

- [x] isometricの地形画像を購入し、スプライトとして表示する
- [x] シンプレックスノイズによる地形生成
  - シードを固定し、毎回同じ地形を生成させる
  - ボクセルマップとして生成する
  - 土の土地と海のみ生成
- [x] ボクセルを二次元に投影し、isometricのタイルをスプライトにして敷き詰めて土地として表示
  - オクルージョンは考慮せず、奥行きの深いものから順にすべてスプライトとして描画する
- [x] 土地の上に主人公を表示
  - 待機アニメーションを表示
- [x] isometricな土地のスプライト1個1個に対し、透明部分以外に当たり判定を設定して、クリック可能にする
- [x] ドラッグによるスクロール、ホイールによる拡大縮小
- [x] 主人公に小さい矩形を設定し当たり判定とする。矩形外は当たり判定外とする
- [x] 土地のマウスクリックによる主人公の移動
- [ ] 樹木生成と表示
  - 適切な生成方法がまだわからないのでLLMと相談する
- [ ] 画面上部にコマンドパレットを表示
  - 移動、伐採（木と作物）、土を掘る、土を盛る、耕す
    - 種を植える、水を撒くはまずは実装しない。耕す=種を植える＋水をやるを自動実行していると思う
- [ ] 画面左部にインベントリを表示
  - 土、種、農作物それぞれの所持数を表示
- [ ] 樹木表示
- [ ] 伐採コマンドで樹木をクリックすると樹木を削除し、樹木スタック数を+1する
- [ ] 土を掘るコマンドで土地をクリックすると土地を削除し、土スタックを+1する
- [ ] 土を盛るコマンドで土地をクリックすると土地を追加し、土スタックを-1する
  - 本当は荒地にすべきだが、今回は省略して盛った土地は即草になる
- [ ] 耕すコマンドで土地をクリックすると土地の種類を草から土に変更する。種スタックを-1する
- [ ] 耕してから一定時間経過すると、農作物のスプライトを作成し表示する
- [ ] 伐採コマンドで農作物をクリックすると収穫し、農作物スタックを+1し、種スタックを+2する
  - 土地は草にもどる。また耕すことが必要
- [ ] 農作物スタックを定期的に-1する
- [ ] 農作業の自動化アイディアを考える
  - 単純に水やり装置を置く、とか、トラクターを配置する、とかでもいいかもしれないが、できればマイクラのように、水を流すと農作物を水流で収穫でき、ホッパーを使って集めることができる、みたいなことをやりたい
  - かなり難しいと思う
  - プログラム言語の要素からアイディアを取得したい。全体としてヴィジュアルプログラミングみたいなことをしたい
