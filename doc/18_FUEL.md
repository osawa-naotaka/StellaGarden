# 燃料システム設計

## 1. 設計方針

### 1.1 背景

- 炉（焼窯）を使った加工がゲーム中盤以降の生産チェーンの基盤になる
- 焼きレンガ（doc/16_IRRIGATION.md）、将来的な金属精錬など、燃料を必要とする加工が複数存在する
- 燃料の種類によって「燃焼時間」と「到達温度」が異なり、用途の使い分けが生まれる
- 木材→木炭への加工は、エネルギー効率のトレードオフを伴う判断になる

### 1.2 基本原則

- 燃料は2種類: **木材**（基本燃料）と**木炭**（加工燃料）
- 木炭は木材より「燃焼時間が長い」「到達温度が高い」「煙が少ない」が、変換ロスがある
- スキルツリーによる制限はない（doc/15_RE_SYNOPSIS.md のオープンクラフト方式に準拠）
- リソースの可用性のみが制約

## 2. 燃料の種類と特性

### 2.1 比較表

| 特性 | 木材 | 木炭 |
|---|---|---|
| 入手方法 | 伐採 | 炭焼き窯で木材を加工 |
| 燃焼時間（1個あたり） | **1**（基準） | **2**（木材の2倍） |
| 到達温度 | 低〜中（600〜1000°C相当） | 高（1000〜1300°C相当） |
| 煙 | 多い | 少ない |
| 温度の安定性 | 不安定（炎→熾火と変化） | 安定（一定温度で長時間） |
| 保存性 | 湿気で腐る可能性あり | 半永久的に保存可能 |

### 2.2 燃焼時間の比率: 1:2

- 木材1個の燃焼時間を基準（1）とし、木炭1個の燃焼時間を2とする
- 現実の発熱量比（木材16〜18 MJ/kg : 木炭29〜34 MJ/kg ≒ 約1:1.8〜2.0）に基づく
- ゲームとして「木炭にすると倍持つ」という直感的でわかりやすいルール

### 2.3 到達温度の区分

燃料ごとに到達できる温度帯を分け、加工レシピの前提条件とする:

| 温度帯 | 木材 | 木炭 | 用途例 |
|---|---|---|---|
| 低温 | ○ | ○ | 調理、乾燥 |
| 中温 | ○ | ○ | 焼きレンガ（900〜1100°C） |
| 高温 | × | ○ | 金属精錬、ガラス（将来） |

**焼きレンガは木材で焼成可能**（doc/16_IRRIGATION.md 6.3節）。現実でもレンガの焼成温度900〜1100°Cは木材の燃焼で到達できる。

高温帯は木炭でのみ到達可能とし、金属精錬など将来の加工で木炭の必要性が生まれる。

## 3. 木材→木炭の変換

### 3.1 変換レシピ（2案併記、要決定）

炭焼き窯は使い捨て（doc/11_TOOL.md 参照）。茎は炭化して消滅、土は窯を崩した際に回収可能。

#### 案A: 3:1（現実寄り）

```
丸太 ×12 + 茎 ×2 + 土 ×2 → 木炭 ×4 + 土 ×2
```

- 丸太:木炭 = **3:1**。現実の収率（20〜25%）をゲーム向けに簡略化
- 木炭への変換は総エネルギーでは損をする → **エネルギーロス vs 質的メリット**のトレードオフ

#### 案B: 1:1（手間寄り）

```
丸太 ×12 + 茎 ×2 + 土 ×2 → 木炭 ×12 + 土 ×2
```

- 丸太:木炭 = **1:1**。エネルギーロスなし
- 木炭は木材の**純粋な上位互換**（軽い・長持ち・高温） → **炭焼きの手間と時間**が唯一のトレードオフ

### 3.2 エネルギー効率の比較

| 比較 | 案A (3:1) | 案B (1:1) |
|---|---|---|
| 丸太12個をそのまま燃やす | 燃焼時間 12 | 燃焼時間 12 |
| 丸太12個 → 木炭にして燃やす | 木炭4個 × 2 = 燃焼時間 **8**（33%ロス） | 木炭12個 × 2 = 燃焼時間 **24**（2倍に増加） |

### 3.3 各案の特徴

#### 案Aの場合: 判断のあるトレードオフ

- 「木炭にすべきか？」の判断が常にある
- 高温が不要なら木材のまま使うほうが効率的 → 燃料の使い分けが生まれる
- 現実に近い

#### 案Bの場合: 時間コストによるゲート

- 木炭は上位互換なので、**作れるなら常に木炭が正解**
- トレードオフは「炭焼きに費やす時間と手間」のみ
- 序盤: 炭焼きの余裕がない → 木材をそのまま使う
- 中盤: 生産が安定 → 木炭にシフト
- 後半: 炭焼きも自動化 → 木材をそのまま使う理由がなくなる
- Factorioの「鉄板→鋼鉄」に近い構造（加工の手間が唯一のコスト）
- 現実からは乖離するが、ゲームとしてシンプルで進行感がある

**備考（案B採用時）:** 木材を燃料として使う行為がゲーム中盤以降は消える。木材にも存在意義を残したい場合は、木材でしかできない加工（燻製など、煙が必要な用途）を将来追加する余地がある。

### 3.4 設計意図（共通）

- 「とりあえず木材で燃やす」は常に可能（序盤のハードルが低い）
- 自動化が進むほど木炭のメリットが大きくなる（補充頻度の低下、搬送コストの削減）
- 現実の「炭焼きは手間だが便利な燃料が手に入る」という構造をゲーム化している

### 3.5 木炭の質的メリット（両案共通）

1. **高温が出せる** — 木材では不可能な加工ができる
2. **1個あたりの燃焼時間が長い** — 炉への燃料補充頻度が下がる（自動化と好相性）
3. **軽い** — 運搬コストが下がる（将来的なベルトコンベア/搬送の自動化で重要）
4. **安定燃焼** — 温度が安定するため加工品質が均一になる（将来的な品質システムで活用可能）

## 4. 炭焼き窯

### 4.1 位置づけ

- 木材を木炭に変換する専用の加工施設
- 炉（焼窯）とは別のエンティティ（炉は「燃料を使って素材を加工する」、炭焼き窯は「木材を蒸し焼きにする」）
- 現実の炭焼きは窯を密閉して不完全燃焼させる工程であり、通常の炉とは異なる

### 4.2 仕様（案）

- 設置型エンティティ
- 木材を投入し、一定時間経過後に木炭が完成する
- 加工中は煙が出る（ビジュアルフィードバック）
- 素材: 石または粘土（要検討）

## 5. 用途別の燃料選択ガイド

ゲーム進行に沿った燃料の使い分け:

| フェーズ | 主な加工 | 推奨燃料 | 理由 |
|---|---|---|---|
| 序盤 | 焼きレンガ | 木材 | 木材で十分な温度。変換ロスを避ける |
| 中盤 | 焼きレンガ大量生産 | 木炭も選択肢 | 補充頻度を減らしたい場合に木炭が有利 |
| 中盤〜後半 | 金属精錬（将来） | 木炭（必須） | 高温帯は木炭でのみ到達可能 |
| 後半 | 大規模自動加工 | 木炭 | 自動搬送との相性（軽い・長持ち） |
